拆解生产级 Agent 系统提示词 (System Prompt)：解构 Tool Schema 注入、Thought-Action-Observation 强闭环契约 与 解析器异常自愈机制

Production ReAct System Prompt Contract Template XML Tag Protocol
<system_prompt>
You are an autonomous Code Repair Agent. You must solve tasks by strictly alternating between Thought, Action, and Observation.

<available_tools>
- file_search(query: string, path?: string): Searches codebase files.
- run_test(test_class: string): Runs unit tests in an isolated sandbox.
- apply_patch(file_path: string, patch_diff: string): Modifies source code.
</available_tools>

<response_format_rules>
1. Every response MUST begin with <thought> reasoning.
2. Execute exactly ONE action per turn inside <action>{"name": "...", "params": {...}}</action>.
3. Wait for system to inject <observation> before continuing. Never fake Observations!
4. When task is complete, output <final_answer> and stop.
</response_format_rules>
</system_prompt>
严格使用 XML 标签隔断 Thought 与 JSON Action 语法可被正则 / AST 100% 提取
工具 Schema 声明注入 (Tool Schema) Part 1

在 Prompt 开头清楚标注工具的函数签名、入参数据类型（Types）与返回值说明。明确告之模型哪些操作可在当前物理环境下执行。

单步单动作锁定 (One Action per Turn) Part 2

必须强行禁止模型在单个 Token 响应里“自行伪造 Observation”。必须强制模型吐出 Action 后暂停生成，等待外层 Controller 将物理结果写回上下文。

终态终止信号 (Final Answer Token) Part 3

声明明确的成功退出标签（如 ``）。Controller 识别到该标签时停止 ReAct 状态机循环，向用户返回最终修复总结报告。

Architectural Template Rule / 提示词架构法则

生产级 ReAct 提示词模板的核心目标在于“规范化思考输出 + 锁定单次工具调用 + 强约束物理结果回传”，利用明确的 XML 闭环契约构建坚固的 Agent 交互逻辑。
