模块三：推理范式精讲 / Module 3

推理范式的演进图谱：从 Direct Prompt 到 ToT

探索大模型推理逻辑的演化脉络：通过在计算图中分配更多的 思考 Token (Thinking Tokens)，换取算法推导、复杂重构与深层逻辑决策的精度突破

Stage 1: Direct Thinking: $O(1)$

直接提问 (Direct Prompting)

输入指令，LLM 在单次前向传播中直接预测最终代码。无中间推理缓存。

Input: "写一个快速排序"
Output: def quicksort()...
适于：简单 API 调用 逻辑崩溃率高
Stage 2: Few-Shot Style In-Context

少样本范例 (Few-Shot Prompt)

在 Prompt 中附带 2~3 个 Input-Output 示例，注入团队规范与 DSL 契约。

Example 1: In -> Out
Target In -> Target Out
适于：私有规范/格式控制 无推理过程
Stage 3: Zero-Shot CoT Kojima et al.

零样本思维链 (Zero-Shot CoT)

使用 "Let's think step by step" 魔法句，显式触发自回归生成 Thinking Tokens。

"让我们一步步分析逻辑："
Step 1: 检查空指针...
零成本触发中间推理 精度提升 ~30%
Stage 4: Few-Shot CoT Wei et al.

手工思维链 (Manual CoT)

在范例中展示完整“推理推演步骤 + 最终代码”，教会 LLM 如何拆解业务算法。

Thought: 边界->计算->提取
Code: return result
工业重构与审查基石 逻辑拟合度极高
Stage 5: Least-to-Most Decomposition

由简入繁分解 (Task Breakdown)

先将大问题（如实现 LRU Cache）拆解为子目标列表，按拓扑序依次推理求解。

Subtask 1: 双向链表
Subtask 2: 哈希表映射
适于长链条代码生成 降解复杂度
Stage 6: Tree-of-Thoughts Yao et al.

树状思维 (ToT Search)

从“单链推理”升维至“多路径树状探索”，引入 Evaluation 评价函数与 BFS/回溯剪枝。

Branch A: Score 0.9 (Keep)
Branch B: Score 0.2 (Prune)
复杂系统架构评估 从链条到空间探索

Compute-Accuracy Trade-off / 计算与精度法则

推理范式演进的本质是将“一次性概率生成”升级为显式思维状态空间搜索。输入或生成越多的 Thinking Tokens，模型在概率图谱上的决策路径就越精准。
