3. Few-Shot Demonstration

4. User Query + Tail Re-statement
高注意力区 (90-100%)
头尾双侧重（Recency & Primacy Effect）驱动生成质量。

“Lost in the Middle” U型注意力衰减曲线

Liu et al. (Stanford)
Token Position 0% (Head) 50% (Middle) 100% (Tail)
信息检索准确率降至最低 (<40%)
错误策略 (Middle Placement)

将关键 API 阻断约束隐藏在 10k Token 的长文档中部（第 5000 位置）。
结果：模型忽略约束，产生非法调用。

架构策略 (Tail Pinning)

System Prompt 声明规则 + User Query 尾部重申核心约束。
结果：规则遵循率从 38% 提升至 99%。

架构规则：严禁把“必须强制执行的负向约束”夹杂在巨量检索文档中间！

Architectural Takeaway / 架构小结

长上下文窗口不等于“无限注意力”。在设计工程系统时，必须使用 “尾部锚定 (Tail Pinning)” 机制，将核心指令拉回至 Token 序列末尾。
