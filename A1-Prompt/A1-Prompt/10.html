XML 属性装载元数据 (XML Metadata)

在编写 Code Agent 的 System Prompt 时，固定使用全小写下划线 XML 标签（如 ``、``），并要求模型在思维链与输出中同样保持 XML 结构响应，实现端到端的结构化协同。
