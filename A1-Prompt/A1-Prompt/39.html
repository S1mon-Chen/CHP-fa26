课程总结 / Course 1 Knowledge Synthesis

本课核心知识图谱小结：指令工程与结构化上下文构建

全景复盘四大核心板块：从 模块一：结构化 Prompt 原理、模块二：上下文与确定性输出，到 模块三：推理范式精讲 与 模块四：工具与物理状态交互

1 模块一：结构化 Prompt 原理与防御性设计 Fundamentals
  • 非确定性 V-CPU 范式：将 LLM 视为概率运算单元，Prompt 即高级汇编指令。
  • 防御性编程 3 原则：前置断言（Pre-conditions）+ 强 Schema 契约 + Fallback 降级。
  • 错误级联效应 (Error Cascading)：切断前文微小偏差导致的自回归毁灭性漂移。
核心原则: 消除模糊语义性
2 模块二：结构化上下文与确定性输出 Context & Schema
  • XML 标签物理隔离：利用 `` 等标签隔离数据与指令，免疫攻击。
  • AST 骨架剪枝与 Lost in Middle：Tree-sitter 抹平函数体节约 80% Token，规避注意力衰减。
  • Pydantic & 约束采样：借助 GBNF 语法树掩码做到 100% 格式零报错。
核心原则: 强类型 API 契约
3 模块三：高级推理范式精讲 Reasoning
  • Test-Time Compute 扩展：CoT (Wei/Kojima) 用思考 Token 扩展深度。
  • 多路径探索与分解：Self-Consistency 多投票 + Least-to-Most 拓扑拆解。
  • ToT & Reflexion 试错自愈：启发式树搜索 (ToT) 与沙箱单测反思 (Reflexion)。
核心原则: 算力换取逻辑正确率
4 模块四：工具与物理状态交互 Tools & Agent
  • ReAct 闭环与 Function Calling：Thought-Action-Observation 与 Tool Call 映射。
  • 系统规则引擎 (.cursorrules)：继承分层 (Security $\to$ Repo ADR $\to$ Scoped File Match)。
  • Prompt Eval & Self-Healing：Pass@1 黄金数据集、CI 卡扣与手写 Agent 参考实现。
核心原则: 控制流缝合有状态沙箱

契约化输入输出

XML 上下文隔离 + Pydantic 强类型 DTO 数据通道。

结构化思维推演

从 CoT 到 ToT 树搜索，Test-Time Compute 降本提质。

有状态沙箱自愈

错误 Traceback 转化为 Observation 驱动自动闭环纠错。

Course 1 Knowledge Milestone / 知识图谱收官总结

掌控 Prompt 工程的终极法则：“用结构化契约限制非确定性，用推理范式扩展思考算力，用 ReAct 闭环连接物理沙箱”；这正是迈向高级 AI 编程架构师的第一步。
