子系统 1：Codebase 上下文构建器 (Context Packager) 代码与规范

建立高包含度与零越界风险的结构化上下文：手写 Context Packager 算法，将工程文件树、符号依赖、Diff 编辑历史打包为结构化 XML 上下文标签 (`<codebase_context>`)，并结合 Tiktoken 物理预算裁切

1. 上下文打包三原则与 XML 隔离规范

XML Structuring & Token Budgeting Principles

Packager Specs
XML Tagging
显式 XML 节点隔断（Explicit Tagging）： 使用 `` 与 `` 严格包裹源码，防范模型将源码当作系统指令触发 prompt 注入。
Priority Trunc
按优先级配额裁切（Priority Truncation）： 优先全量保留主编辑文件，其次保留 LSP 诊断错误关联代码，最后保留骨架 (Skeleton) 与依赖文件。
Token Budget
精准 Tiktoken 预算控制： 调用 `tiktoken` 提前计算 Token 数量，保证注入 Prompt 的上下文长度精准硬锁定在配额（如 8000 Tokens）内。
物理本质：把非结构化文件树整理为语义清晰、带有类型元数据的结构化 Prompt 载荷

2. Context Packager 核心代码实现

Python Context Packager with Tiktoken

Python Code
# 生产级 Codebase Context Packager 打包器实现
import tiktoken

def package_codebase_context(files_map: dict[str, str], max_tokens: int = 8000) -> str:
encoder = tiktoken.encoding_for_model("gpt-4o")
xml_buffer = ["<codebase_context>"]
current_tokens = len(encoder.encode(xml_buffer[0]))

for
path, content in files_map.items():
file_xml = f' <file path="{path}">\n{content}\n </file>'
file_tokens = len(encoder.encode(file_xml))
if
current_tokens + file_tokens > max_tokens:
break # 严格预算拦截，防止超长破防！
xml_buffer.append(file_xml)
current_tokens += file_tokens

xml_buffer.append("</codebase_context>")
return "\n".join(xml_buffer)
  • 防注入隔断：将外部可变文件内容强行限定在特定 XML 节点中，模型绝不混淆上下文与指令。
  • 硬性 Token 截断：基于 BPE 分词器做精确流式计数，杜绝 400 Bad Request Context Window 过长报错。
物理本质：手写极简无依赖算子完成多文件到强类型 XML 上下文的转换
