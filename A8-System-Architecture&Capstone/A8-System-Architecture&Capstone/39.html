大模型时代 AI 架构师十六大法则矩阵

16 Golden Rules for Enterprise AI System Architecture

16 Rules Matrix
1. 结构化契约

拒绝裸自然语言，强类型 Pydantic/XML 为唯一契约。

2. 三域解耦

脑体分离：Brain 逻辑与 Body 物理工具强行解耦。

3. 标准化协议

MCP JSON-RPC 为连接外部物理环境的统一管道。

4. 事实锚定

Codebase RAG 混合检索是消杀代码幻觉的防护墙。

5. 能力封装

Skill 模式网络是高内聚原子能力的面向对象抽象。

6. 面向切面

Spring AOP / IoC 托管物理写事务与 RBAC 权限。

7. 有向有环图

用 DCG Graph 表达 ReAct 循环、重试与自愈。

8. 显式收敛

显式挂载 END 节点与硬性 `recursion_limit`。

9. 持久快照

Checkpointer 保存全量状态，实现崩溃断点续传。

10. 时光旅行

凭 `checkpoint_id` 精确回溯节点与 Fork 假设推演。

11. 蜂群隔离

Supervisor 隔离子 Agent 局部草稿，保护全局 Context。

12. 死锁熔断

结合动作指纹去重与 Token 配额拦截震荡。

13. 物理隔离

不可信代码置于 E2B MicroVM 沙箱，切断外网。

14. 确定性 Harness

拦截写副作用确定性回放，依托 Pass@k 跑分。

15. 可观测治理

无 OpenTelemetry Tracing 与 Evals 绝不上线。

16. 评估驱动演进

以 SWE-bench 与 CI/CD 质量卡扣驱动 Agent 演进。
