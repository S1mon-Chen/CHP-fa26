1. E2B 沙箱测试与 TDD 自愈闭环规约

Ephemeral MicroVM Pytest & Self-Healing Specs

Sandbox Specs
MicroVM Isolation
用后即焚物理隔离 (MicroVM Isolation)： 启动网络封锁 (`network_mode="none"`) 的临时 E2B 容器，只读挂载项目代码并安全应用 Diff 补丁。
Traceback Capture
错误堆栈真实捕获 (Physical Truth Observation)： 捕获 Pytest 吐出的真实 `AssertionError` 与 Traceback 堆栈，剥离环境噪点后打包为结构化反馈。
Reflexion Loop
TDD 驱动自愈重试 (Reflexion Loop & Max Retries)： 若退出码不为 0，将报错 Traceback 灌回 Coder Sub-Graph 发起重修，设定 `retry_count <= 3` 防止死锁。
物理本质：把实际代码运行的报错堆栈转化为无幻觉的客观真相 Observation 驱动纠偏

2. E2B 沙箱单测与自愈 Node 实战代码

Python Capstone E2B Sandbox TDD Node

Python TDD Node
# 生产级 Capstone E2B 沙箱单测与 TDD 自愈节点实现
from e2b_code_interpreter import Sandbox

async def e2b_tdd_sandbox_node(state: CapstoneState) -> dict:
diff_patch = state["current_patch"]
retry_count = state.get("retry_count", 0)

# 1. 在用后即焚的 E2B Ephemeral MicroVM 中应用 Patch 并运行 Pytest
with Sandbox() as sbx:
sbx.files.write("/repo/patch.diff", diff_patch)
sbx.commands.run("cd /repo && patch -p1 < patch.diff")
test_res = sbx.commands.run("cd /repo && pytest")

# 2. 单测成功通过：返回 PASSED 进入下一安全与审察节点
if
test_res.exit_code == 0:
return {"test_status": "PASSED", "traceback": None}

# 3. 单测失败：捕获真实 Traceback，作为 Observation 灌回 Coder 自愈
return {
"test_status": "FAILED",
"traceback": test_res.stderr,
"retry_count": retry_count + 1
}
  • 物理隔离绝对无害：即使生成的代码包含死循环或段错误，仅销毁临时容器，主机零污染。
  • 100% 物理真相驱动：以真实的 Pytest 退出码与错误堆栈为唯一靠山，完全消杀大模型的自我幻觉。
物理本质：把物理沙箱的实际运行结果包装为状态节点，驱动状态机闭环自愈收敛
