Handcrafted Core Subsystems vs Blackbox Frameworks

Core Operators
Blackbox Trap
避免框架黑盒魔改困境： 通用 Agent 框架封装过深，难以支持 IDE 毫秒级增量 AST 刷新、精细 Diff 应用与物理撤销。
Decoupled
纯逻辑算子强解耦： 将 Context 拼接、AST 骨架提纯与 Diff 校验抽象为无依赖的纯 Python/Pydantic 模块。
Reusable
多端零依赖复用： 8 大子系统算子可无缝部署于 VS Code 客户端、FastAPI 异步网关或 CI/CD 质量门控。
物理本质：把 AI Coding 平台的控制力建立在确定性无依赖的子算子之上
