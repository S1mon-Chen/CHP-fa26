1. Capstone 平台四大核心全自治能力维度

Autonomous Coding Agent System Capabilities

Capstone Scope
1. Auto-Triage
工单分诊与代码库范围定位 (Scope Finder)： 监听 GitHub Issue Webhook，结合 Codebase RAG 混合检索与 Tree-sitter AST 精准裁剪上下文。
2. Diff Patch
Unified Diff 补丁生成与内存 AST 验证： 根据 Devin 系统 Prompt 规范输出 ``，应用前通过 `ast.parse()` 断言语法合规性。
3. TDD Healing
E2B 沙箱 TDD 边运行边自愈 (Self-Correction Loop)： 在隔离 MicroVM 中跑 Pytest，将失败 Traceback 转化为 Observation 驱动 Coder 智能体自愈重修。
4. OWASP Gate
OWASP 静态安全卡扣与 GitHub PR 自动合并： 通过 Gitleaks/Semgrep 与 Reviewer 裁判评估，零越界通过后通过 GitHub API 自动 Commit 与 Squash Merge。
物理本质：将 8 门课离散原语演进升级为真正具有生产交付能力的企业级无人值守智能体

2. Capstone 端到端 7 阶自动化重构流水线

7-Stage End-to-End Replay Flow

7 Stages
# Capstone 无人值守自动编程平台执行管道流：
Stage 1: GitHub Webhook Listener (Issue Created / Bug Ticket)
Stage 2: Triage Agent & RAG (Scope Identification & AST Skeleton)
Stage 3: Context Packager (Tiktoken Hard Truncation & XML Tagging)
Stage 4: Coder Sub-Graph (Devin Prompt & Unified Diff Patching)
Stage 5: E2B Sandbox Test (Isolated Pytest & Traceback TDD Loop)
Stage 6: Reviewer & OWASP Audit (Gitleaks + LLM Judge Approval)
Stage 7: GitHub PR Merge (Auto Approve & Squash Merge to Main)
  • 完全透明跟踪：全程输出 OpenTelemetry / LangSmith Spans，便于回溯排查异常。
  • 零生产污染：测试完全限制在用后即焚的 E2B 微沙箱中，保证代码主干绝对安全。
物理本质：把所有离散子系统缝合为一个具有生产发布裁决权的全栈 Agent 管道
