2. MCP 配置文件与系统提示词缝合

mcp_config.json & System Prompt XML

MCP Config
// mcp_config.json：多源 MCP Server 标准接入规范
{
"mcpServers": {
"github": {
"command": "npx",
"args": ["-y", "@modelcontextprotocol/server-github"],
"env": { "GITHUB_PERSONAL_ACCESS_TOKEN": "ghp_xxx" }
},
"postgres": {
"command": "npx",
"args": ["-y", "@modelcontextprotocol/server-postgres", "postgresql://user:pass@localhost/db"]
}
}
}
  • 标准 JSON-RPC 传输：使用 stdio 或 SSE 连接远端 GitHub 与 Postgres MCP 服务，零侵入扩展。
  • System Prompt 边界强化：在 Prompt 中约束只能使用 MCP 暴露的规范工具进行 DB 与 Git 读写。
物理本质：把安全秘钥与物理 API 隔离在 MCP Server 端，仅向 Agent 暴露工具 Schema

Architectural Core Thesis / 架构师视角

不要在 Agent 主框架中硬编码特定工具或数据库接口！通过 System Prompt 定义强类型角色契约（原语一），借助 MCP 协议动态自动拉取并注入工具集（原语二），这是实现企业级系统零耦合、多工具弹性扩展的物理要诀。
