1. 端到端 Trace 句柄透传与 Parent-Child Spans 规约

Trace ID Propagation & OTel Parent-Child Spans

Tracing Specs
Trace ID
全局唯一链路透传 (`trace_id`)： IDE 插件发起 HTTP 请求时注入 `X-Trace-Id`，网关与 Agent 引擎透传至所有子 Spans，保证日志绝对关联。
Parent-Child
父子节点 Span 嵌套关系 (Span Hierarchy)： Root Span 为工单处理，Child Spans 依次捕获 Context 拼接、MCP 工具探测、Coder 补丁生成与 E2B 单测日志。
Prompt Mirror
Prompt 与 Observation 镜像留痕： 100% 记录每一次 LLM 推理入参、System Prompt 版本与沙箱返回的 Traceback，支持秒级故障还原。
物理本质：把 Agent 内部复杂的图状态跳转转换为标准的 OpenTelemetry 树状血缘视图

import os
from opentelemetry import trace
from opentelemetry.sdk.trace import TracerProvider

# 1. 开启 LangSmith 图状态血缘 (Lineage) 自动捕获
os.environ["LANGCHAIN_TRACING_V2"] = "true"
os.environ["LANGCHAIN_API_KEY"] = "ls__secret_key_xxx"
os.environ["LANGCHAIN_PROJECT"] = "prod-ai-coding-platform"

# 2. 挂载 OTel Tracer 透传客户端网关的 trace_id
tracer = trace.get_tracer("ai.coding.gateway")

def execute_agent_with_trace(request_headers: dict, state: dict):
trace_id = request_headers.get("X-Trace-Id", generate_uuid())
with
tracer.start_as_current_span("agent_execution_root") as root_span:
root_span.set_attribute("trace.id", trace_id)
root_span.set_attribute("issue.id", state.get("issue_id"))
return langgraph_app.invoke(state, config={"configurable": {"thread_id": trace_id}})
  • 零无缝强关联：将网关层 `trace_id` 直接作为 LangGraph 的 `thread_id` 映射存盘，实现日志与状态绝对同步。
  • 异构系统统一：不管是 Java 网关还是 Python 图引擎，OTel Span 格式可全量送入 Jaeger/Datadog 分析。
物理本质：把非确定性的图推演过程映射为 OpenTelemetry 标准化链路树
