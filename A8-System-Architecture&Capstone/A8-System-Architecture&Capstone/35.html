1. Coder 子图与 Unified Diff 生成规约

Devin Prompt Contract & AST Memory Assertion Specs

Coder Specs
Devin Contract
Devin 风格系统提示词约束 (System Constraints)： 限制模型把重构思路写在 `<thought>` 节点，代码改动一律收敛于 `<unified_diff>` 标签，禁止闲聊。
Hunk Format
标准 Unified Diff 格式输出： 按 `--- a/path` 与 `+++ b/path` 生成 Hunks 块，避免全量文件覆盖导致的行丢删丢失。
AST Pre-check
内存写前 AST 语法预检 (Syntax Assert)： 通过 `ast.parse()` 在内存中模拟组装 Patch；若发现 SyntaxError，即刻拦截并重新向 Coder 提示修正。
物理本质：把非确定性的 LLM 重构输出转化为强契约、带内存语法校验的代码补丁
