1. Codebase RAG 知识锚定与 Skill 网络缝合

Codebase RAG Context & Skill Pattern Network

Primitives 3 & 4
Fact Anchor
Codebase RAG 事实锚定 (Course 3 原语)： 依托 AST 语法树按类与方法精确切分，结合向量 (Dense) + BM25 (Sparse) 混合检索精准捞出 Top-K 代码碎片，杜绝架构想象。
Skill Pattern

Synergy
双向协同优势： RAG 为 Skill 提供精准的源码上下文与依赖引用，Skill 为 RAG 提供安全的沙箱校验与物理执行反馈。
物理本质：用高精度知识检索充当大模型防幻觉装甲，用 Skill 模式网充当受控物理双手

2. RAG 混合检索与 Skill 路由缝合代码

Codebase Hybrid Search & Skill Pre-check

Python Pipeline
# RAG + Skill 模式网络缝合控制流
async def execute_rag_and_skill_pipeline(query: str, state: AgentState):
# 1. 触发 Codebase RAG 混合检索（AST Chunk + BM25 + Dense Vector）
chunks = await codebase_retriever.hybrid_search(query, top_k=5)
context = package_ast_chunks_into_xml(chunks)

# 2. 意图路由匹配专属 Skill 模式 (Skill Router)
target_skill = skill_router.route(query, context)

# 3. 触发 Skill 前置 Dry-Run 与安全 Guard 检查
is_safe = target_skill.dry_run_precheck(state.patch_draft)
if not is_safe: raise PermissionError("Dry-run check failed")
return await target_skill.execute(context)
  • Zero-Hallucination 事实强绑定：RAG 把真实 AST 代码与版本依赖精准注入给 Skill 模版。
  • Dry-Run 安全防护网：在物理提交代码改动前，Skill 模式网络先强制进行语法编译预演。
物理本质：把 RAG 获取的确定性事实作为输入输入给具身化 Skill 网络
