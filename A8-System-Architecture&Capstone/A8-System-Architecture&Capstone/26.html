自动化失败回放 (Deterministic Failure Replay) 与历史 Fixture 录制

打造零成本、100% 物理复现的线上故障调试防线：在线上 Agent 运行失败时自动捕获 初始 State、E2B 沙箱 Traceback 与 Patch Diff 补丁，录制为静态 Fixture 模版文件，并通过零采样温度与 Side-Effect Mocking 开展本地零扣费回归复现

1. 线上失败快照录制与确定性回放规约

Failure State Capture & Deterministic Replay Specs

Replay Specs
Failure Capture
线上失败现场自动挂钩 (Failure Hook)： 当 E2B 沙箱跑 Pytest 报红或超时（Exit Code != 0）时，自动挂钩抓取初始 Issue、代码基线 SHA、生成 Patch 与报错 Traceback。
Sanitized Fixtures
脱敏静态测试集落盘 (Sanitized Fixture)： 前置剥离线上环境的真实数据库连接串与密钥，转换为只读 `fixture_issue_1042.json` 挂载入代码仓库。
Zero-Cost Debug
本地零扣费调试 (`temperature=0.0`)： 开发者在本地使用固定的 Mock 响应与零随机采样参数秒级重放该 Fixture，不用为了修一个 Bug 重跑全套线上 API。
物理本质：把非确定性的线上生产故障转化为静态确定性可复现的本地单元测试套件

def record_failure_fixture(task_id: str, state: dict, patch: str, traceback: str):

"issue_desc": state.get("issue_desc"),

Architectural Core Thesis / 架构师视角

不要在生产环境盲目靠猜测重试线上故障！通过自动录制失败时的完整初始 State、E2B 沙箱 Traceback 与 Patch Diff 为静态 Fixture 文件，并结合本地零扣费回放机制（temperature=0.0），能为团队构建秒级复现与定位 Fault 的工程调试防线。
