1. 模块一六大架构原语缝合复盘

Module 1 Six Primitives Synthesis

Six Primitives
P1 & P2
System Prompt 规约 + MCP 标准管道： Prompt 定义角色的物理边界，MCP 以 JSON-RPC 动态暴露出远端 DB 与 GitHub 工具集。
P3 & P4
Codebase RAG 知识 + Skill 模式网络： RAG 提供 AST 代码真相排除幻觉，Skill 模式网络进行前置 Dry-Run 语法预演与 HITL 拦截。
P5 & P6
LangGraph DCG 控制流 + E2B 微型沙箱： 状态图驾驭复杂的自愈与重试逻辑，E2B Ephemeral MicroVM 提供绝对的写隔离防线。
物理本质：单点原语是砖石，分层架构是把砖石织合为生产级平台的蓝图

2. 工业级全栈 AI Coding 分层拓扑

Full-Stack Platform Layered Topology

4-Tier System
[Client Layer] VS Code / Terminal CLI Tree-sitter AST & LSP Listener
↓ SSE Stream / JSON-RPC Protocol ↓
[Gateway Layer] FastAPI / Spring Gateway Rate Limit & Task Queue
↓ Async Dispatch & State Checkpoint ↓
[Engine Layer] LangGraph DCG Swarm RAG + MCP + Postgres Checkpointer
↓ Isolated Code Execution ↓
[Sandbox Layer] E2B Ephemeral MicroVMs Pytest Harness & network_mode=none
  • 端到端流畅流式体验：通过网关层的 SSE 管道，将 Agent 节点的重构推理与工具日志实时渲染给客户端。
物理本质：建立在松耦合、强安全与高可用长连接上的工业级平台

System Layering & Integration Decision Matrix / 全栈分层架构与组件集成矩阵

Module 1 Master Matrix
架构层级 / Tier 选型技术栈 / Tech Stack 核心职责 / Primary Role 安全与高可用保障 / Safeguards

网关层 (Gateway) FastAPI / Redis Rate Limiter / SSE Stream 租户鉴权、流量限流、心跳保活与流式推送 异步 Celery 队列隔离长任务阻塞

沙箱层 (Sandbox) E2B Ephemeral MicroVMs / Pytest Harness 只读编译、单测运行、Traceback 收集 `network_mode="none"` 隔离主机风险
