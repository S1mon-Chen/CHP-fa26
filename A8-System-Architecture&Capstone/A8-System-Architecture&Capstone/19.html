子系统 8：人类断点与交互批准 (HITL Terminal Prompt) 控制器

在自主重构与高危变更间建立人类安全最终控制线：手写 HITL 人类打断与审批控制器，当补丁涉及删除文件、修改数据库 Schema 或敏感配置时触发 LangGraph `interrupt()` 原语 异步挂起，并通过 CLI / Slack 交互弹窗收集人类决策后原位恢复与 `update_state` 状态覆写

1. 人类打断 (HITL) 与风险分级规约

LangGraph Interrupts & Risk Level Classification

HITL Specs
Risk Sensor
高危动作前置感应 (Risk Sensor)： 静态扫描 Unified Diff，若包含删除源文件 (`--- a/file`)、修改 `DROP/ALTER TABLE` 或暴露未密化 Secret，自动标记高风险。
Async Interrupt
零资源消耗异步挂起 (`interrupt()`)： 触发 LangGraph 状态持久化快照（Checkpointer），线程与内存完全释放，直至收到外部人类批准信号。
State Override
人类状态强行覆写 (`update_state`)： 人类可批准、驳回或手动修补 Diff 参数后恢复运行，实现真正的“人机混合双轮智能（Hybrid Intelligence）”。
物理本质：将人类意志与责任约束无缝嵌入非确定性 AI 状态流的最关键节点

Architectural Core Thesis / 架构师视角

不要把高危物理变更动作完全托付给非确定性的 AI 决策！通过手写 HITL 人类断点与交互批准控制器，结合状态图的 interrupt() 异步挂起与 update_state() 状态覆写，能为企业级代码自动化重构构建最后一道绝不可逾越的安全防火墙。
