1. SSE 与 WebSocket 架构选型与长连接保障

SSE vs WebSocket Protocols & Gateway HA

Streaming Protocols
SSE (Preferred)
Server-Sent Events (HTTP/2 单向流)： 轻量级标准 HTTP 协议，天然穿越企业防火墙，原生产生 `text/event-stream`，支持基于 `Last-Event-ID` 自动重连，是 AI 补全/Token 推送的首选。
WebSocket
WebSocket (全双工双向长连接)： TCP 握手升级，适合高频双向打断（如推演中途人类发语音/弹窗打断干预），但需要专门的处理连接池与网络保活。
Keep-Alive
心跳保活与 Gateway Nginx 避坑： 设置 `: ping\n\n` 心跳包防超时；Nginx 网关层配置 `proxy_buffering off` 确保流数据零延迟透传。
物理本质：用标准单向 HTTP 流流式吐出微观推演粒度，彻底抹平数十秒等待延时感
