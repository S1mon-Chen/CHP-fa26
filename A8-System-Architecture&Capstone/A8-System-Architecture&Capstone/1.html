单点技术原语阶段 (Primitives Era)

Isolated Atomic Capabilities

Courses 1 - 7
// 单点技术原语如离散砖石：
├── Prompt Engineering (结构化契约)
├── MCP Server & Protocol (上下文与工具管道)
├── Codebase AST RAG (代码索引与混合检索)
├── Skill Pattern Net (路由与 Dry-Run 预演)
└── DCG State Graph (重试与自愈控制流)
  • 缺乏微服务组网：单点原语缺乏统一的高并发网关、鉴权与高可用租户隔离防护。
  • 长连接通信断层：没有长生命周期 SSE / WebSocket 流式推送，IDE 客户端无法实时感知 Agent 思考片段。
物理事实：单点原语是建立建筑的砖石，需要合理的系统架构缝合

生产级 AI Coding 平台 (Platform Era)

Integrated Microservice System Architecture

Course 8 Capstone
// 工业级全栈 AI 辅助编程系统分层拓扑：
Client Layer: VS Code / Terminal CLI (Tree-sitter AST & LSP)
Gateway Layer: FastAPI / Spring Cloud Gateway (SSE / Stream)
Engine Layer: LangGraph / Spring AI Swarm + Postgres Saver
Sandbox Layer: E2B Ephemeral MicroVMs + OpenTelemetry
  • 端到端闭环自愈：从 Issue Webhook 触发 $\to$ 分诊定位 $\to$ Diff 生成 $\to$ 沙箱单测自愈 $\to$ OWASP 审查 $\to$ PR 自动合并。
  • 企业级可观测性与门控：集成 OpenTelemetry 全链路 Tracing、Prometheus 成本看板与 SWE-bench CI/CD Pass@1 质量卡扣。
终局定位：打通端到端自主代码修复、重构与安全审查的全栈编程 Agent 平台
