1. GitHub Actions 质量卡扣与阻断规约

CI/CD Quality Gate & Automated PR Blocking

Gate Specs
Pass@1 Threshold
Pass@1 硬性准确率门槛断言： 在 PR 触发时自动跑基准测试套件；若整体得分低于阈值（如 $Pass@1 < 0.95$），流水线直接退出非零状态码。
Security Gate
OWASP 安全漏洞硬性一票否决： 挂载 Semgrep 静态扫描，一旦发现硬编码 API Key、SQL 注入风险或未鉴权写接口，立即触发一票否决。
Auto Protection
GitHub PR 自动拦截与评论回写： 在 GitHub Branch Protection 开启 `Require status checks to pass`，并自动向 PR 提交包含诊断信息的失败报告。
物理本质：把 Agent 生成质量与代码规范收敛为物理 GitHub CI/CD 关卡中的非零 exit_code
