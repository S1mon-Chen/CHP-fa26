2. Tree-sitter AST 符号提取实战代码

Python Tree-sitter AST Extractor

Python Code
# 使用 Tree-sitter 提取 Python 代码的 Class / Function 符号图
from tree_sitter import Language, Parser

def extract_python_ast_symbols(code_bytes: bytes) -> dict:
# 1. 初始化 Tree-sitter 跨语言解析器
parser = Parser()
PY_LANG = Language('build/my-languages.so', 'python')
parser.set_language(PY_LANG)
tree = parser.parse(code_bytes)

# 2. 编写 AST S-expression 语法查询提取方法与类声明
query = PY_LANG.query("""
(class_definition name: (identifier) @class.name)
(function_definition name: (identifier) @func.name)
""")
captures = query.captures(tree.root_node)
return [node.text.decode('utf8') for node, _ in captures]
  • 毫秒级准实时响应：C 语言底层解析引擎，千行源码解析仅消耗小于 5ms 物理 CPU 时间。
  • 强类型符号边界：为 Codebase Vector DB 检索提供天然根据语法边界切分的 AST Chunks。
物理本质：用标准语法分析器替代大模型粗暴的纯文本按行盲切
