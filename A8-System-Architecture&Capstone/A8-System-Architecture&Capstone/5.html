1. 无状态 Agent 微服务与网关防线

Stateless Agent Microservices & Gateway Defense

Gateway Pattern
Rate Limit
令牌桶频次限流 (Redis Token Bucket)： 在 API 网关层通过 Redis 限制租户调用 QPS 与并发数，杜绝滥用导致后端大模型 Token 账单暴风增长。
Stateless
无状态 Worker 水平缩放 (Auto-scaling)： 将 Agent 逻辑抽象为无状态算子，状态全量托管于 PostgreSQL Checkpointer 与 Redis，支持 K8s HPA 弹性扩容。
Async Queue
异步任务队列解耦 (Celery / RabbitMQ)： 长时推演任务同步返回 `task_id`，避免 HTTP 请求超长连接挂起，支持轮询或 SSE 状态订阅。
物理本质：用高并发流量网关隔绝非确定性 Agent 推演带来的阻塞风险
