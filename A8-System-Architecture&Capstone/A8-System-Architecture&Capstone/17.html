1. E2B 微沙箱执行与 TDD 自愈闭环规约

Ephemeral MicroVM Execution & TDD Self-Correction Specs

Tester Specs
MicroVM Run
用后即焚物理隔离 (MicroVM Isolation)： 调用 `e2b_code_interpreter.Sandbox` 启动只读挂载且切断网络 (`network_mode="none"`) 的硬件级隔离容器。
Traceback Capture
报错堆栈结构化捕获 (Error Observation)： 捕捉 Pytest 抛出的 `AssertionError` 与 Traceback，剔除干扰冗余行后包装为精准的自愈反馈。
Healing Loop
TDD 自愈重试路由 (Test-Driven Reflexion)： 结合状态图条件边，若单测全绿 (`exit_code == 0`) 则流向 Reviewer；若报错则重传给 Coder 重修（最多重试 3 次）。
物理本质：把物理沙箱的真正报错作为绝对无幻觉的物理真相 Observation 灌回模型大脑

2. E2B 沙箱单测与自愈 Node 实战代码

Python Sandboxed Healing Node for LangGraph

Python Code
# 生产级 E2B 沙箱测试与 TDD 自愈节点实现
from e2b_code_interpreter import Sandbox

def sandboxed_testing_node(state: RefactorState) -> dict:
current_diff = state["current_diff"]
retry_count = state.get("retry_count", 0)

# 1. 物理安全隔离：启动用后即焚的 E2B Ephemeral MicroVM 沙箱
with Sandbox() as sbx:
sbx.files.write("/home/user/repo/patch.diff", current_diff)
sbx.commands.run("cd /home/user/repo && patch -p1 < patch.diff")
res = sbx.commands.run("cd /home/user/repo && pytest")

# 2. 单测成功通过：返回 PASSED 进入下一节点
if
res.exit_code == 0:
return {"test_status": "PASSED", "traceback": None}

# 3. 单测失败：捕获报错堆栈并触发 TDD 自动重修自愈回路
return {
"test_status": "FAILED",
"traceback": res.stderr, # 将报错丢给 Coder 自愈！
"retry_count": retry_count + 1
}
  • 崩溃物理屏蔽：即使测试代码引发底层死循环或段错误，仅销毁容器微虚拟机，主进程稳如磐石。
  • 真正的 Pass@1 质量卡扣：不凭大模型自说自话，唯有真正跑通沙箱 Pytest 验证才能进入下一阶段。
物理本质：把测试执行结果包装为状态节点，驱动状态机闭环收敛

Architectural Core Thesis / 架构师视角

不要让模型凭空揣测自己的代码是否正确！通过手写 E2B 沙箱测试节点，把实际运行 Pytest 产生的 Traceback 堆栈包装为客观无幻觉的 Observation 回传给模型大脑，是驱动 AI 智能体实现 TDD 自动边运行边自愈修复的唯一工程通道。
