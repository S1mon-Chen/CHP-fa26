建立生产级 APM 指标测量与成本归因防线：在微服务网关与 Agent 图节点侧嵌入 Prometheus Counter / Histogram 采集器，实时监控 Prompt / Completion Tokens 吞吐、TTFT (首字延迟) 与节点耗时，并通过 Grafana 看板 预防单夜 Token 成本风暴

1. Prometheus 三大核心指标维度与成本归因

Prometheus Metrics Design & Cost Attribution Specs

Metrics Specs
Tokens & USD
Token 吞吐与美元开销 (`Counter`)： 按 `model`、`tenant_id` 与 `token_type` (prompt/completion) 统计总量，按官方单价实时换算美元开销。
TTFT & Latency
TTFT 首字延迟与节点耗时 (`Histogram`)： 测量从请求发出到收到第一个 Token 的 TTFT，以及 RAG、MCP 工具与 E2B 沙箱测试等离散节点的耗时分布 (P95/P99)。
Quota Alert
异常失败率与成本配额报警 (`Gauge`)： 监测单任务成本爆表或图节点死循环，自动通过 Alertmanager 向 PagerDuty/钉钉 发送熔断警报。
物理本质：把非确定性的推演计算转化为工业级 APM 可测量、可报警的流式数据指标

2. Python Prometheus 指标埋点与采集代码

Python Prometheus Metric Collector & Exporter

Python Metrics
# 生产级 Agent 成本与延迟 Prometheus 埋点采集器
from prometheus_client import Counter, Histogram, Gauge

TOKEN_COUNTER = Counter('agent_tokens_total', 'Tokens', ['model', 'type'])
COST_COUNTER = Counter('agent_cost_usd_total', 'Cost USD', ['tenant_id'])
LATENCY_HIST = Histogram('agent_step_duration_seconds', 'Latency', ['node'])

def record_agent_step_metrics(node_name: str, model: str, prompt_toks: int, comp_toks: int, duration: float, tenant: str):
# 1. 累加 Prompt 与 Completion Tokens 计数
TOKEN_COUNTER.labels(model=model, type='prompt').inc(prompt_toks)
TOKEN_COUNTER.labels(model=model, type='completion').inc(comp_toks)
# 2. 计算精准美元消耗并累加
usd_cost = (prompt_toks * 0.0000025) + (comp_toks * 0.00001)
COST_COUNTER.labels(tenant_id=tenant).inc(usd_cost)
# 3. 记录节点耗时直方图分布
LATENCY_HIST.labels(node=node_name).observe(duration)
  • 租户成本精确归因：带上 `tenant_id` 标签，轻松回答“哪个团队/哪个功能昨晚消耗了最多美元”。
  • 标准 `/metrics` 抓取暴露：兼容 FastApi 与 Prometheus Server 的 Scrape 机制，极简拉取。
物理本质：把 Agent 内部计算开销暴露为工业级标准云原生监控指标
