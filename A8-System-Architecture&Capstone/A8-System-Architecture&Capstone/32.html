1. Capstone 平台 6 大核心工程需求矩阵

6 Core Functional & Engineering Requirements

Requirements
1. Webhook
GitHub Issue Webhook 事件实时触发： 监听 `issues.opened` 事件，提取 Issue Number、标题与描述正文发起异步 Task。
2. Scope Finder
Codebase RAG + AST 影响范围定位： 根据 Issue 关键字与混合检索定位关联文件，提取 Tree-sitter Skeleton 压缩上下文。
3. Coder Patch
Devin 风格 Unified Diff 生成与语法断言： 基于契约 Prompt 生成 <unified_diff> 补丁，物理应用前使用 `ast.parse()` 预检。
4. E2B Sandbox
E2B Ephemeral 沙箱单测自愈回路： 在隔离容器中跑 Pytest，捕获 Traceback 驱动 Coder 自检重修（最多重试 3 次）。
5. OWASP Gate
Semgrep / Gitleaks 安全拦截卡扣： 审查 Patch 中的秘钥泄漏与 SQL 注入，发现漏洞后一票否决并指示自愈。
6. Auto PR
GitHub API 自动 Approve & Squash Merge： 校验 100% 全绿通过后，通过 GitHub REST API 自动提交 PR 并完成 Squash 物理合并。
物理本质：把生产级代码修改流程转化为清晰、可验证、带卡扣的 6 大系统需求

2. Capstone 端到端 Master 架构控制流

End-to-End Execution Topology & Graph Flow

Master Flow
# Capstone 无人值守 Agent 控制流节点拓扑：
[1. GitHub Webhook] ──POST──► [2. Triage Agent]
└─► Codebase RAG & Tree-sitter Skeleton Extraction
└─► [3. Coder Agent Sub-Graph] (Devin Prompt)
└─► [4. E2B Sandbox Test Node]
├─► [Pytest Failed] ──► Observation Traceback ──► Loop back to [3] (Max 3)
└─► [Pytest Passed] ──► [5. Reviewer & OWASP Scan]
└─► [APPROVED] ──► [6. GitHub API Auto Squash Merge] ──► END
  • 自愈重修环路 (TDD Reflexion Loop)：测试失败时 Traceback 作为 Observation 灌回 Coder Node，实现真正的自动修补。
  • 多门控安全拦截：语法校验 + E2B 沙箱测试 + Gitleaks 秘钥扫描 + LLM 裁判共识，4 重安全卡扣护航。
物理本质：把前 7 课积累的所有原语与手写子系统串联为严密的状态图架构
