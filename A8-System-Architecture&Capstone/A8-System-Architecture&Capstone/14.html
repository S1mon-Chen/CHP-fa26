1. MCP 桥接协议与动态工具节点转译

MCP Stdio/SSE Pipe & Dynamic Tool Translation

MCP Specs
Stdio / SSE
双模进程/网络通信管道： 支持基于标准输入输出 (`stdio`) 拉起本地子进程，或通过 `SSE` 连接远程部署的第三方 MCP 服务。
Discovery
动态能力探查 (`list_tools`)： 发送 JSON-RPC 初始化请求后自动广播探查，动态拉取 Server 暴露的所有 Tools、Resources 与 Prompts。
Schema Trans
Schema 自动转译与节点注册： 将 MCP 的 JSON-RPC Tool Schema 自动无缝映射转译为 LangGraph / Spring AI 引擎的原生可调算子。
物理本质：把物理环境中繁杂的扩展接口归一化为标准的 JSON-RPC 消息响应管道
