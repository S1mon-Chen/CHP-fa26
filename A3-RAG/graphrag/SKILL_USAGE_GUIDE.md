# Vibe Project Generator 使用指南

本文档介绍如何与大模型交互，以触发 **Vibe Project Generator** Skill 自动生成项目。

---

## 一、什么是 Vibe Project Generator

**Vibe Project Generator** 是一个 AI Skill，它能够根据用户的自然语言描述，自动生成完整的、可运行的项目结构。

**技能位置**：`.trae/skills/vibe-project-generator/SKILL.md`

**核心能力**：
- 理解项目需求
- 设计项目结构
- 生成完整代码
- 创建配置文件
- 编写启动脚本
- 生成使用文档

---

## 二、触发 Skill 的方式

### 方式一：描述项目需求（推荐）

直接用自然语言描述你想要的项目，大模型会自动识别并调用 Skill。

**示例**：

```
"我想开发一个GraphRAG的教学案例，使用Neo4j作为后端存储"
```

```
"创建一个基于Ollama的本地RAG系统"
```

```
"开发一个能够对比RAG和GraphRAG的演示系统，包括前端界面"
```

---

### 方式二：提供代码片段

给大模型一段代码，让它生成完整项目。

**示例**：

```
"根据以下代码片段，生成一个完整的可运行程序：

[粘贴你的代码片段]
"
```

---

### 方式三：指定技术栈

明确说明要使用的技术，大模型会据此生成合适的项目结构。

**示例**：

```
"用Flask + Neo4j + Ollama创建一个知识图谱问答系统"
```

```
"开发一个React前端的Python后端项目"
```

---

### 方式四：描述使用场景

说明你的具体使用场景，让大模型推荐合适的方案。

**示例**：

```
"我需要创建一个教学演示用的知识图谱系统"
```

```
"为公司内部创建一个技术调研的原型"
```

## 七、Skill 的能力边界

### ✅ 可以生成

- 完整的项目结构
- 可运行的代码（含错误处理）
- 依赖配置文件（requirements.txt / package.json）
- 启动/停止脚本
- README 使用文档
- 基础的测试用例
- 配置文件（config.py 等）

### ❌ 无法保证

- 100% 代码正确性（需人工验证）
- 复杂架构的自动设计（需要更多指导）
- 特定业务逻辑的完整性
- 第三方服务的可用性

### 💡 当不确定时

大模型会主动询问：

- 技术栈偏好
- 具体功能需求
- 项目规模预期
- 部署环境要求

## 八、最佳实践

### 1. 从简单开始

```
❌ "创建一个像Facebook一样的社交平台"

✅ "创建一个命令行社交网络原型"
```

### 2. 提供上下文

```
❌ "创建一个博客系统"

✅ "创建一个面向技术博主的博客系统，使用Markdown存储"
```

### 3. 迭代完善

```
第一步: "创建一个基本的Flask API"
第二步: "添加用户认证功能"
第三步: "添加分页支持"
```

### 4. 明确验收标准

```
"这个系统需要能够：
1. 处理1000个并发请求
2. 支持用户登录
3. 数据持久化到PostgreSQL"
```
