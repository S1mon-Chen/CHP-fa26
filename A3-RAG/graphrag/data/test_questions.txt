# GraphRAG vs RAG 对比测试问题集

本文件收集了各类问题，用于演示 GraphRAG 与普通 RAG 在能力上的区别。

## 1. 关系推理问题（多跳推理）

这类问题最能体现 GraphRAG 的优势，需要通过多个实体之间的关系链条来推导答案。

### 1.1 家族/社交关系推理
- "张三和谷歌公司有什么关系？"
  - 答案路径：张三 → 父亲 → 李四 → 工作单位 → 谷歌公司

- "张三和王五之间有联系吗？"
  - 答案路径：张三 → 父亲 → 李四 → 工作单位 → 谷歌公司，王五 → 工作单位 → 谷歌公司

- "谁是苹果公司的CEO的家人？"
  - 需要先找到CEO（蒂姆·库克），再查找其家庭关系

### 1.2 公司/组织关系推理
- "苹果公司和史蒂夫·乔布斯是什么关系？"
  - 答案路径：苹果公司 → 创始人 → 史蒂夫·乔布斯

- "谷歌公司和人工智能技术有什么联系？"
  - 答案路径：王五 → 提倡 → 人工智能技术，王五 → 工作单位 → 谷歌公司

- "库克和谷歌公司有关系吗？"
  - 需要判断苹果公司CEO（蒂姆·库克）与谷歌公司是否存在关联路径


## 2. 路径查找问题

需要找到实体之间的关联路径。

- "从史蒂夫·乔布斯到苹果公司，中间经历了什么？"
  - 路径：史蒂夫·乔布斯 → 创始人 → 苹果公司

- "张三是如何与谷歌公司产生联系的？"
  - 路径：张三 → 父亲 → 李四 → 工作单位 → 谷歌公司

- "苹果公司和谷歌公司有什么共同点？"
  - 可能路径：两家公司都是科技公司，都位于美国加州，可能有共同的管理人员或合作关系


## 3. 属性查询问题

查询实体的特定属性。

### 3.1 简单属性查询（两者都能回答）
- "张三的职业是什么？"
- "苹果公司位于哪里？"
- "谁提倡人工智能技术？"
- "谷歌公司的CEO是谁？"

### 3.2 复杂属性查询
- "李四的职业技能是什么？"
  - 需要通过：李四 → 工作单位 → 谷歌公司，结合张三 → 李四的关系来推理

- "王五除了担任CEO外，还有什么成就？"
  - 需要检索多个相关实体的属性


## 4. 聚合统计问题

需要统计实体数量或关系数量。

- "我们有多少个实体？"
- "有多少人在科技公司工作？"
- "苹果公司涉及哪些关系类型？"
- "图中有多少条边？"


## 5. 开放式问题

涉及多个实体的综合分析。

- "蒂姆·库克的背景是什么？"
- "谷歌公司是一家什么样的公司？"
- "苹果公司的发展历程是怎样的？"
- "人工智能技术在当今社会的地位如何？"


## 6. 推理验证问题

验证图谱中的推理是否正确。

- "如果李四在谷歌工作，而张三是李四的父亲，那么张三和谷歌公司是什么关系？"
- "根据图谱信息，王五和苹果公司有关系吗？"
- "史蒂夫·乔布斯和蒂姆·库克都在苹果公司工作，他们之间有什么联系？"


## 推荐测试流程

### 步骤1：基础导入
导入以下示例数据到系统：
```
张三是李四的父亲，李四在谷歌公司工作。张三是一名的士司机。
王五是谷歌公司的CEO，他提倡人工智能技术。
谷歌公司位于美国加州山景城。
苹果公司是一家总部位于美国加州库比蒂诺的科技公司。
蒂姆·库克是苹果公司的CEO。
史蒂夫·乔布斯是苹果公司的创始人。
中国市场是苹果公司最重要的市场之一。
```

### 步骤2：对比测试
按以下顺序提问，观察两种系统的回答差异：

1. **简单问题**（两者都能答对）：
   - "苹果公司位于哪里？"
   - "谁提倡人工智能技术？"

2. **关系问题**（GraphRAG更优）：
   - "张三和谷歌公司有什么关系？"
   - "苹果公司和库克是什么关系？"

3. **路径问题**（只有GraphRAG能回答）：
   - "从张三到谷歌公司，中间经历了什么？"
   - "史蒂夫·乔布斯到苹果公司CEO之间有什么关系？"

4. **复杂问题**（测试综合能力）：
   - "如果李四在谷歌工作，而张三是李四的父亲，那么张三和谷歌公司是什么关系？"


## 预期结果对比

| 问题类型 | 普通RAG | GraphRAG |
|---------|---------|----------|
| 简单属性查询 | ✅ 准确 | ✅ 准确 |
| 直接关系查询 | ⚠️ 可能遗漏 | ✅ 准确 |
| 多跳关系推理 | ❌ 无法回答 | ✅ 准确 |
| 路径查找 | ❌ 无法回答 | ✅ 准确展示 |
| 聚合统计 | ❌ 困难 | ✅ 支持 |


## 注意事项

1. **知识图谱质量**：三元组提取的准确性直接影响 GraphRAG 的效果
2. **实体名称匹配**：模糊匹配已实现，但可能仍有边界情况
3. **跳数限制**：当前配置支持最多2跳推理，更深的路径需要调整参数
4. **RAG索引构建**：确保RAG和GraphRAG使用相同的数据源
