核心算法：滑动窗口文本切块 (Chunking)

从物理切分到语义对齐：构建大模型可感知的知识颗粒

为什么要切块？

  • ● 上下文窗口限制： LLM 的输入有硬上限（Context Window），无法一次喂入全量文档。
  • ● 避免“中间迷失”： 资料过长时，LLM 会忽略输入中间的核心线索。

滑动窗口原理

Chunk Size (块大小) 定义分片长度
Chunk Overlap (重叠度) 保证相邻块语义衔接

def sliding_window_chunker(text: str, chunk_size: int, overlap: int) -> list[str]:
    chunks = []
    start = 0
    
    while start < len(text):
        end = start + chunk_size
        chunk = text[start:end]
        chunks.append(chunk)
        
        # 核心逻辑：移动步长 = 块大小 - 重叠大小
        start += (chunk_size - overlap)
        
        # 防死循环边界检查
        if start >= len(text) or chunk_size <= overlap:
            break
            
    return chunks
工程思维： 滑动步长 Stride = chunk_size - overlap 是切片的核心秘密。Overlap 作为“语义胶水”，能够确保跨物理切片边界的专有名词或语义线索不会因生硬裁剪而丢失，极大地保障了后续检索的召回连续性。
