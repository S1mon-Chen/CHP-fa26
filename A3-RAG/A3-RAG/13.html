高级 RAG 演进架构：三阶段治理

1. Pre-Retrieval (检索前)

治水先治源

使命要义： 重点在数据送入向量索引引擎之前，解决由于用户口语化表达、错字或技术概念模糊导致的“第一层偏离”。

典型算法手段： Query Rewrite（查询改写）、 HyDE（假设性文档嵌入）、 智能 Query 路由。

2. Retrieval (检索中)

多维提广度

使命要义： 摒弃单一向量数据库暴力临近检索的硬伤，确保在大规模数据集中捞取到完整、不失真且带有强字面匹配性的潜在段落。

典型算法手段： Dense + Sparse 混合检索、 BM25 字面匹配、 向量元数据多租户过滤。

3. Post-Retrieval (检索后)

提纯防迷失

使命要义： 针对捞回的多路海量文档片段进行无情瘦身与提纯，彻底破解大模型“中间迷失（Lost in the middle）”的阅读理解盲区。

典型算法手段： Cross-Encoder 重排序、 LLMLingua（提示词上下文压缩）、 动态切片分值重筛。

架构演进共识： 高级 RAG 的本质是从单纯的物理搬运数据转向主动的数据周期治理。在这三个环节中运用适当的重排序和改写算法，能够让 RAG 系统整体召回率与准确性指标（Ragas 指标）获得成倍的数学提升，是工业级生产落地不可逾越的护城河。
