检索后优化：交叉编码器重排序 (Cross-Encoder Re-ranking)

Bi-Encoder vs Cross-Encoder Attention Mechanics
The Two-Stage Retrieval Funnel
  • ● 第一阶段：粗筛 (Bi-Encoder)：利用快速的向量内积（O(1) 复杂度），从百万量级的文档中秒级打分筛选出 Top-50 候选切块。
  • ● 第二阶段：精排 (Cross-Encoder)：将这 50 个切块与提问两两配对，输入精排模型，利用注意力矩阵进行全方位语义对齐计算，精选出纯度最高的 Top-5 投喂大模型。
re_ranker.py 
from transformers import AutoModelForSequenceClassification, AutoTokenizer
import torch

tokenizer = AutoTokenizer.from_pretrained("BAAI/bge-reranker-large")
model = AutoModelForSequenceClassification.from_pretrained("BAAI/bge-reranker-large")

def re_rank(query: str, docs: list[str]) -> list[tuple[str, float]]:
    pairs = [[query, doc] for doc in docs]
    with torch.no_grad():
        inputs = tokenizer(pairs, padding=True, truncation=True, return_tensors='pt', max_length=512)
        # 交叉注意力打分，输出单维度相关性极高、量纲对齐的 logits 分值
        scores = model(**inputs).logits.view(-1).tolist()
    return sorted(zip(docs, scores), key=lambda x: x[1], reverse=True)
业界共识 (没有 Re-ranker 就不要上线生产)： 双塔模型将 Query 和 Doc 隔离表征成静态向量，导致词与词之间的注意力（Token-level Cross Attention）交互完全丢失。而交叉编码器（Cross-Encoder）允许问题和分块中的每个单词在高维度多头注意力矩阵中全双工交叉对齐。在真正的 RAG 系统设计中，“双塔检索粗筛 + 单塔精排重塑”是公认能够平衡算力耗时和绝对精准度的黄金设计。
