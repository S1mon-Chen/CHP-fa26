极简 RAG 后端：20行代码跑通全管道

Educational Goal

用不超过 20 行的纯 Python 代码实现端到端 RAG 极简原型，帮助学生在宏观上掌握数据在全管道中的流动过程。

Pipeline Workflow
  • 1. 语义检索 (Retrieve)：计算提问向量并查询最相关的 1 个参考切片（top_k=1）。
  • 2. 上下文组装 (Augment)：利用 Python 格式化字符串进行 Prompt 拼接约束。
  • 3. 本地模型调用 (Generate)：调用 Ollama 接口驱动本地推理，输出精准答复。
naive_rag_pipeline.py 
# 假设已经初始化好了 db
query = "什么是向量数据库的 HNSW 算法？"
q_vector = get_ollama_embedding(query)
results = db.query(q_vector, top_k=1)

# 1. 上下文拼装 (Context Augmentation)
context = results[0]["meta"]["text"]
prompt = f"请严格根据以下参考资料回答问题：\\n【资料】：{context}\\n【问题】：{query}"

# 2. 调用大模型生成响应 (LLM Generation)
llm_response = requests.post(
    "http://localhost:11434/api/generate", 
    json={
        "model": "llama3", 
        "prompt": prompt, 
        "stream": False
    }
).json()

print(llm_response["response"])
Naïve RAG 的脆弱硬伤： 这种极简链路在生产环境中极其脆弱。一旦检索召回了低质量或跑题的切块（例如 top_k=1 匹配失败），不相关的数据就会严重“污染” Context。大模型在垃圾输入的误导下，仍会强行输出极具迷惑性的幻觉事实。
