1. 文档源 PDF / Markdown

4. 向量化 Embedding Extraction

在线流程 检索与生成管道 (Retrieval & Generation Pipeline)
1. 用户提问
2. 提问向量化
3. 相似度检索
4. 上下文组装
5. LLM 生成
6. 最终响应
软件工程的核心演进：六大抽象组件解耦
1. 解析器 (Parser)

消除不同格式文档物理结构差异（PDF、Docx、HTML统一化）

2. 切分器 (Splitter)

定义物理分段策略（Token、语义切分），维护切片重叠边界

3. 向量模型 (Embedder)

提供高维语义特征空间转换（如 BGE、OpenAI-Embedding）

4. 向量库 (Vector DB)

底层数据的向量近似检索核心（Qdrant、Milvus 的标准抽象）

5. 路由器 (Router)

负责控制提问流向，自主判定是否启用检索或分流至特定库

6. LLM 驱动 (Driver)

提供各大模型的标准连接通道与结构化输出接口（如 LangChain/LlamaIndex）
