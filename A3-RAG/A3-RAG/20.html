知识图谱增强：GraphRAG (进阶架构)

The Achilles' Heel of Local Vector Search

传统检索死角：当用户问“总结这两家公司在过去三年里所有的合作项目”时，由于线索零散分布在几十个异构文件里，局部相似度检索会产生漏检，无法在宏观上拼装信息网络。

GraphRAG Paradigm Shift
  • ● 图谱关系抽取：利用大模型离线扫描，提前识别并抽取文档里的 实体 (Entity) 与 关系 (Relationship)，构建相互交织的语义知识图谱。
  • ● 社区发现聚合：采用社区发现算法（如 Leiden）对图谱进行区域层级划分，利用 LLM 对子社区预先提炼摘要报告，从根本上解决非局部归纳问题。

def graph_rag_global_search(query: str, level: int = 2) -> str:
    # 1. 识别并提取查询中提及的核心概念实体 (Entities)
    target_entities = extract_query_entities(query)
    
    # 2. 定位包含这些实体关系的拓扑子图社区 (Leiden Communities)
    communities = kg_index.get_matched_communities(target_entities, level=level)
    
    # 3. 遍历提取目标社区在离线阶段由 LLM 聚合好的“章节综述报告”
    community_summaries = []
    for comm in communities:
        report = kg_index.get_community_report(comm)
        community_summaries.append(report)
        
    # 4. 合并多路报告拼装 Context，驱动 LLM 进行全局宏观归纳
    prompt = f"请整合以下子社区综述回答：\\n{community_summaries}\\n提问：{query}"
    return call_llm(prompt)
工程实践价值： 微软提出的 GraphRAG 并非完全摒弃向量，而是将“图模型”与“向量语义”在数据级实现深度咬合。在面对跨源全局性问题时，传统的 Top-K 细粒度搜索会由于缺乏宏观视图而答非所问；利用 图拓扑提取 + 预编译社区摘要报告，能够在完全不超出输入 Token 上限的前提下，轻松建立具备超强宏观全局归纳的企业级高智商 RAG 服务。
