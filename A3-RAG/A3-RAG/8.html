ollama_embedding.py 
import requests


def get_ollama_embedding(text: str, model: str = "bge-m3") -> list[float]:
    url = "http://localhost:11434/api/embeddings"
    payload = {
        "model": model,
        "prompt": text
    }
    
    res = requests.post(url, json=payload).json()
    return res["embedding"]
架构师视角： Embedding 模型决定了 RAG 系统的“理解深度”。本地部署 Ollama 提供 API 接口是保证数据隐私与零成本调用的最佳工程实践，BGE 系列模型目前是中文社区的首选。
