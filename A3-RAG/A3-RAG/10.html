HNSW Multi-Layer Search Routing
qdrant_hnsw_tune.py 
from qdrant_client import QdrantClient
from qdrant_client.models import VectorParams, Distance, HnswConfigDiff

client = QdrantClient(url="http://localhost:6333")
client.create_collection(
    collection_name="enterprise_knowledge",
    vectors_config=VectorParams(size=1536, distance=Distance.COSINE),
    # 高吞吐 HNSW 拓扑图索引调优配置
    hnsw_config=HnswConfigDiff(
        m=16,             # 每个节点的底层最大连接数 (拓扑图宽度)
        ef_construct=128,  # 索引构建时的搜索深度 (越大图质量越高)
        full_scan_threshold=10000 # 数据量低于此值时强制走全内存暴搜
    )
)
HNSW 算法精髓（类似多维跳表）： 检索复杂度仅为 O(log N)。在建索引时调大 m 与 ef_construct 能有效提高检索召回率（Recall），但会成比例增加建图内存开销与耗时。这是软件工程在**时间与空间**维度的又一次经典权衡。
