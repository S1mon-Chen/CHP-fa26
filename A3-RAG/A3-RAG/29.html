自反思架构 (Self-RAG / Corrective RAG) 的工程闭环

Vibe Ingestion: Blind Faith Generation

生成前缺乏审计与纠偏：静态 RAG 的检索是不加验证地全部塞进 Prompt。如果向量相似度召回的都是无关的噪声干扰，大模型会强行依靠这些垃圾信息生成错误的“一本正经瞎编”的幻觉，导致生成端对端质量不可控。

Active Self-Correction Closed-Loop
  • ● 大模型变身“阅卷官” (Evaluator)：召回切片后，先启动轻量模型评估每个 Chunk 的相关置信度评分（“完全相关”、“部分相关”、“垃圾废话”）。
  • ● 搜索引擎动态补救 (Corrective)：一旦判定所有召回切片均无有效事实支撑，立刻触发 Tool Call 驱动外部搜索引擎（如 Tavily）在线抓取最新事实完成证据链重构。
  • ● 双端事实一致性自纠错：初稿成文后，大模型再次自我审查：“我生成的答案是否能在刚才保留的 Context 证据中被安全推导？”未通过则立刻退回重新生成。

def corrective_rag_flow(query: str) -> str:
    # 1. 向量检索与质量自评估过滤
    chunks = db.query(query, top_k=3)
    valid_chunks = [c for c in chunks if eval_relevance(query, c) >= 0.7]
    
    # 2. 触发主动补救：若相关性不足则调用大网搜索补货
    if not valid_chunks:
        valid_chunks = google_search_api(query)
        
    # 3. 驱动大模型生成初稿
    draft = generate_answer(query, valid_chunks)
    
    # 4. 幻觉自审：比对初稿与上下文，若有捏造则退回重构纠偏
    if check_hallucination(draft, valid_chunks):
        draft = regenerate_and_debias(query, valid_chunks)
    return draft
自反思闭环控制论 (Closed-Loop Quality Control)： 自反思架构（CRAG / Self-RAG）是解决生产系统不确定性的关键跃迁。传统的 RAG 是“无条件信任检索”的开环系统，其最终生成质量完全向检索效果低头。通过引入**阅卷评估、备用网络检索补救、以及幻觉自检反思重写**的工程闭环，大模型具备了在运行时进行自我容错与纠偏的能力，能将真实业务中失控的幻觉发生概率逼近归零。
