多路召回合并算法：倒数排名融合 (RRF)

The Dimensionality Barrier

数值不对称的合并痛点：向量匹配返回相似度余弦值（如 0.85），而 BM25 返回原生词频统计原始分（如 12.4）。量纲与标尺完全失真，根本无法直接相加排序。

RRF Mathematical Premise

倒数排名融合算法（Reciprocal Rank Fusion）：抛弃绝对分值，仅仅评估文档在两条异构路径中的相对排名顺序：

RRF_Score ( d ) = ∑ m ∈ M 1 k + r m ( d )

* 其中 r_m(d) 为文档 d 在第 m 路检索结果中的自然名次，k 为平滑常数（业界一般设为 60）。

reciprocal_rank_fusion.py 
def rrf(vector_results: list, bm25_results: list, k: int = 60) -> list:
    rrf_scores = {}
    
    # 1. 累加计算向量检索路径的倒数相对位次 score
    for rank, doc_id in enumerate(vector_results):
        rrf_scores[doc_id] = rrf_scores.get(doc_id, 0.0) + 1.0 / (k + (rank + 1))
    
    # 2. 累加合并关键词检索路径的倒数相对位次 score
    for rank, doc_id in enumerate(bm25_results):
        rrf_scores[doc_id] = rrf_scores.get(doc_id, 0.0) + 1.0 / (k + (rank + 1))
        
    # 3. 根据倒数位次累加和进行全局降序重排
    sorted_docs = sorted(rrf_scores.items(), key=lambda x: x[1], reverse=True)
    return sorted_docs
工程常数 k=60 的数学哲学： 引入常数 k 是为了极大程度地缓和“高位名次对整体总分产生的恶性统治力”。如果没有 k（即 k=0），那么第一名（1/1 = 1.0）的分量将是第三名（1/3 ≈ 0.33）的三倍。而当设定 k=60 时，第 1 名（1/61）与第 3 名（1/63）的分值趋于相对平滑，极大地保护了长尾匹配的参考连续度。
