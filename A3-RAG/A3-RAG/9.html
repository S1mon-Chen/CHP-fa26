手写一个内存版向量数据库 (TinyVectorDB)

Educational Goal

通过徒手编码，透视工业级向量数据库在原子底层的操作本质。

Key Logic Steps
  • 1. 使用 NumPy 矩阵化处理查询，实现底层加速计算。
  • 2. 线性暴搜 (Linear Scan)：遍历内存，两两计算高维余弦相似度。
  • 3. 降序提取 Top-K：利用索引变换直接输出最相似的文本片段。
tiny_vector_db.py 
import numpy as np

class TinyVectorDB:
    def __init__(self):
        self.vectors = []
        self.metadata = []
    def insert(self, vector: list[float], meta: dict):
        self.vectors.append(vector)
        self.metadata.append(meta)
    def query(self, query_vector: list[float], top_k: int = 2) -> list[dict]:
        q_v = np.array(query_vector)
        scores = []
        for v in self.vectors:
            idx_v = np.array(v)
            # 计算余弦相似度
            dot_product = np.dot(q_v, idx_v)
            norm_q = np.linalg.norm(q_v)
            norm_v = np.linalg.norm(idx_v)
            cosine_score = dot_product / (norm_q * norm_v)
            scores.append(cosine_score)
        top_indices = np.argsort(scores)[::-1][:top_k]
        return [{"meta": self.metadata[i], "score": scores[i]} for i in top_indices]
软件工程警示： TinyVectorDB 的检索复杂度为 O(N)。面对千万级的大规模生产数据，线性扫描将导致系统响应彻底瘫痪，这正是工业界需要引入 HNSW（分层导航小世界图） 等近似最近邻 (ANN) 索引算法的根本原因。
