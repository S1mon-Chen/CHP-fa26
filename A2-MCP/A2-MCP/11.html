协议生命周期与协商

Host 与 Server 从握手到下线的标准化交互序列

握手与能力协商

在 initialize 阶段，双方交换 Capabilities。通过版本协商确保协议兼容性，这是建立信任的关键。

正常运行与优雅退出

协商完成后进入 Normal Operation。最后通过 shutdown 命令进行优雅下线，确保资源回收与状态持久化。

1. initialize
协商期：交换协议版本，同步双方 Capabilities (能力集)。
↓
2. initialized
就绪期：Server 确认配置完成，Host 准备发送业务请求。
↓
3. Normal Operation
运行期：执行 Tools 调用、Resources 访问及 Prompts 生成。
↓
4. shutdown
关闭期：Host 通知 Server 停止接收新请求，开始清理资源。
↓
5. exit
退出期：Server 进程彻底终止，STDIO 管道关闭。
