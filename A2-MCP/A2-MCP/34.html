部署模式：Java 原生进程加载

将 Spring Boot 应用打包为独立执行文件，通过标准 STDIO 实现跨平台挂载

独立可执行打包 (Fat Jar)

利用 Spring Boot 构建插件，将业务逻辑、MCP 协议栈以及所有内嵌依赖打包为单一的 .jar 文件，极大简化了部署与分发流程。

Host 原生唤起

宿主客户端（如 Claude Desktop）无需复杂的容器环境配置，只要系统具备 Java 运行环境 (JRE)，即可直接通过原生命令启动 Server 进程并建立长连接。

终端编译 & Host 配置示例 
// 1. 在项目根目录执行 Maven 打包命令
$ mvn clean package -DskipTests
# 构建成功后生成 target/se-mcp.jar


// 2. MCP Host (如 Claude Desktop) 的配置文件示例
{
  "mcpServers": {
    "spring-se-scanner": {
      "command": "java",
      "args": [
        "-jar",
        "/absolute/path/to/target/se-mcp.jar"
      ]
    }
  }
}
