基于 JSON-RPC 2.0 的消息格式

MCP 协议的标准消息交互规范，定义了请求与响应的强类型协议格式

JSON-RPC 2.0 规范

MCP 选择 JSON-RPC 2.0 作为消息传输载体，确保了跨语言互操作性。每个消息包含 jsonrpc 版本、id (用于异步响应匹配)、method (调用函数名) 以及可选的 params 或 result。

设计要点

通过这种强结构化的序列化格式，Host 与 Server 能够解耦地进行工具发现、资源拉取与 Prompt 交互，实现了标准的请求-响应生命周期。

Request Example 
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "get_weather",
    "arguments": { "city": "San Francisco" }
  }
}
Response Example 
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "content": [{ "type": "text", "text": "72°F and sunny" }]
  }
}
