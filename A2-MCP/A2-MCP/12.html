错误处理规范 (代码级)

遵循 JSON-RPC 2.0 标准错误体系，构建确定性强的企业级错误反馈机制

JSON-RPC 2.0 标准错误码

代码 含义 描述
-32700 解析错误 服务端接收到无效 JSON，解析失败
-32600 无效请求 发送的 JSON 不是有效的请求对象
-32601 方法未找到 请求的方法不存在或当前不可用
-32602 参数无效 方法参数语义错误或格式不匹配
-32603 内部错误 服务端内部异常，非请求本身导致
-32xxx 服务端错误 -32000 到 -32099 预留用于自定义错误

错误响应设计要点

在 data 字段中提供具体上下文（如必填字段缺失说明），不仅能辅助人工调试，更能让 LLM 感知异常原因并尝试自愈 (Self-Correction)。

Error_Response_Example.json 
{
  "jsonrpc": "2.0",
  "id": 1,
  "error": {
    "code": -32602,
    "message": "Invalid params",
    "data": "City parameter is required."
  }
}
