Tools 的副作用管理与人工审批

Human-in-the-loop: 为敏感写操作建立确定性的安全审查防线

软件工程风险控制

对于涉及 写操作、敏感数据修改或外部服务调用 的 Tool，完全自动化即意味着失控。Host 必须在调用链中强制引入人工审批环节。

审批与可观测性

通过配置 Approval Flag，Host 能够在 LLM 发起调用前，向用户弹窗确认意图与变更内容，确保每一项高危操作都在受控范围内。

mcp_tool_approval.py 
// 在 Host 端为敏感 Tool 配置审批开关

@mcp.tool(requires_approval=True)
def delete_database_record(record_id: int):
    """高危操作: 物理删除记录"""
    return "Deleted successfully."
