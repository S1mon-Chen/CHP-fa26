实现 Tools：装饰器与类型检查

利用现代 Python 类型系统实现协议层与业务逻辑的自动化封装

类型驱动开发 (TDD)

FastMCP 利用 Python 的 Type Hints 机制，在代码编写阶段即定义了接口的边界。这使得开发过程高度直观且减少了配置误差。

自动化 Schema 生成

集成 Pydantic 模型，通过 Field 显式定义参数说明。Server 会自动将其转换为符合 JSON Schema 标准的工具描述供 LLM 理解。

risk_calculator.py 
from pydantic import Field


# 显式定义参数 Schema，自动生成模型可理解的描述
@mcp.tool()
def calculate_risk(
    project_id: str = Field(..., description="Unique ID of the project"),
    budget: float = Field(0.0, description="Project budget")
) -> str:
    """Calculates project risk based on budget."""
    risk = "High" if budget < 10000 else "Low"
    return f"Project {project_id} has {risk} risk."
