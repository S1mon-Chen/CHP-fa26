安全性与权限沙箱

在本地 STDIO 模式下，确立显式的权限限制以防御潜在风险

⚠️

风险模型分析

在 STDIO 传输模式下，MCP Server 进程直接以宿主用户权限运行。这意味着如果没有防御，Server 可能拥有读取用户所有敏感文件（如 ~/.ssh）的能力。

工程安全最佳实践

将 Server 视为“默认不可信”。开发者必须在代码逻辑中实施显式的路径过滤 (Path Filtering) 和操作范围限制，仅暴露应用所需的绝对最小权限。

Security_Sandbox_Example.py 
import os


// ⚠️ 不安全代码：允许访问任意路径
// open(file_path).read()

// ✅ 安全沙箱实现：路径强制受限
ALLOWED_BASE_DIR = "/home/user/project/data"


def read_safe(file_name):
    target_path = os.path.join(ALLOWED_BASE_DIR, file_name)

    // 1. 验证路径是否真的在沙箱内
    if not target_path.startswith(ALLOWED_BASE_DIR):
        raise PermissionError("Access Denied!")

    return open(target_path, "r").read()
