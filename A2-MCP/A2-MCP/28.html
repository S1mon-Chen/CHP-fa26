MCP Server 的单元测试方法

确保工具与资源在受控的 I/O 环境下，满足 JSON-RPC 2.0 协议标准

自动化测试要求

在软件工程交付中，MCP Server 必须编写自动化测试。这不仅验证核心逻辑的正确性，更是确保在协议版本升级时系统不会产生回归 (Regression)。

Mock 传输层方法

最工程化的方法是 Mock 输入流(stdin)和输出流(stdout)。通过在内存内交换协议消息，实现 零依赖、无 Network 的并发协议测试。

tests/test_server.py 
# 模式一：FastMCP 高抽象测试 (最便捷)
@pytest.mark.asyncio
async def test_tool_execution():
    async with server.test_client() as client:
        result = await client.call_tool("scanner", project_id="P1")
        assert "scanning project" in result[0].text

# 模式二：底层 Mock stdio JSON-RPC (更工程化)
async def mock_call(request_json: dict) -> dict:
    # Mock stdin 写入请求，stdout 读取响应
    m_stdin, m_stdout = MockStream(), MockStream()
    transport = StdioServerTransport(m_stdin, m_stdout)
    m_stdin.write(json.dumps(request_json) + "\n")
    return json.loads(m_stdout.read())
