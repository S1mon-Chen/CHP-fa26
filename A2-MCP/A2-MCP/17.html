类型安全：JSON Schema 的重要性

定义强契约，确保大语言模型生成调用的参数符合后端严格规范

预防 LLM 幻觉

JSON Schema 为 LLM 提供了强制的约束边界。通过 types, enums, required fields 的声明，可以有效预防模型输入非法参数，提升交互的健壮性。

自描述能力

Schema 不仅是校验规则，更是自描述文档。其中包含的 description 字段直接决定了 LLM 是否能理解参数含义，从而实现精准的工具调用。

tool_schema_definition.json 
{
  "get_weather": {
    "description": "Get current weather in a city",
    "inputSchema": {
      "type": "object",
      "properties": {
        "city": { "type": "string", "description": "The city name" },
        "unit": { "type": "string", "enum": ["C", "F"] }
      },
      "required": ["city"]
    }
  }
}
