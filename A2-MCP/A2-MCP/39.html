重新定义 Vibe Coding (在 SE 语境下)

从“盲目生成代码”向“基于架构范式的上下文注入”演进

摒弃黑盒盲写

核心思想：不是让 AI 自由发挥盲写代码。在企业级软件工程 (SE) 中，缺乏约束的代码生成会导致系统架构发散，最终走向不可维护的深渊。

架构引导与填充

利用现代 IDE (如 Cursor) 强大的 Context Injection (上下文注入) 能力，开发者定义好底层范式，将 AI 视为高并发的“打字机”，引导其快速填充已确立的架构规范。

IDE Prompt Context (Cursor)
❌ 传统代码生成：
User: "帮我用 Spring Boot 写一个 MCP 服务"
Result: 产生不符合项目现有风格的样板代码，缺乏工程约束。
✅ SE 语境下的 Vibe Coding（上下文精确注入）：
Context 注入: @CourseService.java @McpConfig.java
Developer Prompt:
"在现有的架构下，为 CourseService 增加缓存查询 Tool。严格遵守以下工程约束："
  1. 继承当前项目的 DI（依赖注入）范式
  2. 强制使用 @McpTool 声明，不改变核心业务逻辑
  3. 生成规范的 Javadoc 作为 LLM 的语义路由描述
// AI 执行结果：遵循上述模式生成安全可维护的差异化代码
