环境搭建与依赖管理 (Maven)

通过 Spring AI BOM 统一版本管理，快速引入 MCP Server 核心组件

Spring AI BOM

利用 Bill of Materials (BOM) 统一管理所有 Spring AI 模块的版本。避免手动管理多个依赖产生的版本冲突问题，简化升级流程。

MCP Starter 依赖

引入 spring-ai-starter-mcp-server。该依赖提供自动配置支持，能够让 Spring Boot 应用快速具备作为 MCP Server 的协议处理能力。

pom.xml 
<!-- 1. 定义 Spring AI 版本管理 -->
<dependencyManagement>
    <dependencies>
        <dependency>
            <groupId>org.springframework.ai</groupId>
            <artifactId>spring-ai-bom</artifactId>
            <version>1.0.0-M1</version>
            <type>pom</type>
            <scope>import</scope>
        </dependency>
    </dependencies>
</dependencyManagement>

<!-- 2. 引入 MCP Server Starter 核心依赖 -->
<dependencies>
    <dependency>
        <groupId>org.springframework.ai</groupId>
        <artifactId>spring-ai-starter-mcp-server</artifactId>
    </dependency>
</dependencies>
