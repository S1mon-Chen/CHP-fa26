1. Spring Boot 极简集成与低侵入封装优势 Spring Abstraction

`spring-boot-starter-kafka` 依赖导入 Maven Starter

引入 Starter 依赖后，Spring Boot 会根据类路径自动对齐原生的 `kafka-clients` 版本，消除了手动管理底层依赖兼容性的烦恼。

声明式配置外置化 (`application.yml`) Externalized Config

将集群地址、反序列化类、重试策略与消费组 ID 等模板代码剥离至 YAML 文件，零硬编码即可完成 Producer 与 Consumer 策略绑定。

编程式 Topic 声明与 `KafkaAdmin` 自动建表 NewTopic Bean

在 Spring `@Configuration` 类中注册 NewTopic 类型的 Bean，应用启动时 KafkaAdmin 会自动向 Kafka 发起建表，无需运维手动切控制台开辟。

开发体验：样板代码极度收敛，开发者只需关注领域模型与业务 Handler
2. 生产级 `application.yml` 与 `NewTopic` 配置实战 YAML & Java Config
# A. application.yml 核心属性配置
spring:
kafka:
bootstrap-servers: localhost:9092
producer:
key-serializer: org.apache.kafka.common.serialization.StringSerializer
value-serializer: org.springframework.kafka.support.serializer.JsonSerializer
acks: all
consumer:
group-id: order-service-group
auto-offset-reset: earliest
key-deserializer: org.apache.kafka.common.serialization.StringDeserializer
value-deserializer: org.springframework.kafka.support.serializer.JsonDeserializer
// B. 编程式自动创建 Topic (`KafkaTopicConfig.java`)
@Configuration
public class KafkaTopicConfig {
@Bean
public NewTopic orderEventsTopic() {
return TopicBuilder.name("order-events")
.partitions(3)
.replicas(2)
.build();
}
}
