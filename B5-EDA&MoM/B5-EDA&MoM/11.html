1. 发布与订阅 (Publish & Subscribe) Write / Read Streams

持续将实时事件流**写入 (Write)** 到 Kafka 消息集群，或**读取 (Read)** 已有的分布式事件流。完全兼容传统的“消息队列 (MQ)”发布订阅机制。

**海量高吞吐**：单节点即可支撑每秒百万级消息发布。
**多语言 Client**：原生支持 Java, Go, Python, C++ 等客户端。
功能归类：替代传统消息队列处理低延迟并发通信
2. 持久化可靠存储 (Durable Storage) Append Log Storage

事件流以不可变追加日志 (Append-Only Log) 的形式**落盘持久化存储**。存储期限可任意配置（从 7 天、1 个月到永久保存）。

**无限次数据重放 (Replayability)**：新上线服务可追溯历史。
**多副本容错 (Replication)**：ISR 机制保障节点宕机数据零丢失。
功能归类：充当分布式不可变 Commit Log 存储数据库
3. 实时流式计算 (Stream Processing) Kafka Streams / Flink

允许应用程序在事件**发生的同时进行实时处理**（如滑动时间窗口聚合、流表 Join、异常过滤检测），也可进行历史追溯批处理。

**Kafka Streams API**：轻量级嵌入式流计算 Java 库。
**生态无缝对接**：与 Apache Flink, Spark, ksqlDB 原生集成。
功能归类：实时 ETL 数据清洗与复杂事件处理引擎 (CEP)

核心架构启发 (Kafka Event Streaming Definition)

Apache Kafka 绝不仅仅是一个简单的“消息队列”。它通过把消息组织为**持久化、可分片、可多副本复制的分布式追加日志**，成功充当了企业现代化数字架构中的 **“中央事件血脉 (Event Backbone)”**。
