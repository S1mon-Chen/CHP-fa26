Spring Boot JMS 整合实战：`JmsTemplate` 与 `@JmsListener`

`JmsTemplate` Producer, `@JmsListener` Consumer, `MappingJackson2MessageConverter` & Embedded Artemis Setup

1. 消息发送与 POJO JSON 转换 (`JmsTemplate`) Producer & Config
// 1. 注册 JSON 消息转换器以透明序列化 POJO
@Bean
public MessageConverter jacksonJmsMessageConverter() {
MappingJackson2MessageConverter converter = new MappingJackson2MessageConverter();
converter.setTargetType(MessageType.TEXT);
converter.setTypeIdPropertyName("_type");
return converter;
}
// 2. JmsTemplate 发送 POJO 消息 (`MsgController.java`)
@RestController
public class MsgController {
@Autowired private JmsTemplate jmsTemplate;
@GetMapping("/msg")
public String sendMsg() {
Email email = new Email("info@example.com", "Hello Msg");
// 自动转换为 JSON 并投递至 "mailbox" 队列
jmsTemplate.convertAndSend("mailbox", email);
return "Sent email payload!";
}
}

2. 声明式监听器 (`@JmsListener`) & POJO 映射 Consumer & Model
// 1. 业务领域消息 POJO (`Email.java`)
public class Email {
private String to;
private String body;
public Email() {}
public Email(String to, String body) { this.to = to; this.body = body; }
// Getters, Setters & toString() ...
}
// 2. 声明式异步消息消费者 (`Receiver.java`)
@Component
public class Receiver {
@JmsListener(destination = "mailbox")
public void receiveMessage(Email email) {
System.out.println("Received <" + email + ">");
}
}

Speaker Notes / 讲师讲稿
🎯 引导学生透视 Spring Boot 对 JMS 的工程封装： “向学员做解构说明：原生 JMS 需要手动管理 Connection 和 Session 对象的释放，而 Spring 的 `JmsTemplate` 屏蔽了这一切。配合 `MappingJackson2MessageConverter`，我们可以直接把业务对象 `Email` 传递给 `convertAndSend`，框架会自动序列化为 JSON 文本。”
💡 剖析 `@JmsListener` 容器的优势： “提示学员关注右侧的 `Receiver.java`：通过在普通 Spring `@Component` 的方法上加上 `@JmsListener(destination = "mailbox")` 注解，Spring 容器会在后台自动拉取并反序列化消息，实现极简的非阻塞消费。”
