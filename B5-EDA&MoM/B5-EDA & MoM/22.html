Native Java Kafka Client: KafkaProducer & KafkaConsumer 实战

`KafkaProducer` Thread-Safety, Asynchronous Callback, `KafkaConsumer` Polling Loop & Manual Offset Commit

1. 线程安全 `KafkaProducer` 异步发送与回调 Thread-Safe Producer
// A. 构建配置与实例（全局复用单例）
Properties props = new Properties();
props.put(ProducerConfig.BOOTSTRAP_SERVERS_CONFIG, "localhost:9092");
props.put(ProducerConfig.KEY_SERIALIZER_CLASS_CONFIG, StringSerializer.class);
props.put(ProducerConfig.VALUE_SERIALIZER_CLASS_CONFIG, StringSerializer.class);
props.put(ProducerConfig.ACKS_CONFIG, "all"); // 零数据丢失
// B. 异步带 Callback 回调发送
try (Producer<String, String> producer = new KafkaProducer<>(props)) {
ProducerRecord<String, String> record =
new ProducerRecord<>("order-events", "order_1001", jsonPayload);
// 非阻塞发送，返回 Future，并设置 Callback 机制
producer.send(record, (metadata, exception) -> {
if (exception == null) {
System.out.println("Acked Offset: " + metadata.offset());
} else {
System.err.println("Send Failed: " + exception.getMessage());
}
});
}
线程安全特性 (Thread Safety)

`KafkaProducer` 内部维护了并发 BufferPool 与 Sender 线程，是完全线程安全的。全应用只需共享一个单例对象。

生产要点：设置序列化器 (Serializer) 与全局复用单例 Producer 实例
2. 单线程安全 `KafkaConsumer` Poll 循环与手动 Commit Single-Thread Consumer
// A. 构建 Consumer 配置并关闭自动提交
Properties props = new Properties();
props.put(ConsumerConfig.BOOTSTRAP_SERVERS_CONFIG, "localhost:9092");
props.put(ConsumerConfig.GROUP_ID_CONFIG, "order-group");
props.put(ConsumerConfig.KEY_DESERIALIZER_CLASS_CONFIG, StringDeserializer.class);
props.put(ConsumerConfig.VALUE_DESERIALIZER_CLASS_CONFIG, StringDeserializer.class);
props.put(ConsumerConfig.ENABLE_AUTO_COMMIT_CONFIG, "false"); // 手动提交
// B. 订阅 Topic 并开启无限 Poll 循环
try (KafkaConsumer<String, String> consumer = new KafkaConsumer<>(props)) {
consumer.subscribe(Collections.singletonList("order-events"));
while (running) {
ConsumerRecords<String, String> records =
consumer.poll(Duration.ofMillis(100));
for (ConsumerRecord<String, String> record : records) {
processOrderRecord(record.value());
}
consumer.commitSync(); // 同步提交已消费 Offset
}
}
非线程安全警告 (Non-Thread-Safe)

`KafkaConsumer` 绝对非线程安全！必须采用“一个线程配一个 KafkaConsumer 实例”模式，或通过线程池异步处理业务再手动提交。

核心原生 API 启发 (Client Architecture Insight)

掌握原生 API 的线程安全性是基础：KafkaProducer 是线程安全的且全局共享，而 KafkaConsumer 为单线程独占。结合 **关闭 `enable.auto.commit`** 进行手动 Commit 是保障消费防丢防重的黄金法则。

🎯 强调 Producer 与 Consumer 的线程安全性差异： “向学员重点做提示：`KafkaProducer` 内部包含完整的 BufferPool 与 Sender 线程，是线程安全的，全应用只需创建一个共享单例；而 `KafkaConsumer` 是**绝对非线程安全**的，多线程同时访问同一个 `KafkaConsumer` 实例会直接抛出 `ConcurrentModificationException`。”
