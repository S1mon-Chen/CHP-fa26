1. ES 8.x 新一代官方 Java Client 初始化三步曲

Client Pipeline
告别已废弃的 `RestHighLevelClient` (HLRC) Deprecated in 7.15+

老旧的 HLRC 依赖了巨量的 ES Server 内部类Jar包，版本耦合严重。ES 8.0+ 引入全新的 **Elasticsearch Java API Client**，完全基于 JSON/Jackson 和 Fluent Lambda 构建。

1 Low-Level RestClient (HTTP 物理连接池) HttpHost

使用 RestClient.builder(HttpHost) 管理底层的异步 Netty/HTTP 物理连接池与长连接。

2 JacksonJsonpMapper & RestClientTransport Transport Layer

传入 Jackson 对象映射器 JacksonJsonpMapper，构建数据传输层 RestClientTransport 处理 JSON 自动序列化。

3 ElasticsearchClient 强类型入口 Fluent DSL

实例化 ElasticsearchClient 入口，支持以 1-to-1 匹配 JSON DSL 的 Fluent Lambda 范式构建复杂的检索与聚合。

特点：轻量无服务器依赖，强类型保护，与 JSON DSL 结构完美映射

2. 生产级 `ES8ClientPractical.java` 组合检索代码实战

ES8ClientPractical.java
// ES 8.x 强类型 Fluent Lambda 检索代码实战
public class ES8ClientPractical {
public static void main(String[] args) throws IOException {
// 1. 初始化 Low-Level RestClient 与 Jackson 转换器
RestClient restClient = RestClient.builder(new HttpHost("localhost", 9200)).build();
ElasticsearchTransport transport = new RestClientTransport(restClient, new JacksonJsonpMapper());
ElasticsearchClient esClient = new ElasticsearchClient(transport);
// 2. 构建强类型 SearchRequest (Fluent Lambda DSL)
SearchResponse<ProductDTO> response = esClient.search(s -> s
.index("products")
.query(q -> q
.bool(b -> b
.must(m -> m.match(t -> t.field("title").query("wireless headphones")))
.filter(f -> f.term(t -> t.field("status.keyword").value("active")))
)
)
.sort(so -> so.field(f -> f.field("price").order(SortOrder.Asc)))
.from(0).size(10),
ProductDTO.class // 传入目标 Class 进行 JSON 自动反序列化
);
// 3. 提取 Hits 结果与 DTO 反序列化对象
for (Hit<ProductDTO> hit : response.hits().hits()) {
System.out.println("ID: " + hit.id() + " | Score: " + hit.score() + " | Item: " + hit.source().getTitle());
}
}
}
