1. 课后核心架构思考题与高频面试挑战 (Discussion Questions)

Deep Questions

Q1 倒排索引Segment不变性与近实时(NRT)搜索解耦

为什么 Lucene 底层的 Segment 被设计为物理不可变 (Immutable)？Elasticsearch 是通过什么内存缓冲 (Index Buffer)、OS PageCache 刷刷新 (Refresh 1s) 与 Translog 顺序追加日志机制，在保持物理 Segment 不可变的前提下实现 1 秒内的近实时 (NRT) 检索的？

Q2 Query Context 与 Filter Context 性能差异物理剖析

在编写复杂的 ES Query DSL 时，为什么将 status=active 或 price >= 100 放在 bool.filter 比放在 bool.must 中性能高出数倍？请结合 BM25 浮点打分计算与 Node-Level Roaring BitSet 内存位图缓存机制进行说明。

Q3 双路混合检索与 RRF 倒数排名融合算法物理优势

为什么单靠高维向量检索 (ANN) 容易漏掉特定的商品规格型号或人名专有名词？倒数排名融合 (RRF) 算法是如何在数学上抹平 BM25 得分 (浮点数 10+) 与向量余弦得分 ($[-1, 1]$) 的数量级量纲差异，达成双剑合璧的？
