Lucene 高级 Query 表达式 (Lucene Advanced Query Types)

Query Family Hierarchy: TermQuery, PhraseQuery, BooleanQuery Clauses & PointRangeQuery

1. Lucene Query 家族三大核心类别 (Query Family)

Query Hierarchy
基础词项与短语查询 (Term & Phrase Queries) Positional Search
  • • TermQuery：精准搜索单一词项（如 `category:tech`）。
  • • PhraseQuery：短语邻近搜索，允许指定 slop 位置间隔。
  • • MultiPhraseQuery：支持多词项同义词扩展的短语查询。
组合与布尔查询 (Boolean Queries) BooleanClause
MUST (+) 必须匹配且参与 BM25 得分
SHOULD 可选匹配，匹配增加 Boost 提分
FILTER 必须匹配但**不打分 (Fast BitSet)**
MUST_NOT (-) 强行排除包含该词项的文档
数值范围与模糊匹配 (Range & Fuzzy Queries) PointRange & Edit Distance
  • • PointRangeQuery：利用 B-Tree 1D 点索引做数值/时间范围过滤。
  • • PrefixQuery / WildcardQuery / RegexpQuery：前缀、通配符与正则。
  • • FuzzyQuery：基于 Levenshtein 编辑距离防范拼写错误。
提示：用 FILTER 子句替换 MUST，不仅能跳过 BM25 复杂计算，还能激活节点级 BitSet 缓存

2. 强类型 `BooleanQuery.Builder` 组装实战

BooleanQuery Builder
// 组合逻辑查询构建代码
public Query buildComplexQuery() {
// 1. 构建布尔组合器
BooleanQuery.Builder builder = new BooleanQuery.Builder();
// 2. MUST: 必须包含分类 "tech" (参与打分)
builder.add(
new TermQuery(new Term("category", "tech")),
BooleanClause.Occur.MUST
);
// 3. FILTER: 价格在 10.0 到 100.0 之间 (不打分，激活 BitSet 缓存)
builder.add(
DoublePoint.newRangeQuery("price", 10.0, 100.0),
BooleanClause.Occur.FILTER
);
// 4. SHOULD: 标题包含 "lucene"，匹配则额外提分
builder.add(
new TermQuery(new Term("title", "lucene")),
BooleanClause.Occur.SHOULD
);
return builder.build();
}
BooleanClause.Occur 子句行为特征 Clause Behavior

• **`MUST`**：文档必须匹配该查询，且该查询计算出的相关性得分会相加累入最终 `_score`。
• **`FILTER`**：文档必须匹配该查询，但**得分恒定位 0**，性能极高且便于搜索引擎在节点级缓存结果。

核心代码启发 (Advanced Query Types Insight)

灵活组合 Lucene 的 Query 家族是构筑复杂检索系统的核心。生产环境优化金律：**对于状态过滤、价格区间、时间范围等无需计算相关性得分的条件，强制声明为 `BooleanClause.Occur.FILTER`**，这样不仅省去了 BM25 得分计算，还能完美激活 Lucene 节点级 BitSet 缓存。
