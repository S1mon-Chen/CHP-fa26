自定义打分扩展：Similarity API 与 Function Score

Custom BM25 Parameters, FeatureField Saturation Boost & Expression/FunctionScoreQuery

1. 定制与替换 Similarity 打分模型

Similarity SPI

可以在索引创建期和查询期通过设置 Similarity 接口调整底层相关性计算公式：

// 调整 BM25 词频饱和度 k1 与长度归一化 b
IndexWriterConfig iwc = new IndexWriterConfig(analyzer);
iwc.setSimilarity(new BM25Similarity(1.5f, 0.6f)); // 自定义 k1=1.5, b=0.6
// 查询期需保持一致以正确解包 Norms:
searcher.setSimilarity(new BM25Similarity(1.5f, 0.6f));
主流 Similarity 实现类选择 Model SPIs
  • • BM25Similarity：工业界金标准，可调 $k_1$ 与 $b$。
  • • ClassicSimilarity：基于 Vector Space Model (VSM) 与 TF-IDF。
  • • DFRSimilarity / LMDirichletSimilarity：语言模型与信息随机度模型。
黄金法则：索引期与查询期的 Similarity 必须严格配置一致，以保证 Norms 编解码正确

2. 融合业务标量的动态提分 (Boost & Function Score)

Feature Boosting
相关性得分 + 业务因子复合公式
$$\text{Final Score} = \text{Score}_{\text{BM25}} + \gamma \cdot \text{Score}_{\text{Feature}}$$
// 1. 利用 FeatureField (PageRank / 销量) 饱和曲线提分
Query originalQuery = new TermQuery(new Term("title", "lucene"));
Query featureQuery = FeatureField.newSaturationQuery("features", "pagerank");
Query query = new BooleanQuery.Builder()
.add(originalQuery, BooleanClause.Occur.MUST)
.add(new BoostQuery(featureQuery, 0.7f), BooleanClause.Occur.SHOULD)
.build();
// 2. FunctionScoreQuery: 乘法公式 Score_BM25 * ln(Popularity)
Expression expr = JavascriptCompiler.compile("_score * ln(popularity)");
SimpleBindings bindings = new SimpleBindings();
bindings.add(new SortField("_score", SortField.Type.SCORE));
bindings.add(new SortField("popularity", SortField.Type.INT));
Query funcQuery = new FunctionScoreQuery(originalQuery, expr.getDoubleValuesSource(bindings));
商业搜索排序最佳实践 Commercial Ranking

单纯文本匹配容易陷入死板。通过将 PageRank、商品销量、发布时间衰减融打分算式中，才能达成兼顾“内容相关”与“商业转化”的工业级排序！
