RRF 倒数排名融合算法与 Cross-Encoder 重排 (RRF & Reranking)

Reciprocal Rank Fusion (RRF), Dimensionless Rank Fusion & Two-Stage Bi-Encoder Recall + Cross-Encoder Rerank

1. RRF (Reciprocal Rank Fusion) 倒数排名融合公式

Rank Fusion

BM25 得分（如 $14.2$）与向量余弦得分（如 $0.85$）量纲不同无法直接相加。**RRF 抹平具体分值，完全根据名次 (Rank) 进行无量纲平滑融合**：

RRF 倒数排名得分计算公式
$$\text{RRF\_Score}(d \in D) = \sum_{m \in M} \frac{1}{k + r_m(d)}$$

$M$: 检索通道集合 (如 BM25 与 Vector)；$r_m(d)$: 文档 $d$ 在通道 $m$ 中的名次排名；$k$: 平滑常数 ($k=60$)。

RRF 实算演练 ($k=60$) Numerical Example
Doc A: BM25 排第 1 名，向量排第 3 名：
$\text{RRF}(A) = \frac{1}{60 + 1} + \frac{1}{60 + 3} = 0.01639 + 0.01587 = \mathbf{0.03226}$
Doc B: BM25 排第 2 名，向量排第 2 名：
$\text{RRF}(B) = \frac{1}{60 + 2} + \frac{1}{60 + 2} = 0.01613 + 0.01613 = \mathbf{0.03226}$
特点：不受数值量纲漂移影响，高名次文档获得极高权重加成

2. 两阶段检索：Bi-Encoder 召回 + Cross-Encoder 精排

Two-Stage RAG
// 生产级两阶段混合检索精排管线
阶段 1: 粗粒度混合召回 (Bi-Encoder Hybrid Recall) Top 50 - 100 Candidate Chunks

独立计算 Query 与 Doc 的向量点积（Bi-Encoder 向量预建），结合 BM25 快速筛选前 50–100 个粗召回候选集。

阶段 2: 深度重排 (Cross-Encoder Reranker) Top 3 - 5 for LLM Context

使用深度重排模型 (如 BGE-Reranker-Large) 拼接 [Query, Candidate_Doc]。通过交叉注意力机制计算深层语义对齐分，截取 Top 3–5 交付大模型！

Bi-Encoder vs. Cross-Encoder Model Comparison
  • • **Bi-Encoder**：向量提前算好离线存入 Vector DB，检索极快（毫秒级），但缺失交叉注意力。
  • • **Cross-Encoder**：现场计算 Query 与 Doc 的全注意力交互，精度极高，适合小范围候选集精排。
开启下一个核心：Slide 32 · 检索增强生成 (RAG) 系统架构全景链路

核心重排架构启发 (RRF & Reranker Insight)

**RRF 算法**是两路或多路检索融合的最佳桥梁，用无量纲倒数排名解决了分值不互通的尴尬；而在召回候选集后接入 **Cross-Encoder Reranker 重排模型**，能在大模型上下文窗口长度有限的前提下，将最高质量的相关 Chunk 递交给 LLM，极大提升 RAG 的回答准确率。
