Search Steps
1 打开 DirectoryReader 并构建 IndexSearcher DirectoryReader.open()

打开多段物理 Segment 的点路句柄 DirectoryReader.open(dir)，并实例化核心检索执行器 IndexSearcher。

2 使用 QueryParser 解析用户表达式 parser.parse()

传入与索引期完全相同的 `Analyzer`，调用 parser.parse("Lucene Search") 将自然语言解析为 Lucene `Query` 抽象语法树。

3 执行检索 (TopDocs) 与 StoredFields 摘要读取 StoredFields

调用 searcher.search(query, 10) 返回匹配元数据 TopDocs；遍历 ScoreDoc 包含全局文档 ID 与 BM25 得分 score，最后由 searcher.storedFields().document(docId) 惰性加载 `.fdt` 中的原始展示数据。

提示：TopDocs 仅包含 DocID 与得分，读取摘要明细需额外调用 StoredFields

2. 生产级 Lucene 9.x `LuceneSearchPractical.java` 代码

Lucene 9.x Search
// LuceneSearchPractical.java 核心检索完整实战
public class LuceneSearchPractical {
public static void main(String[] args) throws Exception {
Directory dir = FSDirectory.open(Paths.get("index_dir"));
// 1. 打开 DirectoryReader 并创建 IndexSearcher
try (DirectoryReader reader = DirectoryReader.open(dir)) {
IndexSearcher searcher = new IndexSearcher(reader);
Analyzer analyzer = new StandardAnalyzer();
// 2. 解析 Query 查询表达式
QueryParser parser = new QueryParser("title", analyzer);
Query query = parser.parse("Lucene Search");
// 3. 执行检索，获取 Top 10 命中文档 (TopDocs)
TopDocs topDocs = searcher.search(query, 10);
System.out.println("Total Matches: " + topDocs.totalHits.value);
// 4. 遍历 TopDocs 并读取 StoredFields
StoredFields storedFields = searcher.storedFields();
for (ScoreDoc scoreDoc : topDocs.scoreDocs) {
Document doc = storedFields.document(scoreDoc.doc);
System.out.println("DocID: " + scoreDoc.doc
+ " | Score: " + scoreDoc.score
+ " | Title: " + doc.get("title"));
}
}
}
}

核心代码启发 (IndexSearcher Practical Insight)

Lucene 检索的核心是**“两阶段数据加载”**：`searcher.search()` 阶段仅在内存与倒排索引中做 Fast Path 匹配，返回文档 ID (`ScoreDoc.doc`) 与 BM25 打分 (`ScoreDoc.score`)；只有当需要渲染给前端时，才通过 `storedFields.document(doc)` 进行磁盘 `.fdt` 行存加载，避免了大量无效文档的读盘损耗。
