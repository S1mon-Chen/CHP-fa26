Parallel Execution
// 用户查询: "2024款 苹果 M3 芯片 笔记本"
User Prompt / Query Stream
分路 A: BM25 词法分支

倒排索引精准锁死专有名词：
"2024款", "M3"

分路 B: HNSW 向量分支

Embedding $\to$ HNSW 近邻图搜：
"MacBook Pro", "Apple Laptop"

双路结果并行收集 $\to$ 送入下一阶段 RRF 倒数排名融合重排
并发执行：词法分支与向量分支并行并发发起，显著缩短端到端总延时

2. 词法与语义双剑合璧优势 (Complementary Advantages)

Zero-Miss Coverage
BM25 词法优势：精准打击专有名词与规格型号 Lexical Precision

对商品型号（如 "M3-Max-64G"）、订单编号、人名或专有 API（如 "setRollbackOnly"）拥有 **100% 绝对精确的召回率**。

向量 ANN 优势：深度理解抽象意图与同义转换 Semantic Recall

对模糊意图（如 *"适合程序员的高性能轻薄本"*）、口语化表述或同义词转换，能够实现高维空间的语义泛化召回。

// 生产混合检索效果结论

单纯向量检索常因概率近邻而遗漏具体的规格数字/字母；单纯 BM25 检索常因词汇不一致而漏掉同义词。**混合检索将两者的召回优势完美叠加，既不漏掉精准型号，又不漏掉深层意图**！

开启下一个核心：Slide 31 · 倒数排名融合 (RRF) 算法与 Cross-Encoder 重排 (Reranker)

核心架构启发 (Hybrid Search Architecture Insight)

混合检索 (Hybrid Search) 是电商搜索与现代化 RAG 系统的绝对标准形态。单靠词法（抓得准、漏得猛）或单靠向量（泛化好、抓不准专有名词）均有缺陷；通过**双路并发召回 + 算法融合重排**，才能构建真正防漏防错的生产级搜索引擎。
