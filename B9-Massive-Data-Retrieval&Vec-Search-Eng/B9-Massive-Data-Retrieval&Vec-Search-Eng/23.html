Part 03 · 向量检索与 AI 时代 Vector DB

从词法检索到语义检索 (Lexical Search vs. Semantic Vector Search)

Exact Term Matching Limits vs. High-Dimensional Dense Vector Space Nearest Neighbor Mapping

1. 传统词法检索 (Lexical Search) 物理瓶颈

Lexical Flaws
依赖“字面精准重合” (Exact Term Matching) BM25 Model

倒排索引建立在分词后的 Term 字典匹配之上。一旦查询词与文档中的字面词汇没有直接重合，搜索命中率直接跌落至 **0**！

典型词汇孤岛与多义词陷阱 Vocabulary Mismatch
  • 同义表达脱节：
    搜 "苹果手机" 匹配不到未包含该字符串的 "iPhone 15 Pro"；
  • 句式表达多变：
    搜 "怎么修改密码" 漏掉指南标题 "重置密码安全教程"。
代价：无法理解语言背后的抽象语义与泛化关联

2. 向量语义检索 (Semantic Vector Search) 范式突破

Dense Vector Space

利用深度学习 Embedding 模型将非结构化文本、图片降维映射到**高维连续向量空间 (Dense Vector Space, $\mathbb{R}^d$)**：

// 高维连续语义空间映射 (Dense Semantic Mapping)
几何距离越近 $\implies$ 语义越相近 (与字符字面无关!)
Query: "苹果手机" ──Embedding──► [ 0.12, -0.45, 0.88, ... ]
│ 高维几何极近距离 (Cosine Distance $\le$ 0.05)
Result: "iPhone 15 Pro" ──Embedding──► [ 0.11, -0.44, 0.86, ... ]
几何检索本质变迁：
倒排字符比对 $\longrightarrow$ 高维空间**最近邻距离搜索 (Nearest Neighbor Search)**！
语义检索三大技术红利 AI Paradigm
  • • **跨词汇意图理解**：即使完全没有相同字词，依然能够精准召回相关概念；
  • • **多模态同构搜索**：支持“文本搜图片”、“以图搜图”、“音频搜文本”；
  • • **AI 时代 RAG 的核心底盘**：为大语言模型 (LLM) 知识库提供深度上下文语义对齐。
开启下一个核心：Slide 24 · Vector Embeddings 物理意义与 1536 维空间数值表述

核心范式启发 (Semantic Search Paradigm Insight)

向量语义检索代表了搜索引擎的维度的升维突破。传统倒排索引解决的是**“文字字面的精准覆盖”**，而向量检索通过神经网络 Embedding 模型解决的是**“文字背后的深层意图理解”**。两者结合（混合检索）是现代 AI 后端的终极形态。
