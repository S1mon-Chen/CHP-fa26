HNSW 多层小世界网格算法 (HNSW Graph Index Mechanics)

Hierarchical Navigable Small World, SkipList-like Multi-Layer Routing & $O(\log N)$ Complexity

1. HNSW 跳表式多层图拓扑架构 (Multi-Layer Topology)

SkipList on Graph

**HNSW (Hierarchical Navigable Small World)** 将单层“小世界网络”拓展为类似**跳表 (SkipList)** 的多层图结构：

// HNSW 多层图拓扑逻辑示意
Layer 2 (顶级：稀疏高速公路层) Long-range Fast Route
[ Entry A ] ───────────────────────────────► [ Node Z ]
Layer 1 (中层：中等密度过渡层) Medium Density
[ Node A ] ──────────► [ Node M ] ──────────► [ Node Z ]
Layer 0 (底层：全量高密度近邻网格) Full Nearest Graph
[ Node A ] ─► [ Node C ] ─► [ Node M ] ─► [ Node K ] ─► [ Node Z ]
核心原理：高层跨越长距离做粗粒度路由，底层在局部网格做精细 $k$-NN 搜索

2. 路由搜索流程与关键超参数 (Pipeline & Tuning)

$O(\log N)$ Time
1 顶层贪心搜索 (Greedy Search) 降层路由 Top-Down Route

从最高层固定入口节点 (Entry Point) 开始，计算与目标向量的距离，**贪心移动至局部最近节点**。到达该层局部最优后**降层 (Express Pass)**，将上一层的极优节点作为下一层的搜索入口。

2 底层 Beam Search 与 Top K 结果截取 efSearch Bounds

降至最底层 (Layer 0) 后，在全量高密度图中执行大小为 efSearch 的候选池 Beam Search 束搜索，获取全局前 $K$ 个最近邻向量。

// HNSW 三大核心调优超参数
• m (如 16)：每个节点的最大出边连接数（$m$ 越大精度越高，但索引体积增大）。
• ef_construction (如 100~200)：建图时的候选池深度（值越大建图越慢，但召回率更高）。
• ef_search (如 50)：查询时的候选池深度（值越大 QPS 降低，但精度上升）。

核心物理算法启发 (HNSW Index Mechanics Insight)

HNSW 巧妙地将跳表 (SkipList) 的概率降层思想拓展至高维图结构中。利用顶层稀疏图完成极速跨跨度导航，再在底层密集网格做局部精确收敛，成功将高维向量检索的时间复杂度从物理上的线性 $O(N)$ 降至对数级 **$O(\log N)$**。
