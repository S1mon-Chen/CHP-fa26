1. Lucene 索引构建四大核心步骤 (Indexing Pipeline)

Pipeline Steps
1 打开 Directory 并配置 IndexWriterConfig FSDirectory.open()

使用 FSDirectory.open(Path) 映射本地文件系统，绑定 `Analyzer` 与开模参数 CREATE_OR_APPEND。

2 构建 Document 并组装多类型 Field Typed Fields
StringField: 精确匹配不分词 (例如 ID、Path)
TextField: 全文分词分析 (例如 Title、Content)
LongPoint: B-Tree 点索引，用于数值范围过滤
NumericDocValues: 列式存储，用于快速排序
3 写入索引与事务安全提交 writer.commit()

调用 writer.addDocument(doc) 写入缓存，调用 writer.commit() 执行事务落盘与段生成，并在 `try-with-resources` 块中安全释放 `IndexWriter`。

提示：Field.Store.YES 控制字段原值是否存入 .fdt 文件以便结果展示

2. 生产级 Lucene 9.x `LuceneIndexPractical.java` 代码

Lucene 9.x API
// LuceneIndexPractical.java 索引创建完整实战
public class LuceneIndexPractical {
public static void main(String[] args) throws IOException {
Path indexPath = Paths.get("index_dir");
Directory dir = FSDirectory.open(indexPath);
// 1. 配置 StandardAnalyzer 与 IndexWriterConfig
Analyzer analyzer = new StandardAnalyzer();
IndexWriterConfig iwc = new IndexWriterConfig(analyzer);
iwc.setOpenMode(IndexWriterConfig.OpenMode.CREATE_OR_APPEND);
// 2. try-with-resources 安全开启 IndexWriter
try (IndexWriter writer = new IndexWriter(dir, iwc)) {
// 3. 构建 Document 实体
Document doc1 = new Document();
doc1.add(new StringField("id", "doc_1001", Field.Store.YES)); // 精确词不分词
doc1.add(new TextField("title", "Apache Lucene Full Text Search", Field.Store.YES)); // 全文分词
doc1.add(new LongPoint("modified", System.currentTimeMillis())); // 数值点，用于范围查询
doc1.add(new NumericDocValuesField("modified", System.currentTimeMillis())); // 列存用于排序
// 4. 写入索引并提交事务
writer.addDocument(doc1);
writer.commit();
}
}
}

核心代码启发 (IndexWriter Practical Insight)

Lucene 9.x 明确区分了不同物理用途的 Field：**`StringField`** 适用于 ID、Path 等精确值；**`TextField`** 驱动 Analysis 分词做倒排检索；**`LongPoint`** 构建 1D B-Tree 做微秒级区间筛选；**`NumericDocValuesField`** 则生成列式存储，专为高并发 `Sort` 与聚合服务。

🎯 引导学员理解 Lucene 9.x 现代 Field 类型的组合： “向学员解构说明：写 Lucene 索引不是简单往里塞 String，而是要根据查询需求选对 Field 类型：
1. **StringField**：不会被 Analyzer 分词，适合作为 ID 或固定分类；
2. **TextField**：经过分词器，建立倒排索引，适合全文检索；
3. **LongPoint**：用于做数值范围匹配（比如时间筛选、价格筛选）；
4. **NumericDocValuesField**：生成列存，如果查询要求按该字段排序 (Sort)，必须加上它以提升排序性能。”
💡 强调 `try-with-resources` 与事务提交： “请学员注意右侧代码：`IndexWriter` 实现了 `AutoCloseable`，在 `try-with-resources` 块结束时会自动释放文件锁；调用 `writer.commit()` 才会触发事务落盘并写成 Segment。下一个 Slide 9 将讲解 Lucene 的检索与分页实战代码 (`IndexSearcher`)。”
