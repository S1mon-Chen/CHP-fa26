案例 1：千万级电商商品混合检索架构 (E-Commerce Hybrid Search)

Search Engine
业务场景需求 Query: "黑色 2024款 降噪耳机"

用户输入复合长查询："黑色 2024款 降噪耳机"。要求：锁定型号 `"2024款"` 与颜色 `"黑色"`；召回 `"无线头戴耳机"` 抽象语义；过滤价格范围与上架状态；结合店铺权重提分。

// ES 8.x 双路混合检索 + RRF 融合 DSL 结构
{
"query": {
"bool": {
"filter": [ { "term": { "status": "active" } } ], // 1. 硬过滤
"must": [ { "match": { "title": "黑色 2024款" } } ] // 2. BM25 精准锁词
}
},
"knn": { "field": "title_vector", "k": 50, "num_candidates": 200 } // 3. HNSW 语义
}
效果：极度精准匹配型号与颜色，同时语义召回同义替代词，转化率提升 18%

案例 2：RAG 智能企业知识库问答后端 (Enterprise RAG Backend)

RAG Engine
业务场景需求 Zero Hallucination

针对企业数百 MB PDF/Word 规章制度与技术文档，要求大模型 (LLM) 归因回答，绝不产生“幻觉”，且回答后必须附带**物理文档引用出处 (Citations)**。

// 端到端 RAG 检索生成全流程链路 (End-to-End Pipeline)
1. 文档切块: PDF Parsing $\to$ 512 Tokens Chunking (带 50 Overlap)
2. 双重索引: BGE-Large 向量化 $\to$ 存入 ES 8+ (BM25 + HNSW 图)
3. 双路召回: 用户提问 $\to$ 混合检索召回 Top 20 候选 Chunks
4. 交叉重排: BGE-Reranker-Large 计算交叉注意力精选 Top 3
5. Prompt 生成: 注入 Context 交付 GPT-4 / DeepSeek 带来源流式输出
