1. 海量数据检索三大物理设计原则 (Search Engine Rules)

Search Principles
Ⅰ. 优先选用 Filter Context 替代 Query Context

状态码、日期、范围等无打分需求的条件强制写入 `bool.filter`，省去浮点 BM25 算力并激活 **Roaring BitSet 内存缓存**。

Ⅱ. 采用双路混合检索 (Hybrid Search) 规避单一漏洞

BM25 词法抓准型号/专有名词，HNSW 向量抓准抽象意图，配合 **RRF 倒数排名融合算法** 达成双剑合璧。

Ⅲ. 按生命周期 (ILM) 实施冷热分离层级存储

黄金硬件留给 Hot 写入节点，历史数据通过 ILM 自动下沉至廉价 HDD 或 S3 对象存储，大幅降低 70% 以上物理成本。

法则：用物理内存与算法优化换取高吞吐，用多层存储解耦降本增效
