**微服务书籍**
- 《微服务架构入门与实战》林舟，69元，库存18本。适合刚接触微服务的读者，讲服务边界、REST 通信、服务注册、网关，并配有电商书店实例，最适合入门。
- 《Spring Boot 与 Spring Cloud 项目实践》陈远，79元，库存12本。适合有 Java 基础的人，偏重配置中心、网关、负载均衡、部署等工程实践。
- 《微服务系统的可靠性设计》周宁，89元，库存7本。面向已有微服务经验的读者，内容是分布式事务、限流熔断、可观测性等进阶主题。

如果你是零基础，我建议从第一本开始；会 Java，想动手实践，可以选第二本。

**拆封退货政策**
如果你因为“不喜欢内容、买错书、觉得太难”这类非质量原因而退货，那么原本带塑封的图书一旦拆封，就不支持七天无理由退货，会员身份也不能豁免 [P02-1]；如果没有拆封，则须在签收次日起七天内、商品完好且配件赠品齐全的情况下申请 [P01-1]。

如果是质量问题（缺页、倒装、印刷模糊、收到时破损），即使已拆塑封，也可在签收后十五天内凭订单号和问题照片申请退货或换货，核实后书店承担往返运费 [P03-1][P04-1]。
