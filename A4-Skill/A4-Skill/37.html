Toolchain Spec 
class AgentToolchainRegistry:
    # 1. 只读 SQL 审计工具 (ReadOnly Preflight) ★
    @tool(side_effect="READ_ONLY")
    def sql_explain_tool(query_sql: str) -> dict:
        """Runs EXPLAIN query to verify index hit & full table scan risks."""
        return db_sandbox.explain_query(query_sql)

    # 2. 只读 AST 语法树解析器 (ReadOnly Parsing) ★
    @tool(side_effect="READ_ONLY")
    def ast_parse_tool(code_snippet: str) -> dict:
        """Parses Python AST via Tree-sitter for syntax error & complexity."""
        return ast_analyzer.parse_code(code_snippet)

    # 3. 物理隔离沙箱单测工具 (ReadOnly Evaluation) ★
    @tool(side_effect="READ_ONLY")
    def sandbox_pytest_tool(test_path: str, timeout_s: float = 15.0) -> str:
        """Runs pytest inside Docker sandbox and returns pruned Traceback."""
        return docker_sandbox.run_pytest(test_path, timeout_s)

    # 4. 修改类 Git Unified Diff 应用工具 (State-Changing + HITL) ★
    @tool(side_effect="STATE_CHANGING", requires_approval=True, supports_undo=True)
    def git_apply_patch_tool(patch_diff: str) -> str:
        """Applies Git patch with HITL approval gate & git checkout Undo."""
        return git_repo.apply_patch_with_undo(patch_diff)
  • 高内聚原子解耦：四个 Skill 拥有独立明确的副作用标记与校验模型，互相独立但能在 ReAct 控制流中无缝编排。
架构特征：将复杂审计与修复任务解构为 4 个高内聚原子 Skill 契约

SQL 审计与 Patch Agent 工具链拓扑

4-Skill Agent Pipeline Topology

Tool Topology
1. sql_explain_tool SQL 预飞审计

抓取慢查询 SQL 并在物理库只读副本中跑 `EXPLAIN`，导出索引命中率、扫描行数与潜在全表扫描告警。

2. ast_parse_tool AST 语法诊断

在应用层对修复代码实施语法结构提取（Tree-sitter），拦截语法错误与圈复杂度超标改动。

3. sandbox_pytest_tool 沙箱单测自愈评估

拉起无网络的 Docker 沙箱运行 `pytest`；若失败，提取剪枝后的 Traceback 喂回进行 Self-Correction 自动迭代。

4. git_apply_patch_tool Git Patch 事务写入

挂起控制流触发 HITL 人工确认弹窗，批准后将 Unified Patch 应用至 Git 工作树；若失败瞬间自动 Undo 回滚。
