Code Interpreter 隔离执行引擎

e2b Sandbox Execution Code

e2b / Docker 
from e2b_code_interpreter import CodeInterpreter

def execute_python_interpreter(code: str, timeout_s: int = 10) -> dict:
    # 1. 动态拉起物理隔离的 Sandboxed Container ★
    with CodeInterpreter(timeout=timeout_s) as sandbox:
        # 2. 发送大模型生成的任意 Python 代码
        execution = sandbox.notebook.exec_cell(code)
        
        # 3. 结构化抽取标准输出、错误与生成的图表文件 (PNG/SVG) ★
        results = []
        for out in execution.results:
            if out.png:
                results.append({"type": "image/png", "data": out.png})
        
        return {
            "stdout": execution.logs.stdout,
            "stderr": execution.logs.stderr,
            "artifacts": results,
            "error": execution.error
        }
  • 产物全抽取：不仅能捕获 `print()` 输出，还能将 `matplotlib` 生成的图片及数据文件直接打包提取。
核心：把计算密集型与绘图需求完全离溯至有界微型沙箱运行

代码解释器沙箱的三大工程支柱

Code Interpreter Engineering Pillars

Interpreter Security
1. 严苛配额与网络熔断 (Resource Quotas) No Network & Memory Bound

设定最大 CPU 配额（如 1 Core）、RAM 限制（如 512MB）与硬性超时；默认启用 `network_mode="none"` 阻断恶意数据外退。

2. 临时生命周期与状态回收 (Ephemeral Lifecycle) Clean Tear-down

沙箱实例即用即废（Ephemeral）；单次代码推演结束后瞬间销毁容器上下文，彻底防止炸弹死循环与内存泄露残留。

3. 交互式 Data Science 预装库 (Pre-installed Libs) Pandas & Matplotlib Ready

预装 `pandas`, `numpy`, `matplotlib`, `scikit-learn` 等全量分析包，避免代码运行时触发繁重的 `pip install` 延时。

实践选型：e2b (Cloud MicroVM) vs Custom Docker Sandbox Container

Architectural Core Thesis / 架构师视角

代码解释器（Code Interpreter）是高级 Agent 进行高级数据分析、复杂算法求解与自动化图表渲染的核心基础设施；通过 e2b / Docker 物理隔离与临时生命周期管理，兼顾极速推演与宿主物理安全。
