原生 HTTP Function Call 驱动流

Raw Python HTTP Request Engine

Hook Code
import requests, json

# 1. Local Tool Registry Hook Map
TOOL_MAP = {"get_user_email": lambda user_id: f"user_{user_id}@company.com"}

# 2. Raw Request Function
def run_tool_call_loop(messages, tools):
payload = {"model": "deepseek-chat", "messages": messages, "tools": tools}
res = requests.post("https://api.deepseek.com/chat/completions", json=payload).json()
msg = res["choices"][0]["message"]
messages.append(msg) # Append Assistant Response

# 3. Handle Tool Calls Array (Turn 1 Completion)
if "tool_calls" in msg:
for call in msg["tool_calls"]:
args = json.loads(call["function"]["arguments"])
result = TOOL_MAP[call["function"]["name"]](**args) # Local Hook Exec
messages.append({
"role": "tool", "tool_call_id": call["id"], "content": str(result)
})
return run_tool_call_loop(messages, tools) # Turn 2 API Re-call
return msg["content"]
  • 零框架黑盒依赖：展示了工具调用的底质就是基于递归/循环不断向 `messages` 追加 `role: "tool"` 并二次 POST 发起请求。
核心：理解此 20 行核心 Hook，便掌握了所有 Agent 框架的底层引擎
