from enum import Enum

class ApprovalAction(str, Enum):
    APPROVE = "APPROVE"  # 直接放行
    REJECT = "REJECT"    # 阻断并向 LLM 投递拒绝对话
    MODIFY = "MODIFY"    # 人类手动修复风险参数后恢复 ★

def dispatch_skill_with_hitl(tool_call, context):
    # 1. 检查工具元数据是否标记为高危修改类 Skill
    if tool_call.is_high_risk:
        # 2. 状态图持久化挂起 (Suspend) 并触发可视化审批弹窗 ★
        ticket = create_approval_ticket(tool_call)
        human_decision, new_args = wait_for_human(ticket.id)
        
        if human_decision == ApprovalAction.REJECT:
            return "Observation: High-risk action REJECTED by human operator."
        elif human_decision == ApprovalAction.MODIFY:
            tool_call.args = new_args  # 覆盖为人类更正后的安全参数

    # 3. 授权通过后进入物理沙箱执行

HITL 机制的三大工程防御支柱

HITL Architecture Pillars

Safety Control
1. 高危动作断路器 (High-Risk Circuit Breaker) Risk-Based Suspension

自动识别 `git push --force`、`DROP TABLE` 或对写 API；一旦匹配高危属性，控制流瞬间封锁，杜绝脱缰 Agent 造成不可逆破坏。

2. 人类覆写与动态干预 (Modify & Resume) Human Parameter Edit

审批卡扣不仅支持“Approve/Reject”，更允许人类在 Web 弹窗中修正模型带病的入参（如修改越界的改动范围），校正后恢复运行。

3. 状态快照与断点恢复 (State Checkpoint) Async Suspend/Resume

借助控制图快照（LangGraph / LlamaIndex Workflows Checkpointing），在挂起等待审批期间将 Agent 全量状态序列化入库，保障恢复后的认知无缝衔接。

实践案例：Cline / Roo Code / Cursor 的工具执行确认弹窗

Architectural Core Thesis / 架构师视角

自治不等于放任失控！构建 Human-in-the-Loop (HITL) 人工审批卡扣与状态挂起机制，是将自主 Agent 安全引入生产环境、建立人类终极责任防线的核心技术支柱。
