告别手写 JSON Schema 维保噩梦：利用 Python 原生 Type Hints 与 Pydantic BaseModel / FastMCP 装饰器 实现零漂移（Zero-Drift）工具契约自动生成

Pydantic / FastMCP 工具契约定义

Auto Schema Export Code Engine

Pydantic v2 / FastMCP
from pydantic import BaseModel, Field
from typing import Literal, List
from mcp.server.fastmcp import FastMCP

# 1. Pydantic Model 自动转译为 JSON Schema
class
GitPullRequestInput(BaseModel):
title: str = Field(description="PR title in Conventional Commit format")
base_branch: Literal["main", "develop"] = Field(description="Target branch")
draft: bool = Field(default=False, description="Create draft PR")

# 2. FastMCP 装饰器一步完成注册
@mcp.tool()
def
git_create_pr(req: GitPullRequestInput) -> str:
"""Submits a new pull request to GitHub repository."""
return f"PR '{req.title}' created on {req.base_branch}"

// Schema Export: GitPullRequestInput.model_json_schema() ★
  • 零人工维保漂移：修改 Python 代码类型，导出的 Tool Schema 随 CI/CD 自动同步更新。
原则：代码即文档，类型即契约，彻底消除手写 JSON Schema 的语法失误

强类型自动转译的三大工程红利

Pydantic Engineering Redlines

Type Safety
1. 类型精准映射 (Type Mapping) Python Hints $\to$ OpenAPI Spec

`str`, `int`, `bool`, `List[T]` 与 `Literal[...]` 自动映射为 JSON Schema 的 `string`, `integer`, `boolean`, `array` 和 `enum` 限制，无需手动撰写类型字典。

2. 自动标记必填项 (Required Infer) Default Values Detection

Pydantic 会自动扫描无默认值的字段，并自动生成 JSON Schema 的 `required` 强约束列表；带有 `default=` 的字段被隐式归类为可选入参。

3. 运行时双向反序列化 (Runtime Deserialization) LLM Output Validation

当大模型返回 `tool_calls` 参数 JSON 串时，Pydantic 在宿主侧物理执行前自动将其校验反序列化为 Python 对象，不合规时提前拦截报错。

工程最佳实践：使用 FastMCP 或 Instructor 自动化同步全量工具表

Architectural Core Thesis / 架构师视角

绝对不要用纯手写的方式维护 JSON Schema！借助 Pydantic 与 FastMCP 的类型推导与元编程机制，实现“代码即契约、契约即 Prompt”，是将 Skill 快速接入生产工程的标准做法。
