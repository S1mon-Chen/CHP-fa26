参数校验与前置拦截：Pydantic @field_validator 在模型采样前后的防护

物理执行前的第一道高防哨卡：通过 Pydantic @field_validator 前置校验 拦截路径越界、非法 Cron 与注入攻击，并将其转化为 Self-Correction 自愈反馈

Pydantic 前置校验防线

Pydantic Validator Defense Code

Field Interceptor 
from pydantic import BaseModel, Field, field_validator
import re, os

class ScheduleTaskInput(BaseModel):
    script_path: str = Field(description="Path inside /sandbox")
    cron_expr: str = Field(description="5-part Cron format")

    @field_validator("script_path")
    def prevent_path_traversal(cls, v: str) -> str:
        if ".." in v or v.startswith("/"):
            raise ValueError("Path traversal detected! Path must be relative")
        return v

    @field_validator("cron_expr")
    def validate_cron(cls, v: str) -> str:
        if len(v.split()) != 5:
            raise ValueError("Cron expression must contain 5 parts")
        return v
  • 零代价物理拦截：在执行任何系统 Shell 或 I/O 操作前，耗时 $< 0.1$ms 阻断非法越权参数。
物理防线：绝对不允许未校验的概率文本直接拼接进 Shell 命令或系统路径

宿主侧前置拦截的三大工程红利

Pre-Execution Interception Benefits

Zero-Trust Gate
1. 物理越权隔离 (Security Barrier) Path Traversal & Injection

大模型常因提示注入输出 `../../etc/passwd` 或 SQL 注入串。在 Host Python 侧用校验器强行拦截，防止高危请求触达物理沙箱。

2. ValidationError 转化为 Observation Self-Healing Feedback

拦截报错不中断主程序，而是将 `str(e)` 包装为 `role: "tool"` 消息追加回 Context。LLM 读取明确的 `ValueError` 提示后会在 2nd-turn 自动修正参数。

3. 逻辑组合校验 (@model_validator) Multi-field Relation

利用 `@model_validator(mode="after")` 对多字段逻辑做联动判定（如 `start_date < end_date`），解决单字段类型无法表达的业务约束。

工程最佳实践：零信任原则 —— 假定模型吐出的任何字符串都有潜在恶意倾向

Architectural Core Thesis / 架构师视角

永远不要信任大模型生成的参数！借助 Pydantic 的 `@field_validator` 与 `@model_validator` 在物理沙箱入口处构建前置强校验防线，是将概率 LLM 安全接入企业生产基础设施的关键步骤。

Speaker Notes / 讲师讲稿
🎯 强调零信任（Zero Trust）安全底线： “向学员强调：不要假设大模型传过来的参数总是合法的！模型可能因为 Prompt 注入、幻觉或者对业务规则理解偏差，吐出带有 `../..` 路径越界的危险字符串，或者格式错误的 Cron 表达式。直接送入物理沙箱是非常危险的。”
💡 巧用 ValidationError 驱动 Agent 自愈： “向学员介绍：当 Pydantic 抛出 `ValidationError` 时，不要停掉宿主主程序！捕获它的报错明细（例如 `Cron expression must contain exactly 5 space-separated parts`），把它当成 `role: "tool"` 的 Observation 喂回给大模型，模型在下一轮对话中会自动修正这个参数，这就是 Self-Correction 自愈机制的基础。”
