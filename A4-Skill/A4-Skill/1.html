AI 应用与辅助编程架构师视角 (Course 4: Skill & Function Calling)

第 4 课：AI 原子能力与工具调用

从“被动文本”走向“主动有副作用的操作”

解构大模型应用演进的关键拐点：从 无状态概率文本预测器 跨越至 能够改变物理与企业系统状态的计算节点

传统视角 (Text Completion)

被动文本预测器

Stateless Text-In, Text-Out

// 用户提问：“北京今天天气怎么样？”
"根据我训练数据的记忆，北京夏季通常晴朗，温度约为 25-30℃..."
// 局限：静态知识截断、无法感知真实实时状态
  • 封闭计算图：仅在自回归 Token 空间运算，无法直接触达外部 API。
  • 无副作用（Side Effect）：对话不改变数据库、文件系统或外部真实环境状态。
工具调用视角 (Skill & Function Calling)

主动动作调度引擎

State-Changing Atomic Execution

// 用户提问：“查询北京天气并开启客厅空调”
1. tool_call: get_weather(location="Beijing")
2. tool_call: set_thermostat(room="Living Room", temp=24)
// 突破：实时物理环境感知 + 产生真实的物理/系统改变
  • 原子能力契约（Skill Schema）：基于 JSON Schema/Pydantic 暴露的强类型接口。
  • 真实物理副作用：支持读写数据库、发送邮件、执行终端 Shell、控制物理设备。

Architectural Core Thesis / 架构师视角

Skill 是大模型接入真实物理世界和企业 API 的无状态原子能力契约（Atomic Capability Contract）；掌握 Skill & Function Calling，是将 LLM 从“陪聊模型”升级为“企业级决策调度引擎”的必经之路。
