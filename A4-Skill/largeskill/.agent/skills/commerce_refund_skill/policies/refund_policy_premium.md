# Premium 会员退款与库存路由政策

## 1. 权限与额度约束 (Guardrails)
* **单次退款上限**：Premium 会员单次自动/半自动退款金额不得超过 **500 元人民币**。超过此限额的请求必须直接拒绝，并引导至高级人工客服。
* **风控校验**：必须通过 GPS 空间一致性校验。若用户实时 GPS 与注册地不符，触发“动态澄清模式”。

## 2. 金融级人工介入护栏 (HITL)
* 所有通过校验的退款申请，Agent 仅具备生成 **退款提案 (Refund Proposal)** 的权限。
* 最终资金流转必须落地为待审批状态，并向运营管理后台推送一条审批流水，等待人工介入 (Human-in-the-Loop) 确认。
