未实现主题与教学纠偏

课件页本工程边界
11—17、19—20无图 Checkpointer、人工审批、恢复与分支。corpus_snapshot_id 是资料版本；run_id 是日志身份；两者不是 checkpoint_id。
21—30无蜂群、Handoff、子图和 Agent 间通信。第 27 页的预算和指纹原则在单 Agent 中可观察。
31—33、36—37不运行模型生成代码；资料访问控制不是 Docker/MicroVM 沙箱。Web 子进程是运行与限时安排，不是安全沙箱。
34、38固定 seed 或 temperature=0 不能保证重采样得到相同结果。本工程 replay 完全不调用模型，使用保存的观察。
35只统计真实运行计数与 API Token；没有实现 Pass@k、Tool F1 或费用估算。
2、5DAG 系统也可提供任务重试；有向环用于表达本例反复决策。普通 if/while 也能正确实现受限闭环。
39—40总结与后续课程，作为讨论扩展，不把所有主题宣称为本项目能力。
