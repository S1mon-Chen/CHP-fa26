1. 端到端 E2E 评估四大核心维度

4 Quantitative Dimensions for Agent Quality

Eval Pillars
Pass@k
Pass@k 概率正确率： 在 $n$ 次尝试中生成 $k$ 个解，至少有一个解物理通过沙箱单测的无偏估计概率（如 $Pass@1$ 与 $Pass@5$）。
Trajectory
轨迹步骤效率 (Trajectory Efficiency)： 测量从初始状态到达 `END` 节点的平均转换步数（Steps），惩罚盲目重试与多余死循环步骤。
Token/Cost
Token 与经济成本 (Cost Efficiency)： 统计完成单个成功任务所消耗的 Prompt/Completion Tokens 及物理美元费用（例如单任务 $0.15 美元）。
Tool F1
Tool 选型精确度与召回率 (F1 Score)： 评估 Agent 在复杂状态下选中目标工具（Tool Choice）的精准度（Precision）与召回率（Recall）。
物理本质：把非确定性的推理转化为确定性的多维概率数据指标

2. Pass@k 无偏估计与 Harness 评估代码

Pass@k Estimator & Trajectory Analytics

Harness Eval Code
# Pass@k 数学无偏估计计算公式 (HumanEval / SWE-bench 标准)
def calculate_pass_at_k(n: int, c: int, k: int) -> float:
"""n: 尝试采样总次数, c: 通过单测的正确次数, k: k选1索引"""
if
n - c < k:
return 1.0
prob_fail = math.comb(n - c, k) / math.comb(n, k)
return 1.0 - prob_fail

# 评估 Harness 计算单 Task 轨迹综合得分
def evaluate_agent_trajectory(run_log: dict) -> dict:
steps = len(run_log["steps"])
cost = run_log["total_tokens"] * 0.000015
is_passed = run_log["sandbox_unit_test"] == "PASSED"
return {"passed": is_passed, "steps": steps, "cost_usd": cost}
  • 避免简单平均数偏置：使用组合数 $\text{Pass}@k = 1 - \frac{\binom{n-c}{k}}{\binom{n}{k}}$ 准确估计采样方差。
  • 集成 SWE-bench 标准：把测试结果绑定到 CI/CD 流程中，低于预设 Pass@1 门槛直接阻断合并。
