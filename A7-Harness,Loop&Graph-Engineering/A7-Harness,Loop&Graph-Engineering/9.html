容错图转变拓扑：Retry Policy 与异常捕获边

消除网络抖动与工具崩溃导致的整图熔断：结合节点级 指数退避自动重试 (RetryPolicy) 与 物理异常向状态增量（Exception-to-State Patch）的转化，驱动条件边动态切入降级自愈路由（Fallback Recovery Node）

1. 节点级指数退避自动重试 (Retry Policy)

Transient Error Recovery & Exponential Backoff

Transient Retry
# 声明节点专属的瞬时错误重试策略 (RetryPolicy)
from langgraph.pregel import RetryPolicy

retry_policy = RetryPolicy(
initial_interval=1.0, # 初始等待 1 秒
backoff_factor=2.0, # 指数倍增系数 2x
max_interval=10.0, # 最大等待 10 秒
max_attempts=3, # 最多重试 3 次
retry_on=[HTTPError, TimeoutError] # 指定重试异常
)

builder.add_node("api_node", call_tool, retry=retry_policy)
  • 隔绝瞬时抖动 (Transient Errors)：针对网络超时、大模型限流（429 Too Many Requests）自动静默重试。
  • 零状态副作用：在重试成功前不修改 Shared State，确保图计算过程的原子性。
物理本质：图节点粒度的透明自动愈合切面

2. 异常转状态补丁与降级路由 (Catch Edges)

Exception-to-State Patch & Conditional Recovery

Catch Route
# 节点内部捕获物理异常并转译为 State Patch
def safe_action_node(state: AgentState) -> dict:
try:
res = run_sandbox_code(state["code"])
return {"status": "SUCCESS", "output": res}
except Exception as e:
# 🛡️ 将 Crash 物理崩溃转化为常规状态字段
return {"status": "FAILED", "error_log": str(e)}

# 条件边读取 status 自动分流至修复节点或降级节点
builder.add_conditional_edges("safe_action", route_recovery_edge)
  • 崩溃转状态 (Exception to State)：防止未经处理的 Exception 穿透图运行时，将其包装为受控 `error_log`。
  • 自愈回路 (Self-Correction Loop)：条件边感知道 `status == "FAILED"`，自动驱动控制流指向代码修补或人工兜底节点。
物理本质：将无序的进程崩溃映射为确定性的图状态转移

Architectural Core Thesis / 架构师视角

把代码崩溃转化为图状态字典更新（State Mutation），是实现图状态机自我恢复的关键！通过给底层节点配置 RetryPolicy 吸收网络抖动，并在节点内部把不可避免的崩溃捕获并包装为结构化 `error_log`，才能让控制流平滑跳转至修复与自愈分支。
