Checkpointer 存储引擎：SqliteSaver, PostgresSaver 与 RedisSaver 架构

因地制宜选择状态落盘介质：解构单机轻量 SqliteSaver、企业级强一致 PostgresSaver (JSONB 索引) 与超高吞吐内存缓存 RedisSaver，实现通过统一 `BaseCheckpointSaver` 抽象的零代码开发环境环境无缝切换

1. SqliteSaver

Single-File File-based Engine

Dev / POC
# 本地零配置单文件 SQLite 持久化
import sqlite3
from langgraph.checkpoint.sqlite import SqliteSaver
conn = sqlite3.connect("agent_checkpoints.db")
checkpointer = SqliteSaver(conn)
  • 单文件开箱即用：免去外部数据库依赖，适合本地单元测试、Cli 命令行交互与 POC 验证。
  • 轻量低开销：线程内 SQLite 连接简单直接，无网络 IO 延迟开销。
定位：本地开发、单元测试与嵌入式轻量级客户端首选

2. PostgresSaver

ACID Distributed RDBMS Engine

Enterprise Prod
# Postgres 生产级 JSONB 事务持久化
from psycopg_pool import ConnectionPool
from langgraph.checkpoint.postgres import PostgresSaver
pool = ConnectionPool(conninfo="postgres://...")
checkpointer = PostgresSaver(pool)
  • ACID 事务与 JSONB 索引：支持多副本分布式事务锁与原生 JSONB 高效条件检索。
  • 长期审计履历：天然集成数据库连接池 (Connection Pool)，完美适配高并发生产集群。
定位：企业级高可用、多租户隔离与合规审计日志首选

3. RedisSaver

In-Memory Key-Value Session Cache

High Throughput
# Redis 极速内存 Hash 缓存
import redis
from langgraph.checkpoint.redis import RedisSaver
r = redis.Redis(host='localhost', port=6379)
checkpointer = RedisSaver(r)
  • 微秒级低延时：基于 Redis 内存 Hash 数据结构，提供极高读写 QPS，原生支持 TTL 自动过期机制。
  • Session 级短期状态：适合高并发客服对话、短生命周期工作流与高频状态轮询。
定位：高并发 C 端对话 Session 缓存、短期状态极速暂存首选

Unified BaseCheckpointSaver Abstraction Architecture / 统一 Checkpointer 抽象与环境解耦拓扑

Storage Decoupling Pattern
存储引擎 / Engine SqliteSaver PostgresSaver RedisSaver
物理介质 / Medium 单文件 SQLite 数据库 PostgreSQL 关系型集群 (JSONB) Redis 内存数据库 (Hash/Key-Value)
吞吐能力 / Throughput 中等 (受单文件 IO 限制) 高 (支持连接池与水平分库) 极高 (微秒级内存读写 QPS)
过期策略 / Data TTL 需手动清理表数据 分区表清理或定时 SQL 归档 原生 Key TTL 自动过期挥发

Architectural Core Thesis / 架构师视角

面向接口编程，而不是面向具体数据库编程！通过继承统一的 BaseCheckpointSaver 接口，架构师能够保证 Agent 图业务代码与底层存储引擎彻底解耦；开发阶段使用 SQLite 快速单步调试，生产环境零代码修改直接挂载 PostgreSQL 或 Redis 基础设施。
