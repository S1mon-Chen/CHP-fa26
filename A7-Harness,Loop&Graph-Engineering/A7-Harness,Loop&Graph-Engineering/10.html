第 7 课：控制流工程 · 模块一小结

模块一小结：图工程与有向有环图技术选型路线图

总结图工程四大原语（State、Nodes、Edges、Reducers）：深度对比 LangGraph (StateGraph / DCG)、LlamaIndex Workflows (Event-driven) 与 Temporal (Industrial Distributed Workflow) 的适用边界与技术选型权衡

1. LangGraph

Cyclic State Machine (DCG)

Agent State Engine
# 声明式 StateGraph 强类型拓扑
builder = StateGraph(AgentState)
builder.add_conditional_edges(...)
app = builder.compile(checkpointer)
  • 状态归约与图环：原生支持 `Annotated[list, add]` 归约合并与复杂 Cycles 回溯自愈。
  • 时光旅行与持久化：内置 `SqliteSaver` / `PostgresSaver` 支持多轮会话回溯与 HITL 打断。
定位：复杂 Agent 推演、代码自愈与多智能体（Swarm）首选

2. LlamaIndex Workflows

Event-Driven Step Handlers

Event-Driven
# 事件驱动 Step 装饰器模式
@step
async def my_step(ctx, ev: StartEvent) -> StopEvent:
return StopEvent(result=...)
  • 基于事件流解耦：节点间通过抛出 `Event` 与监听 `Context` 触发流转，非显式邻接表定义。
  • RAG 亲和力高：与 LlamaIndex 向量检索、Chunking 与 Query Engine 零成本原生集成。
定位：RAG 密集型检索管道、文档问答工作流选型首选

3. Temporal / Cadence

Durable Distributed Orchestrator

Distributed Engine
# 工业级持久化事件重放 (Durable Execution)
@workflow.defn
class AgentWorkflow:
workflow.execute_activity(...)
  • 分布式长作业持久化：跨多语言（Java/Go/Python），极强高可用、事务锁与跨月定时调度。
  • 融合模式：将 LangGraph 状态图封装为 Temporal Activity 节点，兼顾 AI 与微服务架构。
定位：超大规模分布式微服务编排、长生命周期企业流程

Framework Feature Comparison & Selection Matrix / 框架特性对比选型拓扑

Architecture Decision Tree
评估维度 / Dimension LangGraph (StateGraph) LlamaIndex Workflows Temporal Engine
状态拓扑 / Topology 有向有环图 (DCG / Cycles) 事件驱动步图 (Event-Driven) 分布式工作流 (Durable Graph)
状态归约 / Reducers 原生支持 (`Annotated`, `add`) 事件 Context 键值读写 工作流私有变量状态持锁
时光旅行 / Time Travel 原生 (`checkpoint_id` 回溯/Fork) 需依赖手动 Event 重放 事件历史自动 Replay 还原

Architectural Core Thesis / 架构师视角

简单工作流用线性 DAG，复杂的自我纠偏与多 Agent 协同必须选择带状态归约器 (Reducers) 的 DCG 图引擎！理解 State、Nodes、Edges 与 Reducers 四大原语，能让架构师在 LangGraph、LlamaIndex Workflows 与 Temporal 之间做出最精准的技术选型。
