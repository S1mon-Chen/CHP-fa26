控制流与沙箱工程“八大法则”

The 8 Control Flow Architect Golden Rules

8 Redlines
1. 有向有环 (DCG Graph)

用有向有环图表达 ReAct 循环、重试与自愈。

2. 显式收敛 (Convergence)

显式挂载 END 节点，搭配 `recursion_limit`。

3. 持久快照 (Checkpointer)

基于 Postgres/Redis 原子保存节点状态快照。

4. 时光旅行 (Time Travel)

凭借 `checkpoint_id` 精确回溯节点与 Fork。

5. 蜂群隔离 (Swarm Scope)

Supervisor 隔离子 Agent 局部草稿，保护全局。

6. 死锁熔断 (Loop Guards)

结合动作指纹去重与 Token 配额拦截震荡。

7. 物理隔离 (MicroVM Sandbox)

不可信代码置于 E2B，断绝出站网络与特权。

8. 确定性 Harness (Pass@k)

拦截写副作用确定性回放，依托 Pass@k 跑分。
