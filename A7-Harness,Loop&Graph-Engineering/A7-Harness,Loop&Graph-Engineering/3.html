状态图 (State Graph) 核心架构：State、Nodes 与 Transitions 关系解构

解构 LangGraph / Workflows 的三大数学物理组件：用强类型 Shared State (共享状态) 承载上下文变迁，用单一职责的 Nodes (离散计算节点) 隔离计算与副作用，用纯函数 Transitions / Edges (有向边) 路由图状态流动

1. Shared State (共享状态)

TypedDict / Pydantic Contract

State Memory
// 全局单源真理数据契约
class AgentState(TypedDict):
messages: Annotated[list, add]
generated_code: str
test_errors: str | None
retry_count: int
  • 全局单源真理 (SSOT)：充当图运行时的唯一上下文集市，节点间不直接传递对象，只读写 State。
  • 归约器 (Reducers)：支持追加（`add`）、合并与覆盖更新机制，防止并发修改数据丢失。
物理本质：图运行时的持久化内存数据快照（State Snapshot）

2. Nodes (离散计算节点)

Pure Python Functions / Handlers

Discrete Functions
// 接收 State，仅返回局部修改
def write_code_node(state: AgentState):
code = llm.generate(state["messages"])
return {
"generated_code": code,
"retry_count": state["retry_count"] + 1
}
  • 单一职责原理 (SRP)：每一个 Node 仅完成一项确定操作（如推理、调工具、跑测试、写 DB）。
  • 增量写补丁 (Partial Mutation)：Node 返回局部字典，框架自动将其与 Shared State 进行智能 Merge。
物理本质：接收状态并输出增量变更补丁的纯函数运算单元

3. Transitions (有向边与路由)

Normal & Conditional Edges

Control Edges
// 确定性边与条件边路由
builder.add_edge("START", "write")
def route_eval(state: AgentState):
if state["test_errors"]: return "write"
return "END"
builder.add_conditional_edges("eval", route_eval)
  • 普通边 (Normal Edges)：无条件直接推进指针（如 A $\to$ B）。
  • 条件边 (Conditional Edges)：读取当前 State，依靠 Python 纯函数推导动态决定下一个 Node 或向 `END` 收敛。
物理本质：决定状态流转指针（Pointer）跳转方向的控制逻辑

State Graph Interaction Topology / 状态图三大核心组件交互拓扑

State-Machine Mechanics
1. Shared State
Global Dict (Single Source of Truth)
2. Node Execution
Read State & Output Partial Patch
3. Conditional Edge
Eval State -> Route Next Node / END

Architectural Core Thesis / 架构师视角

把业务逻辑打散为纯函数节点（Nodes），把流转控制留给有向边（Edges），把上下文传递收敛至强类型状态（State）！这种解耦保证了每一个 Node 都可以独立单测与替换，而控制流完全由清晰的有向边与条件函数接管。

Speaker Notes / 讲师讲稿
🎯 状态图三大三大物理要素讲授重点： “向学员深入剖析：为什么 LangGraph 和 LlamaIndex Workflows 都会抽象这三要素？首先，State 相当于共享数据库（Shared Memory）；Node 相当于无状态微服务函数；Edge 相当于 API 路由。Node 读取 State 算完后返回 Partial Dict，再由 Edge 决定下一个调哪个 Node。”
💡 强调 Partial State Mutation（局部状态修改）： “重点引导学员注意 Node 函数的输入输出：Node 的输入是读全局全量 State，但输出仅需返回发生改变的局部字典（例如 `{'retry_count': 1}`）。这种设计降低了 Node 的编写复杂度，也是图状态机实现增量更新（Reducers）的核心支撑。”
