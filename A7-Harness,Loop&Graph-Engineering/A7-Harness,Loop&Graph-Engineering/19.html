Wrapping StateGraph inside @activity.defn

Integration Spec
# 1. 将 LangGraph 编译图定义封装为 Temporal Activity 节点
from temporalio import activity, workflow

@activity.defn
async def run_langgraph_agent_activity(params: dict) -> dict:
config = {"configurable": {"thread_id": params["ticket_id"]}}
return await langgraph_app.ainvoke(params["input"], config=config)

# 2. Temporal 宏观工作流控制：调用 AI Activity 并挂载跨天定时器与 Saga 回滚
@workflow.defn
class EnterpriseTicketWorkflow:
@workflow.run
async def run(self, ticket: dict) -> dict:
ai_res = await workflow.execute_activity(
run_langgraph_agent_activity, ticket,
start_to_close_timeout=timedelta(seconds=300)
)
await workflow.sleep(timedelta(days=7)) # Temporal 支持跨数月定时器！
return ai_res
  • 无限超时与定时睡眠（跨月 Sleep）：Temporal 原生支持 `workflow.sleep(days=30)`，挂起时不消耗任何物理 CPU，解决 HTTP 超时痛点。
  • Saga 事务补偿机制：若 AI 推理完成后物理结算出错，Temporal 可自动触发逆向 Activity 执行数据撤销与补偿。
物理本质：以持久化事件重放（Event Sourcing Replay）驾驭高风险 AI 事务
