1. 重构蜂群四类微智能体 (Micro-Agents) 职责解耦

Specialized Micro-Agents Persona Matrix

Swarm Matrix
Triage Agent
工单与 Issue 分诊路由： 解析 GitHub Issue 与慢 SQL 警报，提取目标模块，初始化 `RefactorSwarmState`。
Coder Agent
重构代码补丁生成器： 专注于根据目标规则生成 Unified Diff 补丁，挂载 `ast_parser` 工具进行静态自检。
Tester Agent
沙箱单元测试校验器： 在 E2B MicroVM 沙箱中应用 Patch 并跑 Pytest，捕获 Traceback 作为变动 Observation。
Reviewer Agent
OWASP 安全与共识卡扣： 审查代码越界风险与安全性；通过验证后给出 `APPROVED` 触发自动 PR 提交。
物理本质：把全能大 Agent 拆解为强类型、受控路由的多微智能体图网络

# Capstone 多 Agent 重构蜂群核心拓扑声明 (LangGraph)
builder = StateGraph(RefactorSwarmState)
builder.add_node("triage_agent", triage_node)
builder.add_node("coder_agent", coder_subgraph) # 挂载 Coder 子图
builder.add_node("tester_sandbox", e2b_tester_node) # E2B 沙箱测试
builder.add_node("reviewer_agent", reviewer_node)

# 条件边：根据沙箱测试结果与 Review 共识动态分流
builder.add_conditional_edges("tester_sandbox", route_test_feedback)
builder.add_conditional_edges("reviewer_agent", consensus_gate_edge)
app = builder.compile(checkpointer=SqliteSaver(conn))
  • 零破坏物理试错：代码 Patch 在 E2B 隔离沙箱（`network_mode="none"`）中运行，100% 杜绝写破坏。
  • 时光旅行自愈（Time-Travel Rollback）：单测连续报错 3 次后自动触发 `checkpoint_id` 回溯，重选方案。
物理本质：建立在确定性状态图、零信任沙箱与共识卡扣基础上的全自动重构平台
