开始前 / 这是一份可离线阅读的教学文档
  1. 在项目目录激活 .venv，安装依赖；命令均在项目根目录执行。
  2. 真实 scripted 需要 Docker 与教学镜像；live 还需要 Ollama。无 Docker 可显式加 --simulate，或回放已有记录。
  3. 命令块不会在网页中执行。复制后到终端运行；RUN_ID、CHECKPOINT_ID 必须替换为实际记录。
  4. 投屏模式用 ← / → 翻页，Esc 返回文档。展开代码可阅读更多上下文；行号来自生成时源码。
cd bookstore-agent-harness
source .venv/bin/activate
python -m harness.web --port 8766

若服务已在 8766 运行，直接访问 http://127.0.0.1:8766；不要重复启动。命令展示预期结果，不表示本次已执行。
