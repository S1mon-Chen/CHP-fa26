class EnterpriseCodeRefactorSkill(BaseSkill):
    def __init__(self):
        self.router = IntentRouterGate()
        self.breaker = CircuitBreaker(fail_max=3)
        self.pruner = LogPruningMiddleware()

    def execute(self, repo_path: str, query: str) -> SkillResult:
        # 1. Router 路由：动态路由挂载 Top-K 相关重构工具 ★
        skills = self.router.route_and_mount(query, top_k=2)

        # 2. Dry-Run 预演：物理写入前捕获 Git 快照 (Stash) ★
        stash_id = self.git.create_snapshot_stash()
        
        try:
            # 3. Fallback 断路器：API 异常瞬间降级至本地算法 ★
            if self.breaker.is_closed():
                patches = self._parallel_ast_refactor(repo_path, skills)
            else:
                patches = self._fallback_local_grep_refactor(repo_path)

            # 4. 沙箱测试与原位 Undo：测试报错原位撤销 + Log 提纯 ★
            test_log = self.sandbox.run_pytest()
            if "FAILURES" in test_log:
                self.git.rollback_stash(stash_id)
                pruned_err = self.pruner.compress_observation(test_log)
                return SkillResult(status="ROLLED_BACK", error=pruned_err)
                
            return SkillResult(status="SUCCESS", patches=patches)
        except Exception as err:
            self.git.rollback_stash(stash_id)
            return SkillResult(status="ERROR", error=str(err))
  • 多模式闭环合力：将原本脆弱的重构脚本升级为带有预演路由、断路降级与原位 Undo 撤销的真正工业级 Skill。

综合重构 Skill 的四大模式柱石

4 Pattern Network Pillars

Network Spec
1. Router 意图路由门控 Tool Crop

在进入代码分析前，通过意图路由网关剔除 95% 不相干的微服务工具，锁定当前任务专属的 AST 解析组件。

2. Fallback 断路器与降级 Circuit Breaker

监控云端高精语法分析 API 状态；若连续 3 次超时或 5xx 报错则打开断路器，平滑切换至本地 `git grep` 规则重构。

3. Dry-Run 预演与快照 Undo Git Stash Undo

真实写入前抓取 Git Stash 快照。只要物理沙箱中的 pytest 测试抛错，瞬间触发原位撤销，恢复仓库初始干净状态。

4. Log Pruning 日志语义提纯 Context Slimming

针对几千行的构建日志，通过正则与首尾视窗提纯出最关键的 `FAILURES` 堆栈，压缩至 200 Tokens 后再返回给 Agent 修复。

Architectural Module 2 Conclusion / 模块二总结

单一设计模式解决局部问题，设计模式网络（Pattern Network）解决系统性崩溃；通过组合 Router、Composite、Fallback 与 Dry-Run Undo，构建既灵活又绝对安全的受控 Skill 体系。
