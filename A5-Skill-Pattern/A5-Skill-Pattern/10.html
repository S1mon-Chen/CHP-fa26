架构师选型决策网络 (Selection Tree)

Skill Standard Decision Framework

Decision Tree
场景 A：团队 IDE/CLI 辅助编程 Claude Code `SKILL.md`

维保于 Git `.claude/skills/`，团队共享统一的代码规范检查、重构 Workflow 与本地 Lint 工具。

场景 B：金融/电商写操作微服务 Spring AI Managed Bean

涉及物理数据库改动与资金状态更新，要求 `@Transactional` 事务回滚、`SecurityContext` 鉴权与物理强类型。

场景 C：跨语言统一 Agent 技能中台 SKILL.md + Dynamic Advisor

一套 Markdown 规范既能给开发人员本地 CLI 使用，又通过 ResourcePatternResolver 动态装载进后端微服务中。

Architectural Module 1 Conclusion / 模块一总结

架构师应当根据“物理作用域”与“状态副作用风险”制定技能标准：IDE 辅助编程优先落地 SKILL.md 开放规范，后端写微服务优先落地 **Spring AI 托管 Bean**，打通双模中台演进。
