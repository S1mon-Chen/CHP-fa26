回归测试与 CI/CD 卡扣：防止 Prompt/Skill 修改引发的隐蔽退化

把守 Git PR 代码合并的最后一道安全关口：将自动化 Skill 回归测试套件 (Regression Suite) 集成至 CI/CD 流水线，对新旧版本做 量化 Delta 指标比对 ($\Delta \text{Pass@1}$, $\Delta \text{F1}$)，若降幅超过门限硬性 阻断 PR 合并 (Block PR Merge)

SkillRegressionGateRunner 代码实现

CI/CD PR Merge Quality Gate Engine

CI/CD Gate 
class SkillRegressionGateRunner:
    def __init__(self, max_allowed_drop_percent: float = 1.0):
        self.max_drop = max_allowed_drop_percent

    def verify_pr_quality(self, pr_metrics: SkillMetrics, base_metrics: SkillMetrics):
        # 1. 计算 Pass@1 准确率与 Tool Choice F1 变化量 Delta ★
        pass_at_1_delta = (pr_metrics.pass_at_1 - base_metrics.pass_at_1) * 100
        f1_delta = (pr_metrics.f1_score - base_metrics.f1_score) * 100

        # 2. 检查退化指标：若 Pass@1 或 F1 跌幅超过 1% 即打断 CI ★
        if pass_at_1_delta < -self.max_drop or f1_delta < -self.max_drop:
            raise RegressionGateFailedException(
                f"BLOCKED: Regression Detected! Pass@1 Δ: {pass_at_1_delta:.2f}%, F1 Δ: {f1_delta:.2f}%"
            )

        # 3. 检查费用暴涨卡扣：USD 单任务成本增长率不得超 15% ★
        cost_increase_pct = ((pr_metrics.avg_cost_usd - base_metrics.avg_cost_usd) / base_metrics.avg_cost_usd) * 100
        if cost_increase_pct > 15.0:
            raise CostGateFailedException(f"BLOCKED: Token Cost Influx! +{cost_increase_pct:.1f}% USD")

        return "PR_QUALITY_GATE_PASSED"
  • 强硬合并卡扣：只要修改 `SKILL.md` 触发指标跌幅，Git PR 自动挂掉 CI/CD Check 阻断合并。
核心：将不可预期的 Prompt 微调转化为 CI/CD 中绝对客观的可量化门控

CI/CD 回归门控的三大工程支柱

3 Core Pillars of CI/CD Quality Gate

CI Gate Pillars
1. GitHub/GitLab Actions 自动化触发 (PR Trigger) Automated CI Pipeline

当开发者提交更改 `.claude/skills/` 或 Prompt 契约的 PR 时，流水线自动触发后端物理测试套件与 Eval Harness。

2. 增量指标差值校验 ($\Delta \text{Metrics Gate}$) Delta Threshold Check

读取主干分支（Main Branch）的基线指标，若分支上的测试导致 Pass@1 降幅超过 1% 或单任务 Token 费用飙升，直接阻断合并。

3. 归因诊断报告与 GitHub PR 评论关联 (PR Comment Report) Automated Attribution

将具体的退化用例、错唤醒的工具名与生成的错误日志整理成 markdown 报告，自动挂载为 GitHub PR 评论，帮助开发者快速定位。
