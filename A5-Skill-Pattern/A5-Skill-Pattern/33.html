class SkillEvalHarness:
    def __init__(self, judge_llm):
        self.judge = judge_llm

    def evaluate_sample(self, sample: EvalSample, agent_output: SkillResult) -> SampleScore:
        # 1. 第一阶：静态确定性物理断言（Tool & 入参匹配）★
        tool_match = (agent_output.selected_skill == sample.expected_skill)
        args_match = (agent_output.args == sample.expected_args)
        
        if not (tool_match and args_match):
            return SampleScore(passed=False, score=0.0, reason="STRICT_SCHEMA_MISMATCH")

        # 2. 第二阶：LLM-as-a-Judge 裁判语义打分 (用于复杂的生成结果) ★
        judge_prompt = f"""
        [USER QUERY]: {sample.query}
        [EXPECTED OUTCOME]: {sample.expected_rubric}
        [ACTUAL SKILL OUTPUT]: {agent_output.observation}
        Evaluate on a scale of 0.0-1.0 and output JSON with 'score' and 'reason'.
        """
        eval_resp = self.judge.evaluate_structured(judge_prompt)
        
        return SampleScore(
            passed=(eval_resp.score >= 0.85),
            score=eval_resp.score,
            reason=eval_resp.reason
        )
  • 双阶高可信评分：用物理相等断言卡死工具与入参，用 LLM 裁判量化自然语言与代码生成的准确度。
核心：将模糊的主观体验评估升级为包含评分量规（Rubric）的自动化工程评测

自动化 Skill Eval Harness 三大工程支柱

3 Core Pillars of Eval Harness

Harness Pillars
1. 生产级基准数据集 (Ground-Truth Benchmark) Dataset Construction

采集中线上真实 100+ 边界 Query，标注标准期望工具名、必填参数与评定量规（Rubric），形成版本化的 Ground-Truth 测试套件。

2. 混合校验引擎 (Hybrid Eval Engine) Assertions + LLM-as-a-Judge

一阶通过 Pydantic / AST 做零误差物理硬断言；二阶引入独立裁判模型（如 Claude 3.5 / GPT-4o）对生成的代码与总结进行语义打分。

3. 自动化分析与归因报告 (Automated Attribution) CI/CD Report Export

批量导出 JSON/HTML 测评分析报表，自动对误唤醒（FP）、漏唤醒（FN）、语法错误与超时分类归因，直接绑定 Git PR 流程。

将模型评价交给代码和裁判引擎！构建 Ground-Truth 标注基准集与双阶裁判引擎 (Assertions + LLM-as-a-Judge)，是驱动技能 Prompt 持续迭代且不凭运气说话的黄金支撑工具。
