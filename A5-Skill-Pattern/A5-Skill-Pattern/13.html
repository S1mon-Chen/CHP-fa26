复合技能组合模式 (Composite Pattern)：原子 Skill 的拓扑编排与流水线组合

消杀多阶决策不确定性的工程利器：将 离散原子 Skill (AST/Scanner/Patcher) 组装为 高内聚复合 Skill (AutoSqliFixer)，内部采用确定性多阶流水线，对大模型仅暴露单进单出受控节点

CompositeAutoSqliFixerSkill 实现

Multi-Stage Skill Orchestration Engine

Composite Skill 
class CompositeAutoSqliFixerSkill(BaseSkill):
    def __init__(self):
        self.parser = ASTParserSkill()      # 原子 Skill 1: AST 结构提取
        self.scanner = SQLiScannerSkill()   # 原子 Skill 2: 静态漏洞扫描
        self.patcher = CodePatcherSkill()   # 原子 Skill 3: 语法树修补

    def execute(self, repo_path: str) -> FixReport:
        # 阶段一：前置只读扫描（确定性代码逻辑）★
        ast_tree = self.parser.parse_dir(repo_path)
        vulns = self.scanner.scan_ast(ast_tree)
        if not vulns: return FixReport(status="CLEAN")

        # 阶段二：生成修复补丁并在沙箱单测校验 ★
        patch = self.patcher.generate_and_test(vulns)
        return FixReport(status="FIXED", patch=patch)
  • 降低大模型决策深度：LLM 只需决策一次 “是否调用 `AutoSqliFixer`”，内部 3 步复杂的代码解析与单测完全由代码流控制。
核心：用确定性的多阶代码流水线取代 LLM 多轮非确定性的工具选择

复合技能组合模式的三大核心支柱

3 Core Pillars of Composite Pattern

Composite Pillars
1. 认知负荷削减 (Cognitive Load Reduction) 1-Step Decision

将需要 LLM 连续进行 3~5 轮 Tool Calling 的长决策链，压缩为一次单一调用，避免多轮推理过程中发生“累积漂移”。

2. 内部确定性编排 (Deterministic Inner Pipeline) Code-Level Safety

在复合技能内部，子步骤的数据校验、临时缓存、单测拦截与异常捕获完全使用高性能代码固化，确保物理安全。

3. 接口封装与可重用性 (Encapsulated Reusability) High Cohesion Node

遵循面向对象“组合优于继承”理念，复合 Skill 拥有清晰统一的 OpenAPI Schema 输入与输出，可继续被更上层系统复用。

Architectural Core Thesis / 架构师视角

能用软件代码决定的多阶流水线，决不让大模型在多轮对话中随机推演！通过 复合技能组合模式 (Composite Pattern) 隐藏多阶复杂性，是消除 Agent 长链条崩溃与提升任务成功率（Pass Rate）的关键范式。

🎯 讲授 Composite Pattern 的核心痛点： “向学员深入剖析：在实际 Agent 场景中，许多复杂的任务需要先解析 AST、再跑静态扫描、再自动修补代码。如果把这 3 个步骤当成 3 个独立的原子工具暴露给大模型，模型在多轮交互中经常会出现遗漏步骤、参数传递错误或逻辑中断。”
💡 强调面向对象设计模式在 AI 时代的延伸： “提示学员：复合技能模式（Composite Pattern）通过将多个原子 Skill 包装在一个高阶 Skill 内部，内部运行确定性的 Python/Java 步骤逻辑，对外只暴露一个 `AutoSqliFixer`。大模型只需决策一次，大幅降低了决策累积误差。”
