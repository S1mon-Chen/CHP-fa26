死循环与死锁检测器 (Infinite Loop Detection)：动作指纹与图环检测

斩断 Agent 无意义递归与资费暴刷的算力锁：基于 SHA-256 动作指纹哈希 (Fingerprint Hash) 与 滑动窗口图环检测 (Graph Ring Detector)，在连续 3 次产生相同动作指纹时强行截断，注入 “强制改变策略”反思 Prompt

ActionFingerprintGuard 实现

Fingerprint Hash & Graph Ring Detector

Loop Guard 
import hashlib, json

class ActionFingerprintGuard:
    def __init__(self, max_repeated_threshold: int = 3):
        self.threshold = max_repeated_threshold
        self.history_hashes = []

    def calculate_fingerprint(self, tool_name: str, args: dict) -> str:
        # 1. 规范化 JSON 字段顺位并计算 SHA-256 动作指纹 ★
        raw_str = f"{tool_name}:{json.dumps(args, sort_keys=True)}"
        return hashlib.sha256(raw_str.encode()).hexdigest()

    def inspect_step(self, tool_name: str, args: dict) -> GuardCheckResult:
        fp_hash = self.calculate_fingerprint(tool_name, args)
        self.history_hashes.append(fp_hash)

        # 2. 检查尾部滑动窗口指纹重复频次 ★
        recent_tail = self.history_hashes[-self.threshold:]
        if len(recent_tail) == self.threshold and len(set(recent_tail)) == 1:
            # 触发死循环：阻断物理执行，强刷策略反思 Prompt ★
            return GuardCheckResult(
                is_loop=True,
                action="BLOCK_AND_INJECT_REFLECTION",
                prompt="SYSTEM ALERT: You called identical action 3 times! CHANGE STRATEGY!"
            )
        return GuardCheckResult(is_loop=False)
  • 阻断物理无效耗算：在 Agent 尝试第 3 次调用一模一样的工具参数瞬间物理阻断，不给无效 RPC 执行机会。
核心：用确定性 Hash 指纹池监控 LLM 的非确定性行为，死锁发生时强行插干预

死循环与死锁检测的三大防护支柱

3 Core Pillars of Loop Detection

Loop Safeguards
1. 规范化 Hash 指纹计算 (SHA-256 Fingerprinting) Action Fingerprint

将 `tool_name` 连同 JSON 入参的排序序列化键值（`sort_keys=True`）压缩生成 64 位 Hash 指纹，消除 JSON 格式缩进差异的影响。

2. 拓扑环与滑动窗口检测 (Ring & Cyclic Detection) Sliding Window Ring

不仅检测单一动作的连续重复，还能通过有向图环（A $\to$ B $\to$ A $\to$ B）检测多步骤交互的死锁拓扑环，防止间接循环。

3. 渐进式强制打断与策略强修正 (Reflection Injection) Strategy Steering

第一次重复注入警告 Prompt，引导模型自愈修正；若模型连续 5 次仍无法跳出循环，触发 Circuit Breaker 强行退栈熔断。
