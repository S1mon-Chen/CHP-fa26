技能工程架构师“八大法则”

The 8 Architect Redline Rules

8 Redlines
1. 契约优先 (Schema First)

通过 SKILL.md 与 Pydantic 确立无歧义接口。

2. 双模兼容 (Dual Ecology)

融合 Claude Code 声明式与 Spring AI 托管 Bean。

3. 模式组合 (Pattern Net)

组合 Router/Composite/Fallback 防范单点故障。

4. 物理隔离 (Safety Barrier)

高危写操作前置 Dry-Run 预演与 HITL 审批卡扣。

5. 防腐隔离 (ACL Shield)

用 DDD 防腐层与脱敏管道屏蔽外部接口变动。

6. 死锁熔断 (Loop & Budget)

通过 SHA-256 动作指纹去重与 Token 硬配额卡扣。

7. 结构自愈 (Structured Error)

将 Exception 转化为包含代码切片的诊断 Observation。

8. 评测守护 (Eval Gate)

用基准集测试与 CI/CD 差值门控防止隐蔽退化。
