Spring AI 原生 Java Skill 开发：@Bean / @Description / FunctionCallback 契约

Java 声明式 AI 技能开发范式：借助 Spring `@Bean` 声明、`@Description` 语义注入 与 Java Record 契约 DTO，实现自动 JSON Schema 导出与 `FunctionCallback` 确定性回调

Spring AI `@Bean` 声明式 Skill 代码

Spring AI Declarative Skill Spec

Spring AI Bean 
@Configuration
public class PaymentSkillConfig {

    @Bean
    @Description("Queries user payment history by user ID with date filtering")
    public Function<PaymentQueryRequest, PaymentQueryResponse> paymentQuerySkill(PaymentService paymentService) {
        return request -> paymentService.query(request.userId(), request.startDate());
    }
}

// Java Record DTO 自动推导导出标准的 OpenAPI JSON Schema ★
public record PaymentQueryRequest(
    @JsonProperty(required = true) String userId,
    String startDate
) {}

public record PaymentQueryResponse(boolean success, List<PaymentRecord> records) {}
  • 零模板冗余代码：声明标准 `java.util.function.Function` Bean 即可被 Spring AI 框架自动识别并注册。
核心：由 `@Description` 注入 LLM 语义指导，由 Record 类结构反向生成 JSON Schema

Spring AI 原生 Skill 的三大契约优势

3 Core Pillars of Spring AI Java Skill

Bean Contract
1. 声明式 `@Description` 语义 Intent Prompt

通过 `@Description` 注解注入自然语言指导。Spring AI 自动将此描述提取为 API Request 载荷中的 `description` 字段。

2. Java Record 自动导出 Schema Zero-Drift Schema

框架借助 Jackson 与 Class 反射自动分析 Request/Response Record 的字段与 `@JsonProperty` 标注，推导生成准确的 JSON Schema。

3. `FunctionCallback` 底层桥接 Callback Dispatch

Spring AI 将注册的 Function Bean 封装为 `FunctionCallback`，在模型触发 `tool_calls` 时完成反序列化并自动分发给 Lambda 执点。

Architectural Core Thesis / 架构师视角

Spring AI 实现了“Java 原生类型系统”与“大模型 Function Calling 协议”的自动桥接；开发者只需编写标准 `Function` 接口与 Java Record，即可获得无漂移的 OpenAPI Schema 导出与容器级确定性回调。

Speaker Notes / 讲师讲稿
🎯 讲授 Spring AI 的声明式开发范式： “向学员剖析：在 Spring AI 生态里，开发一个 Java Skill 非常自然。开发者只需要在 `@Configuration` 类中声明一个 `Function` 类型的 `@Bean`，加上 `@Description` 注解说明该工具的作用。Spring AI 在启动时会自动扫描该 Bean，利用 Jackson 分析 Record 字段，自动导出无歧义的 OpenAPI Schema。”
💡 强调与 Python Pydantic / FastMCP 的异曲同工： “提示学员注意对比：这与 Python 生态中使用 Pydantic 或 FastMCP 的原理完全一致（都是依靠代码类型与注解导出 Schema）。但 Java 生态的强类型（Java Record）和依赖注入（Autowiring Service）赋予了这种 Skill 更强的编译期校验与企业级架构支撑能力。”
