class ProductionSkillController:
    def __init__(self, registry, db_saver):
        self.registry = registry
        self.loop_guard = ActionFingerprintGuard(max_repeated_threshold=3)
        self.cost_guard = TokenBudgetAndRateLimitGuard(max_tokens=50000, max_steps=10)
        self.sanitizer = ObservationSanitizerPipeline()
        self.checkpoint_mgr = StateGraphCheckpointManager(db_saver)
        self.error_formatter = StructuredErrorFormatter()

    async def execute_task_loop(self, thread_id: str, user_query: str) -> str:
        # 1. 断点续传：恢复上一次崩溃处的最新 State Snapshot ★
        state = self.checkpoint_mgr.resume_or_init(thread_id, user_query)

        while not state.is_finished:
            # 2. 硬配额卡扣：检查步数与 Token 算力预算 ★
            check_res = self.cost_guard.check_and_consume(state.current_tokens)
            if not check_res.allowed:
                return self._graceful_partial_report(state, check_res.reason)

            action = await self.llm.predict_next_action(state.messages)
            
            # 3. 动作指纹哈希：强行拦截连续重复死循环 ★
            loop_res = self.loop_guard.inspect_step(action.tool_name, action.args)
            if loop_res.is_loop:
                state.append_system_warning(loop_res.prompt)
                continue  # 注入 Warning 强引策略修正

            # 4. 执行分发，结构化报错抓取与 PII/AK/SK 脱敏 ★
            try:
                raw_obs = await self.registry.dispatch(action)
                clean_obs = self.sanitizer.sanitize(raw_obs)
            except Exception as raw_err:
                clean_obs = self.error_formatter.format_exception(raw_err)

            # 5. 更新 Context 并将最新快照保存至持久库 (Redis/Postgres) ★
            state.update(action, clean_obs)
            self.checkpoint_mgr.save_node_snapshot(thread_id, state)

        return state.get_final_summary()
  • 完整工程闭环：单文件聚合死锁熔断、预算控制、脱敏管道、结构化报错与断点续传，直接用于生产级 Agent。
核心：用确定性系统控制器包裹非确定性 LLM 决策，筑牢企业级生产安全底线

控制器四大鲁棒性防护子系统

4 Core Robustness Subsystems

Control Pillars
1. 动作指纹死锁检测 (Action Fingerprint Guard) Anti-Loop

通过 `SHA-256` Hash 监测尾部重复动作；连续 3 次相同调用时强行阻断并注入策略重导向 Prompt。

2. 配额预算与优雅降级 (Cost Guard & Quota) Token & Step Caps

绑定 Max Steps ($N \le 10$) 与 Token 算力预算 ($T \le 50,000$)；触顶时触发熔断并导出 Partial Summary。

3. 观察日志脱敏管道 (Observation Sanitizer) Secret & PII Redaction

拦截物理工具返回值，在写入 Message Context 前由正则与 NER 管道清洗抹除明文 AK/SK 密钥与客户 PII。

4. 状态图 Checkpoint 恢复 (Graph Checkpointing) Persistence & Resume

在每个控制转换点提取状态快照保存至 Redis/DB，服务器重启后通过 `thread_id` 实现秒级原位断点续传。
