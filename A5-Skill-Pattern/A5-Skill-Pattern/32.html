class SkillEvalMetricsEngine:
    def evaluate_batch(self, eval_dataset: list[EvalSample], runner) -> SkillEvalResult:
        total = len(eval_dataset)
        pass_at_1_count, total_cost_usd = 0, 0.0
        tp, fp, fn, latencies_ms = 0, 0, 0, []

        for sample in eval_dataset:
            start_t = time.time()
            res = runner.run(sample.query)
            latencies_ms.append((time.time() - start_t) * 1000)

            # 1. 意图召回率 (F1-Score): 评估选工具的精准度 ★
            if res.selected_skill == sample.expected_skill:
                tp += 1
                # 2. Pass@1 准确率: 首 Turn 参数填充与物理执行零报错 ★
                if res.args == sample.expected_args and res.is_exec_success:
                    pass_at_1_count += 1
            else:
                if res.selected_skill: fp += 1
                if sample.expected_skill: fn += 1

            # 3. 经济开销 (Cost USD): 计算每次调用的算力账单 ★
            total_cost_usd += res.tokens_consumed * COST_PER_TOKEN

        f1_score = 2 * tp / (2 * tp + fp + fn + 1e-9)
        return SkillEvalResult(
            pass_at_1 = pass_at_1_count / total,
            f1_score = f1_score,
            avg_cost_usd = total_cost_usd / total,
            p95_latency_ms = np.percentile(latencies_ms, 95)
        )

Skill 评测四大核心量化柱石

4 Core Evaluation Pillars

4 Pillars
1. Pass@1 物理零缺陷执行率 (Pass@1 Accuracy) First-Turn Zero Defect

衡量 1st-turn 生成的入参填报率与物理沙箱单测一次通过率，不依赖二次 Self-Correction 补救。

2. 意图召回 F1 值 (Tool Choice F1-Score) Precision & Recall

评估模型在面对 50+ 技能池时选择目标 Skill 的调和平均数，综合惩罚误唤醒（FP）与漏唤醒（FN）。

3. Token 算力与经济开销 (Execution Cost in USD) Dollar per Benchmark Task

统计单次评估任务所消耗的 Prompt/Completion Tokens 对应的美元成本，防止 Context 膨胀导致资费爆炸。

4. 端到端响应时延 (P95 Latency & TTFT) Latency & TTFT Metrics

记录首 Token 延迟（TTFT）与 P95 物理工具执行完毕时间，确保 Agent 响应速度满足企业 SLA 要求。
