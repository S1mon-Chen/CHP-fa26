class CiCdRefactorAgentOrchestrator:
    def __init__(self, spring_ai_hub, git_repo):
        self.router = IntentRouterGate()                  # 1. 门控路由网关 ★
        self.auditor = CompositeAuditorSkill()             # 2. 复合审计技能 ★
        self.sec_service = spring_ai_hub.get_service()     # 3. Spring AI 托管服务 ★
        self.patcher = DryRunGitPatcherSkill(git_repo)     # 4. 预演撤销修补技能 ★

    async def process_pr_webhook(self, pr_event: PREvent) -> AgentResult:
        # Step A: 路由匹配——仅针对 PR 变更文件精准挂载需求技能
        target_skills = self.router.route_and_mount(pr_event.diff_summary)

        # Step B: 复合静态扫描 (Tree-Sitter + Semgrep 静态分析)
        audit_report = await self.auditor.scan_codebase(pr_event.repo_path)
        if audit_report.is_clean: return AgentResult(status="PR_APPROVED")

        # Step C: 调用 Spring AI 后端服务，生成受控修复代码
        fix_proposal = await self.sec_service.generate_fix(audit_report)

        # Step D: 预演校验 + Docker 沙箱单测 + Git Stash 自动 Undo 撤销 ★
        return await self.patcher.apply_with_safety_guard(fix_proposal)
  • 端到端高可用闭环：结合路由门控、复合扫描、强类型后端与预演撤销修补，构成完全自治的企业级 Agent 管道。
核心：将前两模块掌握的设计模式与第三方模块的鲁棒性工程彻底熔铸一体

CI/CD Agent 四层分层架构详解

4 Architectural Layers of Capstone Agent

4 Layers
1. 意图路由门控层 (Intent Router Gate Layer) Router Pattern

根据 Git PR 触发的文件路径与语种，动态挂载关联 Skill，剔除 90% 不相干的微服务 API 说明，保护 Context Window。

2. 复合审计技能层 (Composite Auditor Layer) Composite Pattern

将 `Semgrep` 静态代码规则与 `Tree-Sitter` AST 语法解析合并为高内聚 Skill，对 LLM 暴露单一高阶检查接口。

3. Spring AI 托管服务层 (Spring Managed Service Layer) Spring AI & Security

后端使用 Spring Boot 托管 `@Bean` 函数，自动触发 `@Transactional` 事务回滚与 `@PreAuthorize` 物理权限鉴权。

4. 预演撤销修补层 (Dry-Run & Rollback Patcher Layer) Dry-Run & Stash Undo

物理写入前创建 Git Stash 快照，在 Docker 无网络沙箱中跑单测；单测失败瞬间触发 `git checkout .` 撤销物理状态。
