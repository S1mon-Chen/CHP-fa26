Spring AI 对 SKILL.md 的双模兼容与动态装载机制

打通 Java 强类型与 Markdown 声明式契约的桥梁：借助 Spring AI ResourcePatternResolver 装载器 与 Skill Frontmatter 解析器，实现 Java Bean 工具 与 SKILL.md 双模兼容 动态注入 Advisor 链

Spring AI `SKILL.md` 动态解析与装载

Dual-Mode Skill Registry & Advisor Chain

Dual-Engine 
@Configuration
public class SkillRegistryConfig {

    @Bean
    public SkillRegistry springAISkillRegistry(ResourcePatternResolver resolver) {
        SkillRegistry registry = new SkillRegistry();
        // 1. 读取项目级与个人级 SKILL.md 规范 ★
        Resource[] resources = resolver.getResources("file:.claude/skills/**/SKILL.md");
        for (Resource res : resources) {
            SkillSpec spec = SkillMdParser.parse(res); // 解析 YAML + MD
            registry.register(spec);
        }
        return registry;
    }
}

// 2. 在 ChatClient 调用时无缝混合挂载双模工具 ★
ChatResponse response = chatClient.prompt()
    .advisors(new DynamicSkillAdvisor(skillRegistry)) // 动态注入 SKILL.md 规范
    .functions("updateOrderStatusSkill")                  // 绑定 Java 强类型 Bean
    .call();
  • 前后端规范统一：前端 CLI（Claude Code）与后端 Spring AI 使用同一份 Git 托管的 `SKILL.md`。
核心：由 Advisor 链完成 `SKILL.md` 动态 Prompt 注入，由 Function 挂载 Java 强类型代码

Spring AI 双模兼容的三大架构支柱

3 Core Pillars of Dual-Mode Compatibility

Dual-Mode Spec
1. 双模统一注册表 Unified Skill Registry

Java `@Bean` 强类型 Function 与 Markdown `SKILL.md` 声明式规范并存，统一暴露给框架路由层与 LLM 门控。

2. Advisor 链动态注入 Dynamic Advisor Pipeline

利用 Spring `ResourcePatternResolver` 扫描 `.claude/skills/` 路径，将 `SKILL.md` 正文自动转换为 `SystemMessage` 动态干预推理。

3. 跨平台与跨语言架构中台 Cross-Platform Hub

一套 `SKILL.md` 文件既能被 Claude Code / Cursor CLI 本地直接运行，又能被后端的 Spring AI 框架解析吸纳，消除厂商锁定。

Architectural Core Thesis / 架构师视角

Spring AI 的双模装载架构实现了“Markdown 声明式规范”与“Java 原生类型系统”的无缝融合；团队维保的同一套 SKILL.md 既能在 IDE 插件端驱动 Agent 辅助编程，也能在后端 Spring 微服务中动态生效。
