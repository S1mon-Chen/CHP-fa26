Spring WS 配置与 WSDL 契约动态生成

MessageDispatcherServlet, DefaultWsdl11Definition & Dynamic WSDL Exposure

1. Spring WS 核心配置组件机制 Servlet & WSDL Publishing

Spring WS 通过独立于 Spring MVC 的核心前端控制器 **`MessageDispatcherServlet`** 拦截 SOAP 请求，并利用 **`DefaultWsdl11Definition`** 在内存中基于 `.xsd` 模式文档动态构建出符合规范的 `.wsdl` 契约文档。

`MessageDispatcherServlet` 拦截器 SOAP Front Controller

替代 Spring MVC 的 `DispatcherServlet`，专门解析 XML/SOAP 报文并把请求路由给 `@Endpoint` 标注的处理类。

`DefaultWsdl11Definition` 契约生成器 Dynamic WSDL

自动将内存中的 XSD Schema 包装为 WSDL 1.1 规范文档。其 Bean 名称（如 `countries`）决定了暴露的 WSDL 访问 URL 路径（`http://localhost:8080/ws/countries.wsdl`）。

Spring WS 运行时访问端点 (Runtime Endpoints)
SOAP 消息服务入口 POST http://localhost:8080/ws
动态 WSDL 契约 URL GET http://localhost:8080/ws/countries.wsdl
自动化增强：`transformWsdlLocations(true)` 自动修正绝对物理 IP 地址
2. WebService 配置类 (`WebServiceConfig.java`) WebServiceConfig.java
package io.spring.guides.gs_producing_web_service;
import org.springframework.ws.config.annotation.*;
import org.springframework.ws.transport.http.MessageDispatcherServlet;
import org.springframework.ws.wsdl.wsdl11.DefaultWsdl11Definition;
import org.springframework.xml.xsd.*;
@EnableWs
@Configuration
public class WebServiceConfig extends WsConfigurerAdapter {
@Bean
public ServletRegistrationBean<MessageDispatcherServlet> messageDispatcherServlet(ApplicationContext context) {
MessageDispatcherServlet servlet = new MessageDispatcherServlet();
servlet.setApplicationContext(context);
servlet.setTransformWsdlLocations(true);
return new ServletRegistrationBean<>(servlet, "/ws/*");
}
@Bean(name = "countries")
public DefaultWsdl11Definition defaultWsdl11Definition(XsdSchema countriesSchema) {
DefaultWsdl11Definition wsdl = new DefaultWsdl11Definition();
wsdl.setPortTypeName("CountriesPort");
wsdl.setLocationUri("/ws");
wsdl.setTargetNamespace("http://spring.io/guides/gs-producing-web-service");
wsdl.setSchema(countriesSchema);
return wsdl;
}
@Bean
public XsdSchema countriesSchema() {
return new SimpleXsdSchema(new ClassPathResource("countries.xsd"));
}
}
@EnableWs 激活 Web Service

开启 Spring WS 框架的注解驱动与请求处理器映射注册机制。

架构亮点：无需手工维护易错的 .wsdl 静态文件，修改 XSD 即可自动更新契约

核心架构机制 (Dynamic WSDL Generation Insight)

通过注册 **`DefaultWsdl11Definition`**，Spring WS 会在运行时扫描内存中的 `XsdSchema`，自动拼装出符合 WSDL 1.1 规范的完整的 WSDL 文本。当客户端访问 `http://localhost:8080/ws/countries.wsdl` 时，Spring 实时回传此 XML 契约文档。

Speaker Notes / 讲师讲稿
🎯 引导学生透视 MessageDispatcherServlet： “向学员强调：Spring WS 使用专门的 `MessageDispatcherServlet` 拦截 SOAP 路径（`/ws/*`），区别于 Spring MVC 的 `DispatcherServlet`。这种清晰隔离使得服务端可以同时支持 RESTful JSON 与 SOAP Web Services 两套服务端点。”
