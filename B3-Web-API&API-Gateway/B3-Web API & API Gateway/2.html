课程大纲与教学目标

从 SOAP 重量级契约到 RESTful 面向资源架构，再到现代化 API 网关治理的核心能力演进

课程模块路线图 (Module Roadmap) Slide 3 - Slide 35
P1

Part 01: SOAP 协议与 XML 契约机制

Slide 3 - 10

跨平台互操作性、SOAP 消息信封、WSDL 抽象/具体契约解析、Spring WS 模式优先开发与痛点分析。

P2

Part 02: RESTful 架构风格与资源设计

Slide 11 - 20

Roy Fielding 6 大架构约束、资源与 URI 命名规范、HTTP 动词与幂等性、星巴克咖啡状态机案例。

P3

Part 03: Spring Boot REST 开发与 CORS 安全

Slide 21 - 28

`@RestController` 与 Java Record、内容协商机制、OpenAPI 3.0 (Swagger)、CORS 跨域预检流程。

P4

Part 04: 现代化 API 网关与治理决策

Slide 29 - 35

Web API 权衡法则、API 网关 4 大核心职责、Spring Cloud Gateway 限流实战与架构决策树。

核心教学目标 (Learning Objectives) 5 Capabilities
1

理解分布式系统中跨硬件、跨操作系统与跨编程语言的异构互操作性原理。

2

掌握 SOAP、WSDL 与 XSD 契约规范，能基于 Spring WS 进行契约优先（Schema-First）服务生产与消费。

3

深刻理解 Roy Fielding REST 架构约束，掌握面向资源（Resource-oriented）的 URI 命名与状态机流转。

4

熟练在 Spring Boot 中构建 RESTful 端点，解决 CORS 跨域预检（OPTIONS）并集成 SPA 客户端。

5

掌握现代 API 网关 4 大治理职责（路由、安全、限流、协议转换）与云原生技术选型。

核心考核要求：能力贯穿“契约设计 $\rightarrow$ 接口实现 $\rightarrow$ 网关治理”

第 3 讲教学逻辑主线

沿着“为什么需要 Web API $\rightarrow$ SOAP 为何过于沉重 $\rightarrow$ RESTful 如何优雅面向资源抽象 $\rightarrow$ API 网关如何集中治理”的技术演进路线展开学习！
