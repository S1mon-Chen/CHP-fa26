XML Schema Definition (countries.xsd) & Spring WS Annotation-Driven Endpoint (CountryEndpoint.java)

<!-- 1. 请求节点: 接收国家名称进行查询 -->
<xs:element name="getCountryRequest">
<xs:complexType>
<xs:sequence>

</xs:sequence>
</xs:complexType>

<!-- 2. 响应节点: 返回强类型的 Country 实体 -->
<xs:element name="getCountryResponse">
<xs:complexType>
<xs:sequence>

`@Endpoint` 核心端点注解 Spring WS Managed

将当前 Java 类注册为 Spring WS 的 SOAP 处理端点（类似于 Spring MVC 中的 `@Controller`）。

`@PayloadRoot` 请求路由映射 Routing Rule

根据 SOAP Body 中 XML 元素的 `namespace`（命名空间）和 `localPart`（节点名称 `getCountryRequest`）把请求精确路由到目标 Java 方法。

自动化契约：JAXB 将 XML 中的 `getCountryRequest` 自动反序列化为 Java DTO
2. Spring WS 端点组件实现 (`CountryEndpoint.java`) CountryEndpoint.java
package io.spring.guides.gs_producing_web_service;
import org.springframework.ws.server.endpoint.annotation.*;
import org.springframework.beans.factory.annotation.Autowired;
@Endpoint
public class CountryEndpoint {
private static final String NAMESPACE_URI =
"http://spring.io/guides/gs-producing-web-service";
private CountryRepository countryRepository;
@Autowired
public CountryEndpoint(CountryRepository countryRepository) {
this.countryRepository = countryRepository;
}
@PayloadRoot(namespace = NAMESPACE_URI, localPart = "getCountryRequest")
@ResponsePayload
public GetCountryResponse getCountry(
@RequestPayload GetCountryRequest request) {
GetCountryResponse response = new GetCountryResponse();
response.setCountry(countryRepository.findCountry(request.getName()));
return response;
}
}
@RequestPayload 参数解包

告知 Spring WS 将输入的 SOAP `` Payload 自动解包并转换成 Java 对象。

@ResponsePayload 返回封包

告知 Spring WS 将方法的返回值 `GetCountryResponse` 序列化为标准的 XML SOAP Response 报文。

架构收益：无需处理底层的 SAAJ XML DOM 节点树，直接以面向对象 OOP 方式编写业务

核心架构机制 (Spring WS Processing Mechanism)

Spring WS 在收到 HTTP SOAP 请求时，首先由核心 Servlet 拦截 XML 报文，提取出 `` 内容，利用 **`@PayloadRoot`** 中定义的命名空间和元素名称匹配目标 Handler 方法，最后借助 JAXB2 插件生成的 DTO 类实现 XML 与 Java 对象的自动转换。
