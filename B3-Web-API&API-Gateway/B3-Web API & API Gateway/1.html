Web API 20 年演进历史路线图 / 20-Year Evolution Roadmap

2000s $\rightarrow$ 2010s $\rightarrow$ 2020s+
2000s: SOAP Era
XML + WSDL + SOAP (RPC / 重度契约)
2010s: RESTful Era
JSON + HTTP Verbs + URI + OpenAPI
2020s+: Modern API Era
REST (External) + gRPC (Internal) + API Gateway
