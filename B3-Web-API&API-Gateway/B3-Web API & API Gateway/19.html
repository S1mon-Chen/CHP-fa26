Spring Boot 构建 RESTful 服务：注解与数据映射

@RestController, @GetMapping, @PostMapping, Java 17 Record DTOs & Jackson JSON Serialization

1. Spring Boot REST 核心注解体系与 Java Record Annotation Reference
`@RestController` 组合注解 @Controller + @ResponseBody

告知 Spring 框架当前类中的所有 Handler 方法默认均返回**数据**而非视图 (View)。返回值由 HttpMessageConverter（如 Jackson）自动序列化为 JSON/XML。

HTTP 动词快捷路由注解 Verb Mapping

@GetMapping、@PostMapping、@PutMapping、@DeleteMapping 明确将 HTTP 动词绑定至具体的方法端点。

Java 17+ `record` 不可变数据载体 (DTO) Java Record DTO

使用简洁的语法定义不可变响应数据结构 public record Greeting(long id, String content) {}，替代繁琐的 Lombok 或 Getter/Setter 模版代码。

自动化能力：Jackson 自动实现 Java Record / POJO 与 JSON Payload 的双向编解码
2. RESTful 控制器与 Record 实现 GreetingController.java
package com.example.restservice;
import java.util.concurrent.atomic.AtomicLong;
import org.springframework.web.bind.annotation.*;
// 1. DTO 实体：使用 Java 17+ Record 定义不可变数据结构
public record Greeting(long id, String content) { }
@RestController
public class GreetingController {
private static final String template = "Hello, %s!";
private final AtomicLong counter = new AtomicLong();
@GetMapping("/greeting")
public Greeting greeting(
@RequestParam(value = "name", defaultValue = "World") String name) {
return new Greeting(counter.incrementAndGet(), String.format(template, name));
}
@PostMapping("/greeting")
public Greeting greetingPost(
@RequestParam(value = "name", defaultValue = "Spring") String name) {
return new Greeting(counter.incrementAndGet(), String.format(template, name));
}
}
GET /greeting?name=User 返回 {"id": 1, "content": "Hello, User!"}
POST /greeting 默认返回 {"id": 2, "content": "Hello, Spring!"}

核心架构启发 (Spring Boot RESTful Development Insight)

Spring Boot 通过 **@RestController** 与 **Java 17+ record** 极大地简化了 RESTful 端点开发。框架自动完成 HTTP 映射、入参绑定、状态码回传与数据序列化，开发者可以专注于核心业务逻辑建模。
