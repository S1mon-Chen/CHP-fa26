1. 高性能缓存架构四大黄金设计法则 (Golden Rules)

Caching Rules
Ⅰ. 优先选用 Cache-Aside 模式，更新 DB 后擦除 Cache

更新缓存不如直接失效缓存；双写一致性推荐使用 **`Canal + Binlog + MQ` 异步无侵入清理** 彻底解耦。

Ⅱ. 超级热点流量引入 L1 Caffeine 进程内内存屏障

结合 Redis Pub/Sub 广播失效事件，让 95%+ 的读请求在 JVM 内存中纳秒级返回，彻底解除网络 Socket 带宽瓶颈。

Ⅲ. 善用概率型数据结构打造极低内存占用

防穿透用**布隆过滤器**，海量 UV 用 **HyperLogLog (12KB)**，大模型 Prompt 用 **Redis Stack HNSW 语义缓存**。

法则：用物理内存遮蔽磁盘低延时，用降级与锁保护核心数据库
