Spring Boot + Caffeine + Redis 二级缓存综合整合实战

L1 Caffeine Local Cache (Nanoseconds) + L2 Redis Distributed Cache (Microseconds) & CompositeCacheManager Assembly

1. 二级缓存分层管线与配置参数

L1 + L2 Architecture
// 二级缓存查询执行管线 (Query Pipeline)
1. 读请求 $\to$ L1 Caffeine Cache (JVM 进程内存)
├── Hit: 秒级返回 (~10ns, 零网络开销)
└── Miss: 继续下查 L2...
2. L1 Miss $\to$ L2 Redis Cluster (集中式内存集群)
├── Hit: 填补回 L1，返回结果 (~1ms)
└── Miss: 穿透至底层 RDBMS...
3. L2 Miss $\to$ L3 MySQL RDBMS $\to$ 写入 L2 与 L1
缓存层级 L1 本地缓存 (Caffeine) L2 分布式缓存 (Redis)
存储位置 JVM 堆内内存 (Direct RAM) Redis 集中式内存集群
TTL 策略 短 TTL (如 10 秒) 降低数据漂移 长 TTL (如 30 分钟) 保护 DB
容量上限 受限于 JVM 堆容量 (如 10,000 项) TB 级 (可集群横向扩容)
配合 Pub/Sub 广播：写请求修改 DB 时发送广播擦除各节点的 L1 本地缓存

2. 生产级 `MultiLevelCacheConfig.java` 组装代码

CompositeCacheManager
// MultiLevelCacheConfig.java 组合二级缓存管理器配置
@Configuration
@EnableCaching
public class MultiLevelCacheConfig {
// 1. 装配 L1 CaffeineCacheManager Bean
@Bean
public CaffeineCacheManager caffeineCacheManager() {
CaffeineCacheManager manager = new CaffeineCacheManager();
manager.setCaffeine(Caffeine.newBuilder()
.maximumSize(10_000) // 10000 条容量上限
.expireAfterWrite(10, TimeUnit.SECONDS)); // 10s 短过期防漂移
return manager;
}
// 2. 装配 L2 RedisCacheManager Bean
@Bean
public RedisCacheManager redisCacheManager(RedisConnectionFactory factory) {
RedisCacheConfiguration config = RedisCacheConfiguration.defaultCacheConfig()
.entryTtl(Duration.ofMinutes(30)) // L2 30min 长过期
.serializeKeysWith(RedisSerializationContext.SerializationPair.fromSerializer(new StringRedisSerializer()))
.serializeValuesWith(RedisSerializationContext.SerializationPair.fromSerializer(new GenericJackson2JsonRedisSerializer()));
return RedisCacheManager.builder(factory).cacheDefaults(config).build();
}
// 3. 组合管理器 CompositeCacheManager (按声明顺序依次查找 L1 -> L2)
@Bean @Primary
public CompositeCacheManager compositeCacheManager(CaffeineCacheManager l1, RedisCacheManager l2) {
return new CompositeCacheManager(l1, l2); // 列表首位为优先匹配层
}
}
