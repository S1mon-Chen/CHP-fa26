2. 声明式微服务五大核心组件 (5 Core Pillars)

Pillars Breakdown
① API Gateway 统一入口 (Spring Cloud Gateway) Netty Reactive

基于 Spring 5 + Project Reactor 非阻塞响应式流，负责流量统一路由重写、CORS 跨域、JWT 统一安全校验与全局限流。

② 服务注册与发现 (Eureka / Nacos) Dynamic Discovery

维护微服务实例 IP/Port 动态注册表，心跳检测，配合客户端负载均衡器（Spring Cloud LoadBalancer）实现自动寻址。

③ 集中配置中心 (Config Server / Nacos) Hot Refresh

集中化管理各环境配置（dev/test/prod），支持基于广播推拉机制的热加载刷新（`@RefreshScope`），免重启应用。

④ 容错熔断降级 (Resilience4j / Sentinel) Circuit Breaker

异常率或慢调用比例超标自动跳闸开路，强行拦截请求并触发 Fallback 降级函数，防止局域网级联雪崩。
