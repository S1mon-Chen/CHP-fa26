2. 核心微服务指标与 PromQL 规则 (PromQL Metrics)

Micrometer Metrics
① HTTP 吞吐与分位数延迟 (QPS & P99 Latency) Request Metrics
http_server_requests_seconds_count

实时计算接口 QPS 及 P95/P99 延迟水准。当 P99 延迟突破 500ms 时触发阈值警告。

② JVM 堆内存与 GC Stop-The-World 停顿 JVM Metrics
jvm_gc_pause_seconds_sum

监控垃圾回收（Old Gen GC）频次与 STW 停顿累计时间，防范 JVM 内存泄漏或频发 Full GC。

③ Resilience4j 断路器状态 (Circuit Breaker State) Resilience4j
resilience4j_circuitbreaker_state

实时上报断路器开闭状态（0=CLOSED, 1=OPEN, 2=HALF_OPEN），当变成 `OPEN` 时瞬间拉响紧急告警。
