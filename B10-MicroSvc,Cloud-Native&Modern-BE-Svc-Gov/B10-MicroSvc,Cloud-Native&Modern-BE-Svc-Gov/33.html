2. Dapr 5 大核心构建块 API 与组件无缝替换 (APIs)

Dapr APIs
① State Management (状态存储) POST /v1.0/state
POST http://localhost:3500/v1.0/state/statestore

存储状态键值对。底层可以自由从 Redis 替换为 Cassandra 或 DynamoDB，无需修改一行业务代码。

② Pub/Sub (发布订阅消息) POST /v1.0/publish
POST http://localhost:3500/v1.0/publish/pubsub/orders

广播事件消息。通过配置 YAML 即可将底层消息中间件从 Kafka 无缝切换为 RabbitMQ 或 AWS SNS/SQS。

③ Secrets & Bindings (秘钥管理与输入输出绑定) GET /v1.0/secrets

统一拉取 HashiCorp Vault、AWS Secrets Manager 秘钥，并自动将事件与外部 S3 / Kafka / Twilio 绑定。

Dapr 架构进化启发 (Dapr Architecture Insight)

如果说 **Istio/Envoy** 解决了 **网络 L4/L7 层流量治理**，那么 **Dapr** 则进一步解决了 **应用 L7 层分布式中间件能力绑定**。两者结合构成了云原生时代极致的多语言、低耦合、开箱即用的后端微服务基础设施。
