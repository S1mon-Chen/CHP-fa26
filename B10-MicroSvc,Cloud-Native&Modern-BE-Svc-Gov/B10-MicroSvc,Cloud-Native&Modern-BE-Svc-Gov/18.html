Part 02 · 服务注册发现与负载均衡

微服务 Demo 实战：`book-service` 与 `user-auth` 注册演练

Multi-Service Cluster Architecture: `book-service` (11130) & `user-auth` (11230) Dynamic Registration

1. Demo 微服务拓扑与 `application.yaml` 挂载配置

YAML Config
// 1. book-service/src/main/resources/application.yaml
server:
port: 11130
spring:
application:
name: book-service
eureka:
client:
registerWithEureka: true
fetchRegistry: true
serviceUrl:
defaultZone: http://localhost:8040/eureka
// 2. user-auth/src/main/resources/application.yaml
server:
port: 11230
spring:
application:
name: user-auth
eureka:
client:
serviceUrl:
defaultZone: http://localhost:8040/eureka
关键：业务服务通过相同的 `defaultZone` 统一挂载至 Eureka 注册中心 (`port: 8040`)

2. 业务端点与 Eureka 控制台注册校验

Endpoints & Dashboard
// BookController.java 购书业务端点
@RestController
public class BookController {
@RequestMapping("/buyBook")
public ResultDTO buyBook(
@RequestHeader("userName") String userName,
@RequestParam("bookName") String bookName) {
return ResultDTO.success(String.format(
"userName: %s, bookName: %s", userName, bookName));
}
}
