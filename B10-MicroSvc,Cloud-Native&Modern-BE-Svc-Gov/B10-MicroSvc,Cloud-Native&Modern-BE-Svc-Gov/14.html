Spring Cloud Eureka Server 服务端代码实战 (Eureka Server Setup Code)

Maven Dependencies, `@EnableEurekaServer` Annotation & Standalone Registry Configuration

1. 依赖声明与配置文件 (`pom.xml` & `properties`)

Maven & Config
// 1. pom.xml 引入 Eureka Server Starter 依赖
<dependencies>
<dependency>
<groupId>org.springframework.cloud</groupId>
<artifactId>spring-cloud-starter-netflix-eureka-server</artifactId>
</dependency>
</dependencies>
// 统一 BOM 版本管理 (dependencyManagement)
<dependencyManagement>
<dependencies>
<dependency>
<groupId>org.springframework.cloud</groupId>
<artifactId>spring-cloud-dependencies</artifactId>
<version>${spring-cloud.version}</version>
<type>pom</type>
<scope>import</scope>
</dependency>
</dependencies>
</dependencyManagement>
// 2. src/main/resources/application.properties
server.port=8761
eureka.client.register-with-eureka=false # 单机模式不向自己注册
eureka.client.fetch-registry=false # 单机模式不拉取注册表
提示：关闭 register-with-eureka 和 fetch-registry 是单机测试关口关键

2. 主启动类实现 (`ServiceRegistrationAndDiscovery...`)

@EnableEurekaServer
// 主启动类代码
@EnableEurekaServer // 声明开启 Eureka 注册中心服务端组件
@SpringBootApplication
public class ServiceRegistrationAndDiscoveryServiceApplication {
public static void main(String[] args) {
SpringApplication.run(ServiceRegistrationAndDiscoveryServiceApplication.class, args);
}
}
`@EnableEurekaServer` 物理工作原理 Auto Configuration

自动注入 Eureka 核心 Dashboard Web 控制台 UI、Jersey REST 接口、 Peer-to-Peer 复制节点管理器以及 PeerAwareInstanceRegistry 内存注册表。

默认端口 8761 与集群扩展 Default Port 8761

`8761` 是 Eureka Server 社区约定默认物理端口。生产环境部署集群时，只需修改 `serviceUrl.defaultZone` 指向其他 Eureka Server 节点 IP 即可完成对等复制挂载。

开启下一个核心：Slide 15 · Spring Cloud Eureka Client 客户端微服务注册代码实战

代码搭建启发 (Eureka Server Setup Insight)

得益于 Spring Boot 的自动配置（Auto-Configuration）机制，搭建一个可用的分布式服务注册中心仅需引入 `spring-cloud-starter-netflix-eureka-server` 依赖，并在主类加上一个 **`@EnableEurekaServer`** 注解即可轻松启动！
