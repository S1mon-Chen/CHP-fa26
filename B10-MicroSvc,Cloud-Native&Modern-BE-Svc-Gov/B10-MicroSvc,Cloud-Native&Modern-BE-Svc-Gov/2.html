第 10 讲：课程大纲与教学目标

从 DDD 领域拆分、注册发现与响应式网关，到 Serverless/FaaS、Service Mesh 边车与全维可观测性

课程模块路线图 (Module Roadmap) Slide 3 - Slide 40
P1

Part 01: 微服务演进与拆分

Slide 3 - 10

单体演进收益与挑战、DDD 限界上下文划界、一服务一库隔离、风险与故障防御公式。

P2

Part 02: 注册发现与负载均衡

Slide 11 - 18

服务发现物理原理、Eureka/Nacos/K8s 选型、Eureka Server/Client 代码与微服务 Demo。

P3

Part 03: 网关路由与容错熔断

Slide 19 - 25

Spring Cloud Gateway 响应式路由、Path 重写、CORS/JWT Filter 与 Resilience4j 断路器。

P4

Part 04: Serverless 与 FaaS 函数

Slide 26 - 30

Serverless 概念、Scale-to-Zero 弹性、Spring Cloud Function 反应式函数与多云适配。

P5

Part 05: Service Mesh 与三维可观测性

Slide 31 - 40

Sidecar 模式、Istio/Envoy/Dapr、OpenTelemetry 链路追踪、Prometheus 指标与 ELK 日志。

核心教学目标 (Learning Objectives) 5 Governance Objectives
1

能够根据业务需求，通过 DDD 限界上下文 进行微服务拆分，并掌握数据库隔离与消息驱动解耦。

2

掌握 服务注册与发现 (Eureka/Nacos) 与客户端动态负载均衡物理原理及 Spring Cloud 代码实现。

3

熟练掌握 Spring Cloud Gateway 响应式网关 的动态路由重写、JWT 鉴权 Filter 及 Resilience4j 熔断降级。

4

理解 Serverless / FaaS 物理优势与 Scale-to-Zero 弹性，能基于 Spring Cloud Function 编写事件函数。

5

掌握云原生 Service Mesh (Istio / Dapr 边车代理) 及 OpenTelemetry / Prometheus / ELK 可观测性体系。

定位：构建高弹性、高可用与全维可观测的云原生现代后端

第 10 讲教学主线哲学与终章收官

作为第二单元的终章，本讲将全面贯通计算、网关路由、消息通讯、分布式事务与海量检索，上升至云原生服务治理与 Service Mesh 全景。
