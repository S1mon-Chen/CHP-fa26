Circuit Breaker Tri-State Machine (CLOSED, OPEN, HALF-OPEN) & Functional Reactive Fault Tolerance

1. 断路器三态转化物理状态机 (State Machine)

State Machine
// 断路器三态自动转化时序 (Tri-State Transitions)
[ CLOSED (关闭/正常状态) ] 错误率 < 阈值 (如 50%)
全量流量正常通过，同时准实时统计失败率与慢调用比例。
▼ 异常率/慢调用超标 $\rightarrow$ 自动跳闸触发!
[ OPEN (开启/跳闸状态) ] 进入休眠窗口期 (Sleep Window 5s)
强行拦截后续请求，绝不发起真实 RPC，直接执行本地 Fallback 降级逻辑。
▼ 休眠期结束 $\rightarrow$ 试探性放行部分流量...
[ HALF-OPEN (半开试探状态) ] 探测下游健康状况
若试探请求成功率达标 $\to$ 恢复至 CLOSED；若依然报错 $\to$ 重新切回 OPEN。
目标：以微秒级拦截阻断雪崩传播，给下游故障微服务争取恢复时间

2. 容错框架演进：Netflix Hystrix 对比 Resilience4j

Hystrix $\to$ Resilience4j
Netflix Hystrix (停更/淘汰) Heavy Thread Pool

基于命令模式（Command Pattern），为每个依赖强制开辟独立线程池进行隔离。面对数百个依赖时线程上下文切换开销巨大，面向面向对象重度封装，已停更。

Resilience4j (现代响应式标准) Functional Vavr

专为 Java 8+ 和函数式编程（Vavr）设计的高性能轻量级容错库。极简模块化设计，完美支持 Project Reactor（Mono/Flux）响应式网关。

Resilience4j 五大核心轻量级模块 Modular Suite
CircuitBreaker 基于滑动窗口统计熔断
RateLimiter 频次速率限制 (漏桶/令牌桶)
Bulkhead 线程池/信号量隔离
Retry / TimeLimiter 指数退避重试与超时控制

断路器模式启发 (Circuit Breaker Insight)

断路器模式（Circuit Breaker）是微服务防雪崩的物理屏障。通过在网关或服务卡口监控异常率，一旦出现慢调用或宕机，断路器自动跳闸（`OPEN`）并触发 Fallback 降级，避免单个慢服务吃光整个系统的线程与内存。

Speaker Notes / 讲师讲稿
🎯 引导学员透视断路器三态转化机制： “向学员做解构说明：断路器模式就像家里的空气开关，包含三个状态：
1. **CLOSED (正常关闭)**：流量畅通，同时后台准实时统计错误率；
2. **OPEN (跳闸开启)**：错误率超标后自动跳闸，直接拦截流量并触发 Fallback 降级，避免漫长等待；
3. **HALF-OPEN (半开探针)**：休眠窗口期过完后放行部分探针流量，成功率达标恢复 CLOSED，失败重新切回 OPEN。”
