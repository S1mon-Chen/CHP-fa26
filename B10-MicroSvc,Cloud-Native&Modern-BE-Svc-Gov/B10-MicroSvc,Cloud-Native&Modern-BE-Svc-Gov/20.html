Maven Starter Dependencies, Programmatic Route Mapping & Gateway Filter Header Injections

1. 网关核心依赖声明 (`pom.xml`)

Maven Starters
// 1. pom.xml 引入 Spring Cloud Gateway & Resilience4j 依赖
<dependencies>
<dependency>
<groupId>org.springframework.cloud</groupId>
<artifactId>spring-cloud-starter-gateway</artifactId>
</dependency>
<dependency>
<groupId>org.springframework.cloud</groupId>
<artifactId>spring-cloud-starter-circuitbreaker-reactor-resilience4j</artifactId>
</dependency>
</dependencies>
⚠️ 依赖排他警告 (Exclusion Notice) No Servlet Starter

Spring Cloud Gateway 基于 Netty 响应式栈运行，**严禁引入 `spring-boot-starter-web` (Tomcat Servlet)** 依赖，否则会导致 Spring Boot 启动初始化冲突崩溃。

关键：支持基于 Reactive Netty 的完全非阻塞 I/O 管道处理

2. 编程式 `RouteLocatorBuilder` 动态路由绑定

RouteLocator Bean
// GatewayApplication.java 动态路由注册
@SpringBootApplication
@RestController
public class GatewayApplication {
public static void main(String[] args) {
SpringApplication.run(GatewayApplication.class, args);
}
@Bean
public RouteLocator myRoutes(RouteLocatorBuilder builder) {
return builder.routes()
.route(p -> p
.path("/get") // 谓词 Predicate: 匹配 /get 请求
.filters(f -> f.addRequestHeader("Hello", "World")) // 过滤器: 注入 Header
.uri("http://httpbin.org:80")) // 目标 URI
.build();
}
}
Predicate 与 Filter 协作机制 Pipeline Pipeline

• **Predicate (断言/谓词)**：决定请求是否符合路由条件（如 Path、Header、Cookie、Query）。
• **Filter (过滤器)**：在匹配成功的请求前/后修改 Request/Response（如注入 Header、重写 Path）。

编程式路由启发 (Programmatic Routing Insight)

Spring Cloud Gateway 既支持通过 `application.yaml` 进行声明式配置，也支持通过 **`RouteLocatorBuilder`** 在 Java 代码中进行编程式注册。利用链式 Lambda 表达，可以极其灵活地组合断言与过滤器。
