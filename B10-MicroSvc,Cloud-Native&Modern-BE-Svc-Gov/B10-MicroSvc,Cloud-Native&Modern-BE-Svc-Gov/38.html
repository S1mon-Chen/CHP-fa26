2. 全栈端到端四大关口职能精要 (4 System Stages)

Full Stack
① 边缘隔离与跨域 (Edge Gateway) MainGateway:8080

客户端唯一暴露入口，统一过滤 OPTIONS 预检请求，阻止任何未带合法 JWT 凭证的请求越界。

② 身份解包与 Header 注入 (JWT Auth Filter) Header Mutation

`JwtCheckFilter` 解码 HMAC256 签名，提取 `userName` 并利用 Request Mutate 将身份信息透明注入下发 Header。

③ 动态寻址与断路器保活 (Discovery & Circuit Breaker) Eureka & Resilience4j

从 Eureka (`8040`) 拉取 `BOOK-SERVICE` 活跃列表，由并发断路器监控慢调用，一旦出现故障快速触发 Fallback。

④ 目标业务逻辑执行 (`BOOK-SERVICE`: 11130) Target Endpoint

下游微服务无感知接收经过网关清洗和身份注入的规范请求，专注执行领域数据计算并返回 JSON 响应。
