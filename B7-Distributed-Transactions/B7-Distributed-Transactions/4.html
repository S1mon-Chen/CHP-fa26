Spring `@Transactional` 切面原理与 AOP 代理 (AOP Proxy Architecture)

Dynamic Proxy Wrappers, `TransactionSynchronizationManager`, ThreadLocal DB Connection Binding & Aspect Life Cycle

Spring 声明式事务 AOP 动态代理拦截与执行管线 (Transaction Aspect Execution Pipeline) TransactionInterceptor Intercepts Method Execution
1. Client Call Spring Proxy

客户端调用 Service。Spring 拦截器拦截调用，交由 TransactionInterceptor 处理。

2. 开启/加入事务 ThreadLocal Bind

获取 DB 连接，关闭 autoCommit(false)，并将其绑定到当前线程的 ThreadLocal。

3. 执行目标逻辑 Target Method

调用业务 Target Bean（如 transfer()）。物理 SQL 均复用绑定的 Connection。

4. 提交/回滚 & 清理 Commit/Rollback

无异常调用 commit()；捕获运行时异常调用 rollback()。最后清理 ThreadLocal。

1. 动态代理类型与连接线程绑定机制

Proxy & ThreadLocal

当容器在 Bean 加载期检测到类或方法标注了 @Transactional 时，Spring 自动生成 Proxy 对象：

JDK Dynamic Proxy vs. CGLIB

• **JDK 动态代理**：目标类实现了接口时使用（基于 InvocationHandler）。
• **CGLIB 代理**：目标类无接口时使用（通过生成目标类的子类字节码）。Spring Boot 2.x+ 默认全量开启 CGLIB。

TransactionSynchronizationManager

内部维护一个 ThreadLocal<Map<Object, Object>> resources，将获取的物理 Connection 与当前线程绑定，确保 DAO 层（JdbcTemplate / MyBatis）复用同一个 DB 连接。

法则：没有 AOP 代理包装，@Transactional 就只是一块无法执行的普通元数据

2. `@Transactional` 核心配置属性解析

Annotation Attributes
propagation

传播行为（默认 REQUIRED），控制嵌套事务加入/挂起。

isolation

隔离级别（默认 DEFAULT），遵循底层 DB 本地配置。

timeout

事务超时秒数，超时强行回滚并抛出 TransactionTimedOutException。

readOnly

只读标志，跳过 ORM 脏检查 (Dirty Checking) 优化性能。

rollbackFor / noRollbackFor

指定触发回滚的异常类型。**Spring 默认仅对 `RuntimeException` 和 `Error` 回滚**，必须显式配置 rollbackFor = Exception.class 防范 Checked Exception！

核心架构启发 (AOP Aspect Lifecycle Insight)

理解 @Transactional 的本质就是理解 **Spring AOP 代理模式**。事务拦截器在目标方法执行前关掉连接自动提交、在执行后捕获异常决定 commit 或 rollback，并通过 ThreadLocal 确保整条链路使用同一物理连接。

Speaker Notes / 讲师讲稿
🎯 引导学员理解 Spring 事务切面的物理时序： “向学员解构说明：当类加上 `@Transactional` 后，注入容器的并非原始 Target 对象，而是代理对象。代理对象在调用真实方法前，先从 DataSource 拿 Connection、设 `setAutoCommit(false)` 并绑定到 `ThreadLocal`，确保 DAO 操作共享同一连接。”
💡 强调 `rollbackFor` 默认规则的陷阱： “请特别提醒学员右侧卡片的 `rollbackFor` 属性：Spring 默认只在抛出 `RuntimeException` 或 `Error` 时触发回滚！对于 `Exception` 子类（Checked Exception，如 `IOException`），Spring **默认不会回滚**！生产代码中必须显式设置 `rollbackFor = Exception.class`。”
