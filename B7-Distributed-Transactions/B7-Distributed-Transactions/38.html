Seata 实战：`@GlobalTransactional` 在 Spring Boot 中的落地 (Code Practical)

Declarative Global Transaction Annotation, XID Propagation via Feign/RPC & Spring Boot YAML Configuration

`@GlobalTransactional` 声明式事务在微服务调用链中的执行管线 (Execution Pipeline) Zero Code Invasion: Intercepted by Seata Spring AOP Aspect
1. TM 开启全局事务 TM Begin

`OrderService` 带有 @GlobalTransactional。TM 切面拦截向 TC 申请开启全局事务并绑定全局唯一 XID。

2. Feign RPC 隐式透传 XID XID Propagation

Seata Feign 拦截器拦截 HTTP 请求，向 Request Header 中隐式注入 TX_XID，将下游 `Stock` 和 `Account` 服务绑定入同一个全局事务。

3. 异常拦截与自动回滚 Global Rollback

若任意分支（如账户余额不足）抛出 Exception，TM 捕获后通知 TC。TC 向各地 RM 下发反向 rollback 指令，依靠 `undo_log` 还原物理数据。

1. 订单服务主入口代码 (`OrderServiceImpl.java`)

Java Implementation
// 生产级分布式事务切面标注
@Service
public class OrderServiceImpl implements OrderService {
@Autowired private StockFeignClient stockFeignClient;
@Autowired private AccountFeignClient accountFeignClient;
@Autowired private OrderDao orderDao;
@GlobalTransactional(name = "create-order-tx", rollbackFor = Exception.class)
public void createOrder(OrderDTO orderDTO) {
log.info("开启全局分布式事务，XID = {}", RootContext.getXID());
// ① 本地新增订单记录 (Order DB)
orderDao.create(orderDTO);
// ② 远程 RPC 扣减库存 (Stock DB - Branch TX 1)
stockFeignClient.deduct(orderDTO.getCommodityCode(), orderDTO.getCount());
// ③ 远程 RPC 扣减账户余额 (Account DB - Branch TX 2)
accountFeignClient.debit(orderDTO.getUserId(), orderDTO.getOrderMoney());
}
}
本质：简单的 `@GlobalTransactional` 注解完全接管了底层极其繁琐的两阶段提交与回滚

2. Spring Boot 配置文件与服务分组配置 (`application.yml`)

YAML Config
seata:
enabled: true
tx-service-group: my_test_tx_group # 逻辑事务分组
service:
vgroup-mapping:
my_test_tx_group: default # 映射到 Seata TC 集群
grouplist:
default: 127.0.0.1:8091 # TC 协调器服务地址
client:
rm:
lock:
retry-interval: 10
retry-times: 30
服务分组 (Service Group Mapping)

通过映射关系，微服务可以解耦直接硬编码 TC 地址。生产环境中可利用 Nacos / Eureka 动态注册与发现 Seata TC 协调器集群。

开启下一个核心：Slide 39 · 第 7 讲课程总结与分布式事务知识图谱

核心实战心得 (Spring Boot Seata Practical Insight)

在 Spring Boot 项目中落地 Seata 非常简洁。只要在业务入口方法标注 @GlobalTransactional，并在各个微服务分支数据库建立 undo_log 表，Seata 就能自动拦截 Feign/Dubbo 调用并完成跨库事务保护。
