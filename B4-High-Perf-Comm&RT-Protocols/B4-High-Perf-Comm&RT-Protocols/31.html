1. `SimpMessagingTemplate` 主动推送原理与范式 Active Push API

在真实工业场景（如金融股票行情变动、后台任务完成通知、系统紧急告警）中，消息往往由**服务端后台线程或外部 MQ 事件主动触发**。Spring 提供了线程安全的 SimpMessagingTemplate 工具类，解耦了请求响应循环。

① 全局主题广播 (`convertAndSend("/topic/...")`) Pub/Sub Broadcast

任何后台组件（如定时任务 `@Scheduled` 或消息队列监听器）均可随时调用 messagingTemplate.convertAndSend("/topic/market-data", quote)，向所有订阅该 Topic 的客户端同时进行极速广播。

② 用户精准私聊 (`convertAndSendToUser(...)`) Targeted User P2P

调用 convertAndSendToUser(userId, "/queue/notifications", notice)，Spring 会自动将地址补全转换为属于该用户的专用 Session 动态前缀（例如 `/user/{userId}/queue/notifications`），确保私密性。

③ 金融高频行情与批量聚合防爆策略 Batch & Rate Limit

对于高频更新（如毫秒级外汇/股票价格），可在服务端使用环形缓冲区或 Reactive 流量聚合（如每 100ms 批量打成 Array），避免过于频繁的 WebSocket 帧冲垮网页端渲染主线程。

架构设计：SimpMessagingTemplate 是连接后端 Spring 事件生态与前端 WebSocket 的枢纽
2. 后台主动推送与私聊 Controller 代码实现 Scheduled & P2P Code
① 后台定时任务高频行情推送 (`StockMarketTickerService.java`) @Scheduled & Broadcast
@Service
@EnableScheduling
public class StockMarketTickerService {
@Autowired private SimpMessagingTemplate messagingTemplate;
@Scheduled(fixedRate = 1000) // 每秒轮询行情并主动广播
public void broadcastStockPrices() {
StockQuote quote = new StockQuote("600519", 1820.50, System.currentTimeMillis());
// 无需客户端请求，主动群发至订阅了 /topic/stocks 的所有长连接
messagingTemplate.convertAndSend("/topic/stocks", quote);
}
}
② 点对点私信与安全身份关联 (`PrivateChatController.java`) convertAndSendToUser
@Controller
public class PrivateChatController {
@Autowired private SimpMessagingTemplate messagingTemplate;
@MessageMapping("/private.message") // 匹配 /app/private.message
public void sendPrivateMessage(PrivateMessage msg, Principal sender) {
// 自动寻址目标用户 msg.getRecipientId() 的专属通道 /user/{id}/queue/messages
messagingTemplate.convertAndSendToUser(
msg.getRecipientId(), "/queue/messages", msg
);
}
}

核心架构启发 (SimpMessagingTemplate Active Push Insight)

SimpMessagingTemplate 将 WebSocket 从“单纯的请求-响应拦截器”提升为“通用后台事件通知总线”。无论是后台定时任务、MQ 消费监听器还是业务微服务事件，均能以非阻塞方式向指定的订阅客户端或特定用户推送实时推送，奠定了工业级长连接推送的工程底座。
