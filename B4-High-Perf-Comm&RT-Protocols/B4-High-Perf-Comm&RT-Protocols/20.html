Spring for GraphQL 架构与工程化快速入门

`spring-boot-starter-graphql`, Schema Co-location, `@QueryMapping` & `@SchemaMapping` Handlers

1. Spring for GraphQL 核心机制与注解编程模型 Spring Integration

Spring 官方提供了 **Spring for GraphQL** 项目，与 Spring Boot 深度集成。开发者只需引入 spring-boot-starter-graphql 依赖，并在约定目录下编写 Schema 文件，即可通过声明式注解将图节点映射到 Spring Bean 方法。

① 约定存放路径与自动挂载 (Auto-Configuration) schema.graphqls

Schema 文件默认存放于 src/main/resources/graphql/*.graphqls。Spring Boot 启动时会自动扫描并合并所有的 `.graphqls` 契约，自动注册为全局可执行的 GraphQL Schema 对象。

② 声明式注解体系 (`@QueryMapping` & `@Argument`) Data Fetchers

在标准 Spring @Controller 中，使用 @QueryMapping 自动绑定同名的 Query 根字段；使用 @Argument 提取 GraphQL 查询入参（如 `id`）。

③ 嵌套关联字段延迟解析器 (`@SchemaMapping`) Lazy Field Resolver

当客户端查询嵌套对象（如 `Book` 内部的 `author`）时，@SchemaMapping 注解方法接收父对象参数 `Book`，**仅在客户端明确索取 `author` 字段时才触发二次查询**。

工程优势：天然集成 Spring 依赖注入、安全拦截器与 Java 17 Record 数据模型
2. Schema 契约与 Spring Controller 实现代码 (Code) Schema & Controller
① Schema 契约 (`src/main/resources/graphql/schema.graphqls`) SDL Schema
type Query { bookById(id: ID): Book }
type Book { id: ID, name: String, pageCount: Int, author: Author }
type Author { id: ID, firstName: String, lastName: String }
② Spring Controller 节点处理函数 (`BookController.java`) @QueryMapping
@Controller
public class BookController {
@QueryMapping // 映射 Query.bookById(id) 根请求
public Book bookById(@Argument String id) {
return Book.getById(id);
}
@SchemaMapping // 映射 Book.author 嵌套图节点
public Author author(Book book) {
return Author.getById(book.authorId());
}
}

核心架构启发 (Spring for GraphQL Engineering Insight)

Spring for GraphQL 通过规范的注解机制彻底屏蔽了底层 GraphQL-Java 引擎复杂的 DataFetcher 繁琐手写注册流程。**通过约定优于配置 (`graphqls`) 结合 `@QueryMapping` 与 `@SchemaMapping`，开发者可以像开发 RESTful 接口一样敏捷优雅地交付强类型的图 API**。
