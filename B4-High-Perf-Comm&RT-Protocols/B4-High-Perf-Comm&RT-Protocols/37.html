大模型时代 AI 打字机流式输出：SSE 在 Generative AI 中的工程落地

Token-by-Token LLM Streaming, TTFT Optimization, Spring AI `Flux>` & Fetch `ReadableStream`

1. 生成式 AI (Generative AI) 打字机流式输出原理 LLM Token Streaming

大语言模型（如 ChatGPT, Claude, DeepSeek）生成长篇回答需耗时数秒甚至数分钟。**若采用传统同步阻塞响应，首字延迟 (Time To First Token, TTFT) 极高，用户体验极差。** 通过将 LLM 内部吐出的 Token 借助 SSE 实时化推流，可将感知延迟从 10s+ 降至 **150ms 以内**。

① 首字延迟 (TTFT) 极致优化与打字机视效 TTFT < 200ms

LLM 内部自回归计算每生成一个 Token，后端立即以 SSE `data: {"content": "..."}\n\n` 帧推向前端，前端配合打字机（Typewriter）动画即时渲染，呈现出拟人化实时思考与回答过程。

② 为何 LLM 场景完美适配 SSE 而非 WebSocket？ Protocol Choice

AI 对话交互具有天然的**单向不对称性**：客户端发起单个带复杂 Prompt 的 HTTP POST 请求；随后仅需服务端单向将生成结果连续吐回。无需复杂全双工 WebSocket 握手，纯 HTTP 语法的 SSE 是性能与轻量化的最佳解。

③ 业界标准终止符规范 (`data: [DONE]\n\n`) OpenAI Spec

参照 OpenAI 标准 API 规范，当大模型生成完全部内容时，服务端发送特殊的终结标记帧 data: [DONE]，告知前端解析器正常关闭 HTTP Stream 句柄并停止光标闪烁。

AI 架构法宝：SSE 打字机推送已成为当下所有 LLM 产品的工业级标准解法
2. Spring AI Reactive 端点与前端 Fetch Stream 代码 Spring AI & JS ReadableStream
① Spring Boot / Spring AI 响应式流端点 (`AiChatController.java`) Flux<ServerSentEvent>
@RestController
@RequestMapping("/api/ai")
public class AiChatController {
@Autowired private OpenAiChatModel chatModel; // Spring AI
@PostMapping(value = "/stream", produces = MediaType.TEXT_EVENT_STREAM_VALUE)
public Flux<ServerSentEvent<String>> streamLlmChat(@RequestBody PromptReq req) {
// 1. 订阅大模型生成的 Token 异步流
Flux<String> tokenStream = chatModel.stream(req.getPrompt());
// 2. 将每个 Token 封装为 SSE 格式数据帧
return tokenStream
.map(token -> ServerSentEvent.<String>builder().data(token).build())
.concatWith(Mono.just(ServerSentEvent.<String>builder().data("[DONE]").build()));
}
}
② 前端 Fetch API + `ReadableStream` 流式读取器 (`chat_ui.js`) ReadableStream Reader
async function fetchLlmAnswer(prompt) {
const response = await fetch('/api/ai/stream', {
method: 'POST', headers: { 'Content-Type': 'application/json' },
body: JSON.stringify({ prompt })
});
// 获取底层 ReadableStream 读句柄
const reader = response.body.getReader();
const decoder = new TextDecoder();
while (true) {
const { done, value } = await reader.read();
if (done) break;
const chunk = decoder.decode(value, { stream: true });
appendTokenToTypewriterUI(chunk); // 实时增量更新打字机 UI
}
}
