核心教学目标 (Learning Objectives) 4 Core Capabilities
1

掌握基于 Protocol Buffers 的强类型二进制 RPC 协议 gRPC 的 4 种通信模式（Unary, Server/Client/Bidi Stream）与 Spring Boot 工程化集成本领。

2

掌握 GraphQL 声明式查询语言，精通 Schema 类型系统、Resolvers 映射与按需精准数据索取，彻底消除 Over/Under-fetching 缺陷。

3

掌握 WebSocket 协议握手与全双工原理，能够熟练运用 Java WebSocket 注解模型与 Spring STOMP 广播构建高性能长连接应用。

4

理解 SSE (Server-Sent Events) 单向 HTTP 流机制，并能在 AI 大模型时代设计出符合极致体验的打字机式流式响应 (Streaming Output) 架构。

能力模型：打破 REST 边界，适配极速 IPC、多端组合、长连接与 AI 流式

第 4 讲教学主线哲学

没有放之四海而皆准的万能协议。**根据通信边界（内网 vs 外网）、数据形态（图状按需 vs 流式）与交互模式（一问一答 vs 双向全双工 vs 打字机流）做出最佳契合的设计**，是现代化服务端架构师的终极追求。
