Spring Boot gRPC 服务端工程化集成

Spring gRPC Auto-Configuration, Project Layout (`src/main/proto`), Dependencies & Server Port

1. Spring Boot gRPC 标准工程目录规范 Project Layout

通过官方 spring-grpc-spring-boot-starter，Spring 实现了 gRPC 服务的自动生命周期绑定。开发者只需将契约存放在 src/main/proto/ 目录下，构建时即可自动派生 Java 基类并在 Spring 容器中发布 Netty 服务。

se3353_22_grpc (Spring Boot gRPC Server)
├── src/main/
├── java/org/sjtu/se/se3353_22_grpc/
├── GrpcServerService.java // 服务端业务继承 BaseImpl
└── Se335322GrpcApplication.java // 启动入口
├── proto/ ← .proto 契约文件专有存放目录
└── helloworld.proto // Protobuf 接口定义
└── resources/
└── application.yml // 监听端口配置 (例如 9090)
└── target/generated-sources/ // Maven 插件自动编译产物
**零手动外挂 Server**：自动启动嵌入式 Netty gRPC Server，监听专属端口。
**注解直接绑定**：基于 `@Service` 即可自动注册到全局 gRPC 路由映射表。
自动化理念：用标准化的 Maven 插件屏蔽复杂的跨语言变码步骤
2. Maven 依赖依赖配置与服务端参数 (`pom.xml` & `application.yml`) Server Configuration
// pom.xml: 核心 starter 依赖与服务管理
<dependencies>
<dependency>
<groupId>org.springframework.grpc</groupId>
<artifactId>spring-grpc-spring-boot-starter</artifactId>
</dependency>
<dependency>
<groupId>io.grpc</groupId>
<artifactId>grpc-services</artifactId>
</dependency>
</dependencies>
// application.yml: 声明 gRPC 服务端监听端口
grpc:
server:
port: 9090 # 默认 gRPC 服务监听端口
client:
local-grpc-server:
address: "static://localhost:9090"
negotiationType: plaintext
编译时生成流程 (Protobuf Compilation Flow)

当运行 mvn package 或 mvn compile 时，内置插件自动扫描 /proto 下的定义，并在 target/generated-sources 自动生成强类型的派生基类（如 `SimpleGrpc.SimpleImplBase`）。

核心架构启发 (Spring gRPC Integration)

Spring Boot 对 gRPC 的工程化封装彻底简化了自建 Netty Server 的繁琐逻辑。**通过约定优于配置 (`src/main/proto`)，开发者可以像编写普通 Spring Service 一样轻松发布高性能的二进制 RPC 服务**。
