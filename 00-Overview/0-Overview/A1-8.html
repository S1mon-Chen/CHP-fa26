8 次课程 5 大分层递进架构图

5-Tier Progressive Curriculum Architecture

5 Tiers Roadmap
Tier 5: 终局系统集成层 L8 (Course 8)

L8 全栈系统架构 & Capstone: 缝合所有原语，手写微服务网关、沙箱 Harness、Tracing 与自动 PR 提交 Agent 平台。

Tier 4: 自主认知与控制编排层 L6 & L7 (Courses 6-7)

L6 智能体架构 (Brain/Body): ReAct、规划与记忆；L7 控制流工程: DCG 状态图、Checkpointer 时光旅行与沙箱 Harness。

Tier 3: 原子执行与模式治理层 L4 & L5 (Courses 4-5)

L4 原子能力 (Function Calling): 强类型工具契约；L5 技能模式 (Skill Network): Router、Fallback、Dry-Run 与防腐层。

Tier 2: 知识与协议扩展层 L2 & L3 (Courses 2-3)

L2 MCP 协议: 上下文与工具标准化暴露管道；L3 企业 RAG: AST 代码切分与混合检索事实锚定。

Tier 1: 基础指令与契约层 L1 (Course 1)

L1 指令工程: XML 隔断、Prompt 三要素、Pydantic 强类型输出与防御性约束。

物理逻辑：底层为上层提供确定性原语，上层为下层提供控制力与系统缝合

8 次课程之间的相互演进关系

Inter-Course Architectural Dependencies

Evolution Flow
从嘴到眼睛
L1 → L2/L3 (语言到上下文感知)： L1 解决了“如何规范表达”，L2 与 L3 通过 MCP 管道与 RAG 检索给 LLM 戴上了看清代码库与外部系统的“眼镜”。
从眼睛到双手
L2/L3 → L4/L5 (感知到物理执行)： 有了上下文后，L4/L5 赋予 LLM 改变物理系统的“双手”，并用 Router、Dry-Run 与中断卡扣确保手不越界。
从双手到大脑
L4/L5 → L6/L7 (能力到控制流)： L6 组合感知与双手构建自主 Agent 大脑；L7 进一步用 DCG 状态图、Checkpointer 与 E2B 沙箱为大脑穿上防护装甲。
从原语到平台
L1~L7 → L8 (组件到全栈平台)： L8 将前 7 次课的所有散落“砖石”通过微服务网关、Tracing 与 CI/CD 评估卡扣组装为商业级 Capstone 平台。
学习方法：每一次课都是下一次课的物理组件，层层递进无缝缝合

Ultimate Goal of Course Series / 课程体系核心培养目标

Architect Mindset Shift
1. 打破黑盒依赖 不依赖开源框架魔法，手写核心子系统算子
2. 驯服概率非确定性 用强契约、DCG 状态图与沙箱确定性卡扣防护
3. 具备全栈交付能力 独立构建能自动修 Bug、跑单测并提交 PR 的平台

Pre-Course Architecture Philosophy / 架构师视角

不要将大模型视为简单的“对话聊天框”，而要将其视为系统架构中的“非确定性虚拟 CPU”！通过全套 8 次课程的学习，你将学会如何用结构化契约（L1）、协议（L2）、知识（L3）、能力（L4-L5）、大脑（L6）、控制流（L7）与微服务架构（L8）将其打造成高平稳、零溃败的企业级数字引擎。
