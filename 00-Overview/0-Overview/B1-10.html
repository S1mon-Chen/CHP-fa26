第二单元：现代服务端架构与技术栈全景路线图

融会贯通微服务网关、高并发计算、通信协议、事件驱动、分布式事务、海量检索与云原生服务治理

柱一：计算与并发基础 Lectures 01 - 02
第 01 讲 云原生状态

云原生架构与分布式状态管理

单体 $\to$ 微服务 $\to$ Serverless，无状态设计 (Stateless) 与集中 Session/Token 管理。

第 02 讲 并发演进

现代 Java 高并发编程与模型演进

JMM 契约、J.U.C 无锁并发、1:1 平台线程瓶颈与 Java 21 虚拟线程 (Loom) 协程。

底座：单机计算与状态解耦
柱二：通信与事件驱动 Lectures 03 - 05
第 03 讲 Web API

Web API 演进与现代化 API 网关

从 SOAP 到 RESTful/OpenAPI，网关路由、统一鉴权、限流熔断与协议转换。

第 04 讲 高性能通信

高性能通信与实时交互协议

gRPC HTTP/2 多路复用、GraphQL 灵活动态查询、WebSocket 与 SSE (AI 流式推送)。

第 05 讲 事件驱动

事件驱动架构 (EDA) 与消息中间件

JMS 到 Kafka/Pulsar，高吞吐零拷贝、Exactly-Once 与 CQRS 事件溯源。

链路：服务间同步/异步管道
柱三：数据、事务与高速检索 Lectures 06 - 09
第 06 讲 单机事务

数据库事务机制与并发控制原理

ACID 特性、MVCC 多版本并发控制、WAL 与行锁/间隙锁死锁防护。

第 07 讲 分布式事务

分布式事务与微服务一致性控制

CAP/BASE 最终一致性，Saga、TCC 模式与 Seata 无侵入事务。

第 08 讲 内存缓存

高性能缓存架构与分布式内存数据库

Redis 核心结构、多级缓存、雪崩/穿透治理与 AI 语义/向量缓存。

第 09 讲 海量检索

海量数据检索与向量搜索引擎

倒排索引与 ES 架构，向量检索 (Vector DB) 与 RAG 混合检索。

持久：数据状态一致与毫秒检索
柱四：云原生服务治理 Lecture 10
第 10 讲 终章集成

微服务、云原生与现代后端服务治理

Spring Cloud $\to$ K8s Native $\to$ Service Mesh (Istio / Dapr)，分布式可观测性三大支柱 (Logs, Metrics, OpenTelemetry Tracing)。

治理：云原生运维与三维可观测性
