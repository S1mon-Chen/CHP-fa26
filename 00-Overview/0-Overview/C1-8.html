第三单元《数据基础设施》8 次课升级演进脉络与底层逻辑

本单元从关系型数据库规范化与理论出发，历经 InnoDB 性能调优与 NewSQL 演进，平滑跨越至文档数据库、知识图谱（GraphRAG）、时序物联网、LSM-Tree 底层引擎，直至面向 AI 时代的向量检索与混合召回底座。以下是全部 8 次课的紧密承接关系图谱。

第 1 讲 (Lecture 1) 关系理论

关系数据库理论与范式化实战

数据依赖、第一至第四范式、正则覆盖、高并发下的反范式化与零停机 Schema 变更。

承接起点：奠定关系存储基石
第 2 讲 (Lecture 2) 存储调优

InnoDB 调优与 B+Tree 索引物理设计

EXPLAIN 执行计划、Buffer Pool、Change Buffer、去除淘汰 MEMORY 引擎改用 TempTable/Redis。

深化：解决单机读写与缓存瓶颈
第 3 讲 (Lecture 3) 高可用与NewSQL

MySQL 备份恢复与 NewSQL 演进

PITR、GTID 主从、MHA/Orchestrator 高可用演练及 TiDB/PolarDB 等分布式 NewSQL 架构演进。

承接：保障关系数据高可用与扩展
第 4 讲 (Lecture 4) 文档模型

NoSQL 文档数据库：MongoDB 与切片

Document Model、WiredTiger 引擎、聚合管道 Aggregation Pipeline、Sharded Cluster 分片与 Change Streams。

转折：引入文档模型与多引擎协同
第 5 讲 (Lecture 5) 图数据库

NoSQL 图数据库：Neo4j 与 GraphRAG

属性图模型、Cypher 图查询语言、图算法、知识图谱与大模型结合的 **GraphRAG** 智能问答底座。

承接：构建复杂网络关系与图检索
第 6 讲 (Lecture 6) 时序数据库

NoSQL 时序数据库：InfluxDB 与 IoT

时序数据高 QPS 追加、InfluxDB 3.0 Apache Arrow/Parquet 引擎、数据降采样 Downsampling、IoT 治理。

承接：应对物联网海量高频时序写入
第 7 讲 (Lecture 7) LSM引擎

LSM-Tree 存储引擎：RocksDB 内部架构

B+Tree vs LSM-Tree 写放大对比、MemTable/SSTable/WAL、Compaction 压缩策略、作为 TiDB/Flink 底座。

承接：探究极高写入吞吐底层的 LSM 引擎
第 8 讲 (Lecture 8) 向量数据库

NoSQL 向量数据库：Milvus 与 AI 召回

Vector Embeddings、HNSW/IVF-PQ 算法、Pinecone/Milvus 选型、BM25+向量双路混合检索与 RAG 底座。

终章：赋能 AI 时代的高维向量检索与 RAG

第三单元《数据基础设施》演进逻辑总结 / Upgraded Data Infrastructure Evolution Logic

RDBMS (1-3) → Document (4) → Graph (5) → Time-Series (6) → LSM (7) → Vector (8)

本单元从传统的关系型数据库理论与 InnoDB 调优（第 1-3 讲）出发，顺应云原生与大数据时代的技术浪潮，平滑扩展至面向多态与半结构化的文档数据库（第 4 讲）、支撑知识图谱与 GraphRAG 的图数据库（第 5 讲）、面向物联网高频追加的时序数据库（第 6 讲）、探究极高写入吞吐底层的 LSM-Tree 与 RocksDB 引擎（第 7 讲），并最终在人工智能浪潮下收官于面向 RAG 与大模型混合检索的向量数据库（第 8 讲），构建出完整的现代企业级高并发数据基础设施全景图谱！
