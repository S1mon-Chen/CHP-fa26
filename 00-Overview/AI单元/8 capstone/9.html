Design Pattern 03 · 反思与自我纠错模式 (Reflection Pattern) 落地指南

模式三：Vibe Coding 下 Reflection 智能体的生成与 SQL 自动报错修复验证

在复杂的数据库查询生成场景中，大模型初次编写的 SQL 常因表名错误或语法缺陷导致执行崩溃。本模式让智能体具备自主反思（Reflection）能力：捕获数据库异常栈，自主分析原因并修复错误，直至 SQL 成功跑通。

Vibe Coding 实践执行四步法 WORKFLOW
1. 在 WorkBuddy 聊天框发送提示词：
"请帮我创建一个 SQL 自动纠错智能体 reflection_sql.py，能够自动执行大模型生成的 SQL，若报错则将错误栈交由 Reflection 模块反思并自主修正语法直到执行成功。"
2. AI 自动生成反思源码：
WorkBuddy 在后台自动新建 reflection_sql.py，内置 SQL 执行器与自我复盘纠错循环逻辑。
3. 自动调起沙箱终端 (Sandbox)：
AI 自动在沙箱中执行运行命令：python reflection_sql.py，验证自愈机制。
4. 检验反思效果 (Verification)：
终端输出第一次执行报错及 Reflection 反思修正后的成功日志，验证闭环！
反思模式：让 AI 具备像人类程序员一样的 Debug 复盘能力！
