Zero-Code Practice · 零代码创建企业级 Expert 专家数字员工

无需写代码！用 WorkBuddy 的 Create Expert 功能一键生成并调用专业智能体

学生无需编写任何 Python 或 JSON 代码！只需点击界面的 「Create Expert」 按钮，输入领域设定提示词，即可快速拥有一个具备行业专长、合规边界的专业 AI 数字员工，并在日常任务中随时通过 @Expert 唤醒使用。

第一步：通过 Create Expert 创建智能体 STEP 01
界面操作路径：
打开 WorkBuddy 左侧菜单栏 → 点击 「Experts」 → 点击顶部 「+ Create Expert」 按钮。
在 Expert 描述框粘贴提示词：
你是“企业财务合规与审计专家”，精通企业财务报销规范、税法发票核验与内部风控红线。 核心职责： 1. 逐行审核员工上传的 CSV/Excel 报销明细表，重点比对金额、报销事由与发票类型。 2. 发现超标餐饮宴请（单笔超 1000 元）、无明细发票或连号发票时，自动标记 [违规风险]。 3. 严格遵循客观中立原则，以结构化表格形式出具合规审查报告，单笔超标金额自动建议转人工总监审批。
系统自动生成底座，无需碰任何代码。
第二步：在聊天框 @ 唤醒并使用 Expert STEP 02
@财务合规与审计专家 请帮我审查工作区里的 reimbursement_sample.csv 报销单，找出所有违规与超标记录，并以结构化卡片列出审计汇总结论。
Expert 自动化执行与交付反馈预览：
🤖 [@财务合规与审计专家 已就绪]
[1] 正在自动加载工作区数据表: reimbursement_sample.csv ...
[2] 比对《企业财务审计红线》：已完成 20 笔报销核验。
⚠️ [违规告警] 发现 1 笔商务宴请金额 2,800 元 (超 1,000 元红线)！
✅ 审计简报生成完毕，已自动挂起大额单据待总监二次审批。
专业聚焦：专人专事，杜绝大模型角色漂移。

Speaker Notes / 讲师备课备注
🎯 讲师教学要点： “各位同学，今天我们不要写任何一行代码！在 WorkBuddy 中，点击左侧菜单的 Experts，再点击 ‘+ Create Expert’ 按钮。把我们左侧准备好的提示词一键复制粘贴进去，就能立刻生成专属于你的‘财务合规专家’！然后在聊天框里直接 @ 它，就能审查报销单了！”
💡 为什么使用 Expert 而不是普通 Chat？ 普通 Chat 的角色会随对话轮数增加而遗忘或漂移；而通过 Create Expert 固化后，它具备持久的角色设定与红线规则，输出始终具备专业稳定性。
