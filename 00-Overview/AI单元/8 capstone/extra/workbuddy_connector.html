Connector（连接器）怎么用？打通企业真实业务系统的一键插头

普通 AI 只能读你手动拖进去的本地文件；而 Connector（连接器） 是经过安全授权的“标准数据插座”。只需 1 次授权（OAuth/API Key），AI 即可直接读写 GitHub、Notion、Jira、MySQL、飞书/钉钉 等企业现有系统，彻底告别“人工下载再上传”的低效流程。

Connector 零代码配置与使用三步法 ZERO CODE
步骤 1：打开 Connectors 市场并选择服务
点击 WorkBuddy 侧边栏 「Settings / Integrations」 → 选择 「Connectors」。
找到你要连接的系统（例如：GitHub、Notion、Jira、MySQL、飞书）。
步骤 2：一键授权绑定 (OAuth 登录或填入 API Token)
点击 「Connect」，在弹窗中完成授权（如通过浏览器登录 GitHub 或填入 Notion Token），系统显示 CONNECTED 绿灯即表示通道打通。
步骤 3：在对话框直接用自然语言调度：
请使用 @GitHub_Connector 读取仓库 'org/order-service' 中最近 3 天标有 'bug' 标签的 Issue，将它们按紧急程度分类，并自动把汇总报告同步写入到我的 @Notion_Connector '2026年Q2研发缺陷追踪' 页面中。
密钥均保存在本地系统凭证链中，支持随时一键断开。
Connector 跨系统打通模拟沙箱 2 CONNECTORS READY
跨系统执行流 (Cross-System Execution): AUTONOMOUS
🔌 [@GitHub_Connector 已触发]
├── 📡 API GET: repos/org/order-service/issues?label=bug
├── 📦 获取成功: 抓取到 4 个未关闭 Bug（P0: 1个, P1: 3个）
🔌 [@Notion_Connector 已握手]
├── 📝 创建页面: '2026年Q2研发缺陷追踪'
├── 📊 自动同步: 4 个 Issues 已渲染为结构化数据库表格
✨ [Done]: 跨系统双向数据搬运完成，全程耗时 1.2 秒！
无需编写爬虫或数据同步脚本，即插即用。

黄金三角协同概念：Expert、Skill 与 Connector 到底怎么配合？

👤 Expert（专家智能体 / Who） “有岗位的数字员工”，负责制定业务策略与思考逻辑（如：SRE 运维专家、财务审计主管）。
🛠️ Skill（能力插件 / How） “手里的通用工具函数”，负责单点运算与格式处理（如：发票核验算法、Word 排版生成器）。
🔌 Connector（连接器 / Where） “通往外部系统的数据通道”，负责提供真实数据进出的管道（如：GitHub、MySQL、Notion、Jira）。
