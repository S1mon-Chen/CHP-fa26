Design Pattern 01 · 智能分流路由模式 (Router Pattern) 落地指南

模式一：Vibe Coding 下 Router 网关的生成、沙箱运行与提示词闭环

在 Vibe Coding 时代，您无需手动编写或拷贝代码！只需点击下方按钮复制完整提示词并发送给 WorkBuddy，AI 即可在内置沙箱中自动创建文件、启动终端并动态运行验证。

Vibe Coding 实践执行四步法 WORKFLOW
1. 在 WorkBuddy 聊天框发送提示词：
"请帮我创建一个智能客服总分发网关 router_gateway.py，包含意图分类器，能把财务,技术,通用咨询分别路由到不同 Agent。"
2. AI 自动生成代码与文件：
WorkBuddy 在后台自动在工作区创建文件并写入完整的 Python 逻辑，无需你手动敲一行代码。
3. 自动调起沙箱终端 (Sandbox)：
AI 自动在内置的安全隔离沙箱终端中执行命令：python router_gateway.py。
4. 检验分流结果 (Verification)：
终端输出分类判定日志（如识别“退款”并精准命中财务 Agent），沙箱验证成功！
告别手动敲代码：对话即代码，沙箱即验证！
