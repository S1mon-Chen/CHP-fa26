核心 Takeaways (随时复习)

1

插头思维：MCP 就是万能转换器

不再需要自己写爬虫或 API 代码。把 MCP 视为开源社区造好的“插头”，你只需要找到对应业务的插头（如 SQLite、Puppeteer）接上即可。

2

极简配置：写 JSON 就是做填空题

对大括号和引号脱敏。配置的核心只是把官方文档里的示例代码复制过来，然后把“文件路径”或“环境变量”替换成你自己的。

3

敬畏数据：双重防呆锁必须上

在接入外部真实数据（尤其是数据库）时，必须在配置文件中开启 Read-Only，并在 Prompt 中强化不准修改数据的约束（PACT 里的 C）。
