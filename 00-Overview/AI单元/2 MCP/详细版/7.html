揭秘 JSON：别怕，这只是 三道填空题

业务人员永远不需要从头手写代码！所有的 MCP 配置都是从官方文档复制过来，
然后只改动那三个关键的“填空位”。

config.json
{ "mcpServers": {
"我的业务数据库": {
"command": "npx", "args": ["-y", "mcp-sqlite-tools"],
"env": { "SQLITE_DEFAULT_PATH": "/Users/admin/Downloads" }
} } }

将鼠标悬停在代码高亮区域查看图解

填空 1 给插头贴个标签

第一行的引号里随便写！这就是给你的插件起个名字，方便你自己认识。比如可以叫 "公司财报库" 或者 "我的网页抓取器"。

填空 2 告诉 AI 去哪买工具包

command 和 args 决定了加载哪个外部工具。这一段绝对不要自己写，直接去官方文档或开源社区把别人写好的名字复制过来。

例如 mcp-sqlite-tools 就是社区里写好的数据库连通器包名。

填空 3 填写你的本地真实地址

这是最重要的一步！你需要告诉插头，你电脑上的数据到底放在哪个文件夹里。绝大多数人的报错，都是因为在这里乱填了一个不存在的路径。
