接通数据库神经：配置 SQLite MCP

弹药已经就位。现在，把下面这段配置复制到你的 Trae 中，
并完成那道最重要的“填空题”。

config.json (免安装现代版)
{ "mcpServers": { "我的业务数据库": { "command": "npx", "args": [ "-y", "mcp-sqlite-tools" ], "env": { "SQLITE_DEFAULT_PATH": "填入你的 Downloads 文件夹路径" } } } }
1

复制配置并粘贴

点击左侧的“一键复制”按钮。然后打开 Trae 的 Settings -> MCP Servers，将代码粘贴进去。

2

完成这道“填空题” (极其重要)

还记得我们在避坑指南里讲的吗？必须把红框里的中文，替换成你真实的本地路径！

/Users/你的电脑名/Downloads
C:\Users\你的电脑名\Downloads
3

保存并亮起绿灯

确保路径两边保留双引号，且语法正确。点击保存，等待 Connected 状态出现！
