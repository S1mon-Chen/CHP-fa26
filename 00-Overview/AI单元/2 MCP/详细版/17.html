跨越次元壁的 “缝合级”指令

现在 AI 既能读本地文件，又能上网抓网页。
我们要用结构化的 Prompt，指挥它打出一套完美的“组合拳”。

自动化审核指令模板
# 请将之前下载的 Excel 拖入 Trae，并发送以下指令：
你现在是一位严格的【财务审计专家】。请帮我完成以下跨维度数据比对任务。

<数据源>
1. 报销标准（外网）：请使用 Puppeteer 抓取工具读取该网页的规章制度：
https://baike.baidu.com/item/差旅费/2965682 (注: 你可替换为公司真实链接)
2. 待审表单（本地）：我已经把《10月报销明细.xlsx》拖进了对话框中。
</数据源>

<执行步骤>
第一步：从网页中提取【交通费】和【住宿费】的报销上限或违规说明。
第二步：读取本地 Excel 里的每一行报销记录和金额。
第三步：进行交叉核对，揪出所有违规超标的员工。
</执行步骤>

<输出要求>
请用 Markdown 表格输出审查报告。表格需包含：姓名、项目、申报金额、合规判定、超标原因。
重点违规的金额和原因，请用红色加粗显示。
</输出要求>

为什么要加 XML 标签？

当任务变得复杂（既要上网抓数据，又要读本地 Excel）时，大模型很容易“发癫”混淆逻辑。使用 <数据源>、<执行步骤> 这样的 XML 标签，就像给大模型画了思维导图，强制它按部就班执行。

明确触发 MCP 工具

注意指令里的这句话：“请使用 Puppeteer 抓取工具读取...”。这是在明确给大模型下发**调用特定插头**的许可权，能极大提高网页抓取的成功率。

SOP 流程化 (执行步骤)

作为“产品经理”，你不需要教 AI 怎么写代码，但你**必须梳理好业务 SOP（标准作业程序）**。先查标准 -> 再读数据 -> 最后比对，逻辑越清晰，AI 的执行就越精准。
