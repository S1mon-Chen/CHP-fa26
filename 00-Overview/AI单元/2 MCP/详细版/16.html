我们不用官方容易报错的 Fetch，直接换上更强大的“无头浏览器”。
好消息是：这次连“填空题”都不用做了！

config.json (Puppeteer MCP)
{ "mcpServers": { "全能网页抓取": { "command": "npx", "args": [ "-y", "@modelcontextprotocol/server-puppeteer" ] } } }

// 如果你的 config 里已经有了刚才的 sqlite，请注意用英文逗号 , 将两个配置隔开。

学以致用：为什么要换插头？

还记得我们在避坑指南里讲的吗？官方的 Fetch 插件底层依赖 Python，容易报 404 Not Found。我们直接换成 Node.js 驱动的 Puppeteer，免除编译烦恼！

这次没有烦人的“填空题”

抓取网页不需要读取你本地的文件，所以你完全不需要配置本地路径 (env)。复制左侧代码，直接粘贴保存即可！
