99% 的新手，死在“路径填空”上

大多数人的 MCP 启动失败，并不是代码写错了，
而是把官方示例里的“假地址”，原封不动地贴到了自己的配置里。

常见的绝望时刻
Terminal
...
[mcp.config.usrlocalmcp.sqlite-db] MCPClient#onClose npm warn deprecated...
[info] [mcp...sqlite-db] MCPServerManager#onClose Disconnected.
[error] ... MCPClient#startFailed Connection closed
[error] ... ExtHostMCPService#$start Fail to start
案情侦破：

你用的是 Mac 电脑（路径前缀是 /Users/...），
但你刚才配置里的最后一行却写着：
"C:/我的工作/2024财务数据.db"
这是 Windows 的假路径！文件找不到，插件当然当场崩溃。

正确姿势：获取文件的“绝对路径”

如果你是 Mac 用户：

  1. 1 在访达中选中目标文件或文件夹。
  2. 2 按住键盘上的 Option (⌥) 键不要松开。
  3. 3 点击鼠标右键，选择 “将 xxx 拷贝为路径名”。

如果你是 Windows 用户：

  1. 1 在资源管理器中选中目标文件或文件夹。
  2. 2 按住键盘上的 Shift ⇧ 键不要松开。
  3. 3 点击鼠标右键，选择 “复制为路径 (Copy as path)”。
注意：Windows 复制出来的路径自带双引号（如 "C:\..."），粘贴到 JSON 时，确保不要出现双重引号 ""C:\...""。
