Module 5: 安全红线与单元收官

Horror Story · 悬崖勒马

当能力爆表的 AI 拿到了一把 无形的刀

刚才我们体会到了“用嘴连通数据库”的爽感。
但是，如果你对这位全能却不懂业务常识的“实习生”随口说错一句话...

临近下班时的随口一说
🥱 “哎，今天查了一天数据库，好累。帮我把库里那些退款的、没用的测试数据**随便清理一下**吧，我准备下班了。”
我
AI 思考中：
用户要求“清理数据”。我已连接 SQLite 数据库，具有读写权限。我将执行 SQL 连带删除操作...
灾难发生
Trae - MCP 执行日志
DANGER
> Calling tool: mcp-sqlite-tools (execute_query)
> Analyzing intent: "Clean up useless test and refunded data"
> Generating SQL command...
DELETE FROM orders WHERE status = 'refunded';
> Executing query...
[SUCCESS] 850 rows deleted.
Database size reduced by 15MB.

为什么会发生这种事？

AI 是一个极度听话但**没有业务常识**的超级机器。当你把数据库直接连给它时，**它默认同时拥有了“读”和“写”的最高权限**。如果你不加以限制，一句随口的抱怨，就可能变成一条真实执行的删库指令（DROP / DELETE）。

在 Vibe Coding 时代，写代码不再是壁垒，“安全兜底与权限收拢”才是产品经理最核心的基本功！
