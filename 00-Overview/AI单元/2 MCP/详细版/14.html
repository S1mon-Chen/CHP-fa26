Under The Hood · 魔法揭秘

一句大白话背后的 黑盒运作机制

刚才那短短几秒钟，你的 AI 助理在后台完成了一个高级数据分析师的所有工作。
让我们慢动作回放，看看它到底有多聪明。

STEP 1 意图理解 (NLP 转换)

AI 接收到你的大白话需求，提取出核心字段要素，并意识到自己需要调用外部工具来获取数据。

"用户要查表 orders，过滤条件是 status='refunded'，目标是退款金额前三..."

STEP 2 自动编写 SQL 代码

AI 将你的需求翻译成了专业的数据库查询语言 (SQL)，并准备通过 MCP 发送给数据库。

SELECT product_name, SUM(price) AS total_refund FROM orders WHERE status = 'refunded' GROUP BY product_name ORDER BY total_refund DESC LIMIT 3;

STEP 3 MCP 提取原始数据

插件执行了上面的 SQL，从你本地的 `.db` 文件中抓取出了冰冷的、机器看的数据格式 (JSON)。

[ { "product_name": "Standing Desk", "total_refund": 3198.0 }, { "product_name": "Mechanical Keyboard", "total_refund": 1377.0 }, { "product_name": "Ergonomic Office Chair", "total_refund": 899.0 } ]

STEP 4 组织汇报文案

AI 大脑拿到 JSON 数据后，按照你的要求（“大白话输出”），将其润色成了老板爱看的分析报告。

“第一名是站立办公桌，高达3198元...”

Vibe Coding 核心心法：你负责把关，它负责干活

作为业务人员，你完全不需要记住 STEP 2 里的 SELECT、WHERE 怎么拼写。你只需要在它弹出请求 (Allow) 的时候，大概扫一眼。如果是查报表，直接点允许；如果数据很重要，你可以让 AI 把它查出来的逻辑用大白话给你解释一遍，**你做业务逻辑的审核者即可**。
