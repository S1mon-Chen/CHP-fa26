让 AI 自动阅读 网页规章制度 辅助审核

痛点：公司报销制度在网页上，每次审核本地 Excel 都要来回对照，容易遗漏。
解法：安装更强大的 Puppeteer MCP (自动化浏览器)，让 AI 边看网页边审表格。

安装 Puppeteer MCP

请将这段代码粘贴到 Trae 的 MCP 配置中。它是官方的自动化抓取组件，**零配置，免填路径**，即插即用！

... "puppeteer-web": { "command": "npx", "args": [ "-y", "@modelcontextprotocol/server-puppeteer" ] } ...

准备待审核文件

点击下方下载包含员工报销明细的本地 Excel 文件。

一键跨网审核指令
[P] 你是专业的财务审计员。
[A] 请通过 puppeteer MCP 访问并读取这篇关于差旅费标准的公开百科页面（提取其中的住宿和餐饮限额原则）：
https://baike.baidu.com/item/%E5%B7%AE%E6%97%85%E8%B4%B9/4523315
[C] 严格根据网上的原则，审核我桌面的 10月报销单.xlsx。不准乱编规则。
[T] 在 Excel 最后加一列，如果超标请标注“违规”及原因，保存为新表。
调用 puppeteer MCP -> 自动打开浏览器并提取百科页面内容...
