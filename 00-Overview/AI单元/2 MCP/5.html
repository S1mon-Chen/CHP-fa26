Module 2: 零代码配置你的第一个 MCP

Installation · 实操演示

打破代码恐惧：安装 MCP 其实就是“填空题”

非技术人员看到 JSON 文件就会本能抗拒。
今天我们揭秘：在 Trae/Cursor 中安装插件，只需要你复制粘贴 1行字。

Trae MCP 设置界面
安装入口：点击 Trae 左侧边栏 -> 展开 MCP Servers -> 点击 + Add
{ "mcpServers": { "sqlite-db": { "command": "npx", "args": [ "-y", "mcp-sqlite-tools" ], "env": { "SQLITE_DEFAULT_PATH": "C:/我的工作/数据文件夹"| } } } }

程序员管这个叫 config.json，很多业务人员打开这里就直接退出了。

Vibe Coding 翻译视角
极简填空
1
给你的插头起个名字 ("sqlite-db")
🔌 插头名称：本地数据库
2
复制免编译的云端组件名 ("mcp-sqlite-tools")
📦 买个转换器：用无依赖的现代 Node 版
3
唯一需要你填写的地方（环境变量）！
📍 授权哪个文件夹？ C:/我的工作/数据文件夹

这就是安装的全部！

不要被括号和引号吓到。别人已经把复杂的连接代码写好了（比如怎么连数据库），你只需要把这段配置复制过来，把最后那个“文件路径”改成你自己的即可。点击保存，你的 AI 就拥有了查库的能力。

配置已复制，请前往 Trae 粘贴！
