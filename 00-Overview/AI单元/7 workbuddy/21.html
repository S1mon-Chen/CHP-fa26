赋予智能体行动的“四肢”。通过注册私有 Python 函数，让大模型在运行时根据用户自然语言意图动态选择并执行对应工具。

运行机制：LLM 动态解析自然语言意图，自主拼装参数并触发对应 Python 函数。
1

私有 Python 函数注册

开发者可将内部数据库查询、API 对接或邮件通知封装为标准 Python 函数，供智能体随时调遣。

2

动态意图解析与参数推断

大模型自动阅读函数签名与 Docstring 文档，精准从自然语言中提取参数（如日期、大区、阈值）。

3

多工具链条自主串联

当单一工具无法满足需求时，AI 会将上一个工具的输出作为输入，自主完成复杂的多步流水线任务。
