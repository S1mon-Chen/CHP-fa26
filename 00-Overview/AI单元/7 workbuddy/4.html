Module 1: 架构对比 —— WorkBuddy vs Dify vs n8n

Ecosystem Comparison · AI 三剑客生态定位对比

灵魂三问：WorkBuddy 与 Dify、n8n 的本质区别是什么？

从“大脑、四肢到全栈伴侣”，理清现代 AI 工程师工具箱中三驾马车的完美分工。

1. Dify (推理大脑)

专注于大模型编排、提示词链、向量知识库检索（RAG）与智能对话应用发布。

核心定位： 负责“思考与问答”。

2. n8n (自动化四肢)

专注于多系统 API 对接、Webhook 钩子监听、定时任务巡检与零代码数据管道。

核心定位： 负责“系统集成与跑腿”。

3. WorkBuddy (全栈伴侣) ⭐

专注于本地代码库深度感知、AST 索引、终端沙箱安全执行与自主 Bug 修复。

核心定位： 负责“直接动手改代码交付”。
