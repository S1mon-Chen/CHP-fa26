智能体定义与 Persona 编写：用 agent.json 赋予垂直领域专业性

通过结构化配置文件设定专属角色边界，将通用大模型转换为具备审计风控或运维巡检能力的资深专员。

agent.json (Auditor Persona) CONFIG
{
"agent_name": "Risk_Auditor",
"role": "Compliance Auditor",
"system_prompt": "You are an expert auditor. Scan workspace metrics, cross-reference targets, output markdown reports.",
"constraints": ["Never disclose salary data", "Verify data source via checksum"]
}
行为约束：通过 System Prompt 划定明确的边界，确保智能体输出专业严谨。
1

结构化配置 (agent.json)

采用标准 JSON 格式集中管理智能体的身份标识、版本号、关联工具与基础策略。

2

System Prompt 行为约束

通过严格的边界限定（如禁止输出敏感薪酬、必须交叉校验数据），防止 AI 产生幻觉或越权输出。

3

垂直领域专业性赋能

让同一个大模型在不同配置文件下摇身一变，成为审计、运维或法务专属的“数字员工”。
