接入大模型后端：打通本地 Ollama (DeepSeek) 与云端 API

为 WorkBuddy 提供强劲的推理算力支持。支持本地运行开源大模型（保护绝对隐私），也可无缝挂载主流云端大模型 API。

方案一：本地 Ollama (DeepSeek-R1) ⭐

完全运行在本地硬件中，代码与数据零外传，特别适合涉密企业或对隐私要求极高的研发场景。

ollama run deepseek-r1:8b
零云端成本 · 绝对隐私安全

方案二：云端大模型 API 接入

通过环境变量或配置文件挂载企业级云端 API Key（如 OpenAI、Anthropic 或国内主流商业大模型）。

WORKBUDDY_API_KEY=sk-xxxxxx
WORKBUDDY_BASE_URL=https://api.model.com
极致推理速度 · 适合大规模复杂重构
