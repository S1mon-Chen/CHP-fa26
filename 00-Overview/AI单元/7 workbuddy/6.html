安装与授权准备：WorkBuddy 的环境依赖与插件配置

在让 WorkBuddy 接手数据清洗项目之前，我们需要正确配置运行依赖、IDE 插件与本地安全授权凭据。

1. 基础环境与依赖要求

确保计算机已安装 Python 3.10+、Git 以及现代 IDE（如 VS Code 或 JetBrains 系列），为代码索引提供底层支持。

python --version && git --version

2. 客户端或插件安装

通过 IDE 扩展市场安装 WorkBuddy 官方插件，或者在终端通过包管理器一键全局初始化 CLI 客户端工具。

npm install -g workbuddy-cli

3. 授权认证与 API 对接

配置企业授权 Token 或接入本地大模型后端（如 Ollama），确保 WorkBuddy 具备合法的推理调用额度。

workbuddy auth login --token
