Local Installation · 项目局部技能部署

项目局部 Skill 安装指南：随仓库版本管理的团队规范

将架构规约和多文件 Skill 直接提交至团队项目仓库中，实现“代码与 AI 规约同步进化”。

Project Root Setup Git Repository

# 在项目根目录下创建 .ai-skills 目录：

mkdir -p .ai-skills/enterprise-architect

# 随 Git 提交后，团队其他成员拉取代码即可共享该 Skill。

完美解决团队协作中“每个人 AI 规范不一致”的痛点，实现规约即代码 (Rules as Code)。
1

项目根目录挂载

在当前微服务或业务系统的项目根目录下建立 .ai-skills/ 隐藏文件夹。

2

随 Git 版本协同提交

将多文件 Skill 纳入 Git 版本控制。当架构规范升级时，通过 Pull Request 团队同步评审。

3

项目独占隔离保护

当切换到其他不相关的项目时，该局部 Skill 自动隐藏，绝不污染全局开发环境。
