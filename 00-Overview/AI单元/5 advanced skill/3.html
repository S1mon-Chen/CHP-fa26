Module 1: 架构演进 —— 复杂 Skill 的多文件结构化设计

Multi-File Architecture · 多文件架构蓝图

复杂 Skill 的核心解法：多文件结构化拆解

借鉴微服务与模块化思想，将庞大的 SKILL 拆分为“总指挥官 + 领域子模块 + 资产库”。

enterprise-architect-skill/ Directory Tree
├── SKILL.md # 总指挥官 (主控路由)
├── rules/
├── security.md # 安全合规规约
└── performance.md # 性能与并发准则
├── templates/
└── arch_report_format.md # 交付样板间
└── scripts/
└── validate_schema.py # 自动化校验脚本
模块化拆分让每个子文件各司其职，完美消灭 Git 冲突。
1

主控文件负责路由分发

SKILL.md 只负责意图识别与总调度，不塞入冗长细节，保持大脑清爽。

2

领域子模块按需隔离

将安全规约与性能规范独立拆分，多人协作时互不干扰，彻底消除合并冲突。

3

公共资产跨 Skill 复用

样板间与校验脚本可被其他轻量 Skill 轻松引用，实现企业 AI 资产的模块化复用。
