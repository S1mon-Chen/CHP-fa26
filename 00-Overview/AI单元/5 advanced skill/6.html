Rules Directory · 领域规约目录

领域子模块拆解：将安全与性能规约独立 isolation

不同业务领域各司其职，安全规约与性能规范各归其位，彻底告别单文件的千行混战。

rules/security.md
# Security Rules (安全合规红线)
1. 凭据防硬编码： 禁止明文密码/Key。
2. SQL 注入防御： 必须使用参数化预编译。
rules/performance.md
# Performance Guidelines (并发与性能)
1. 高并发瓶颈： 读多写少必须引入 Redis 缓存。
2. 慢查询监控： 超过 500ms 的 SQL 必须进行优化索引。
1

关注点分离 (Separation of Concerns)

安全规则、性能规范与业务逻辑解耦，让每个子文件专注于单一领域，便于日常维护与迭代。

2

多人协同零冲突

当团队中负责安全的同学修改合规红线时，只需调整 rules/security.md，绝不触碰其他文件。

3

按需精准注入

只有在识别到特定安全审查请求时，AI 才将该子文件内容载入上下文中，极大节省 Token 开销。
