Configuration · 专属配置

装载插头：接入 本地知识库

现在，让我们把刚刚下载的“弹药库”正式授权给 AI。
依然是一道熟悉的填空题，请在 args 中填入真实的本地路径。

config.json (FileSystem MCP)
{ "mcpServers": { "本地企业知识库": { "command": "npx", "args": [ "-y", "@modelcontextprotocol/server-filesystem", "填入解压后的 Company_Docs 绝对路径" ] } } }
1

复制并粘贴配置

打开 Trae 的 Settings -> MCP Servers，点击左侧按钮复制上面的代码并粘贴。（如果已有其他配置，记得加英文逗号 , 隔开）。

防坑预警：必须是文件夹路径！

错误示范： /Users/.../Downloads/Company_Docs.zip
AI 是无法直接读取压缩包的！请务必确保填入的是解压后文件夹的路径。

/Users/用户名/Downloads/Company_Docs
C:\Users\用户名\Downloads\Company_Docs
3

保存并亮起绿灯

确保路径带有双引号。保存后，观察 Trae 设置界面出现 Connected，即代表 AI 已获准进入该文件夹！
