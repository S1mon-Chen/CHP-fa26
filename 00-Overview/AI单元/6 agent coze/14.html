Coze 一键发布与渠道配置指南

UI GUIDE

1 准备发布并配置变更日志 (Publish)

点击 Coze 工作台右上角的 “发布 (Publish)” 按钮。在弹出的面板中，填写本次迭代的更新日志（例如：“v1.2: 增加硬件故障知识库与多路路由分诊能力”）。

2 勾选分发渠道并授权 (Channels)

Coze 预置了国民级协同软件的免代码对接通道。只需勾选需要的平台，按提示填入您企业内部申请好的应用凭证，Coze 会在后台全自动处理加密与打通：

企业微信 / 微信服务号: 需填入 AppID, Secret
飞书 (Feishu): 需填入 App ID, App Secret

3 开放为 API 供自研系统调用 (可选)

如果您的公司有自建的 ERP 或原生 App，可以勾选“发布为 API”。Coze 会自动生成一个安全的 Bearer Token 与 RESTful 接口文档，您的后端程序员几行代码即可将其接入自有系统。
