Coze 调试与日志查看指南

DEBUGGING GUIDE

1 触发试运行 (Test Run)

点击 Coze 画布右上角的 “试运行” 按钮，输入 Start 节点必填的测试参数（如 keyword: "小米 SU7"），系统将启动整条流水线。

2 展开节点执行详情 (Trace Log)

运行完毕后，界面右侧或下方会弹出执行结果。点击任意节点（如 Plugin 或 LLM），可以展开查看该节点的绝对透明黑盒：

  • Input: 上游真实传过来的数据是什么？
  • Output: 本节点处理后吐出的数据是什么？
  • Duration: 这个节点耗费了多少毫秒？

3 节点标红报错定位 (Error Handling)

如果工作流中断，出错的节点会高亮标红。通常的报错原因有：插件网络超时、大模型参数缺失、或 Code 节点代码存在语法错误（SyntaxError）。
