挂载插件 (Plugins)：接入实时搜索 API，彻底消除大模型幻觉

大模型本身是不联网的“记忆罐”，直接让它生成最新的“竞品动态”，它极大概率会胡编乱造（产生幻觉）。在 Coze 工作流中，我们需要在 Start 和 LLM 节点之间，插入一个插件节点 (Plugin Node)，让流水线具备“实时查阅外部世界”的超能力。

Coze 插件挂载操作指南

UI GUIDE

1 寻找并拖入头条搜索插件

在 Coze 左侧的“插件 (Plugins)”栏，搜索 Toutiao Search。将其拖入画布，放置在 Start 与 LLM 节点之间。

Toutiao_Search.search

2 剪断旧连线，重新映射参数

核心操作：悬停在之前 Start -> LLM 的连线上点击垃圾桶剪断它。然后将 Start 的 keyword 连线给插件的 query 必填参数。

Start.keyword Plugin.query

3 将检索结果投喂给大模型

插件搜索完毕后会输出一个 JSON 列表 (news_list)。将它连线给下游的 LLM 节点，让 LLM 充当“阅读理解”的角色，根据最新资料进行总结。
