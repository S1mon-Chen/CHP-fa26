第六单元：AI 智能体与自动化工作流 (Coze 云端免部署编排实战)

Module 2 · 工作流 (Workflow) 编排实战

实战场景设定：市场部全网竞品动态自动化巡检与结构化日报

企业市场部每天需要耗费大量人力在全网搜索竞品动态，并将零散的信息复制、提炼成格式统一的早报。这种“路径极度固定、输出格式要求刚性”的任务，正是 Coze 工作流 (Workflow) 降本增效的绝佳舞台！

业务痛点与工作流破局方案

BUSINESS CASE

传统人工操作的痛点 (As-Is)

  • 耗时低效：每天早上运营专员需花 1.5 小时在头条、百度搜索竞品（如：“华为鸿蒙”、“小米汽车”）的新闻。
  • 信息噪音大：搜出的文章长篇大论，人工通读和提炼核心观点极为痛苦。
  • 格式易乱：手工复制粘贴到 Word/飞书文档，极易排版错乱、漏掉关键链接。

Coze 工作流破局方案 (To-Be)

我们将用 Coze 搭建一条严丝合缝的自动化装配线。大模型在这里不再享有自由聊天的权利，而是被死死按在“总结提炼”这个固定工位上打工。

[触发] 每天早 8:00 ➡️ [插件] 自动搜索全网新闻 ➡️ [LLM] 去重并提取 3 条核心要点 ➡️ [格式化] 严格转为 Markdown 表格 ➡️ [发布] 发送至飞书群

剧透：下一节我们将用到的 Coze 工作流四大核心节点

1. Start 节点 流水线入口。接收定时器传入的参数（如“今日日期”、“目标竞品关键词”）。
2. Plugin 节点 调用【头条搜索】或【Bing API】插件，瞬间抓取全网最新 Top 10 资讯文本。
3. LLM 节点 大模型干苦力。强制它把几万字废话提炼成 3 条纯干货，不准多说一句客套话。
4. Code 节点 用一段简单的 Python 脚本，把干货拼接成精美的 Markdown 表格，流转给 End 输出。
