系统端到端执行流复盘

ARCHITECTURE REVIEW

1 前台接客与意图解构 (Router)

主控大模型剥离用户情绪，将一大段话精准切割为两个子任务：处理 Error 05 和 取消订单查退款，并分发给两条路线。

2 专科专家挂载武器执行 (Workers)

  • 技术专家：不回答退钱的事，专注调用 PDF 知识库 (RAG) 查阅 Error 05 的排障图解。
  • 财务专家：不回答机器的事，专注调用 ERP API 插件 获取订单取消进度。

3 成果融合成帧 (Merge & Output)

两个底层专家的专业回答被汇聚回主通道，由系统统一润色后，以极高专业度、互不冲突的连贯话术返回给飞书/企微端的用户。
