数据清洗与代码节点：强制约束 100% 的确定性输出格式

大模型是“概率模型”，即使提示词写得再严格，它也可能偶尔输出多余的寒暄语（如“好的，这是您要的 JSON：”）。在工作流中，这种不确定性会导致下游系统（如数据库入库、自动化群发）直接报错。利用 Code 节点（代码节点），我们可以通过一小段 Python 或 JS 脚本，实现格式的物理级硬约束！

代码节点 (Code Node) 配置指南

UI GUIDE

1 添加节点与参数映射

在大模型节点（LLM）之后，拖入一个 Code (代码) 节点。在输入参数中，定义一个变量接收 LLM 的原始文本。

LLM.output_text args.input.llm_text

2 注入极简 Python 清洗脚本

在代码编辑器中，利用编程语言强大的字符串处理能力，强制生成 Markdown 表格。 

def main(args):
    raw_text = args.input.get("llm_text", "")
    lines = raw_text.strip().split('\n')
    md_table = "| 序号 | 竞品动态要点 |\n|---|---|\n"
    for i, line in enumerate(lines):
        if line.strip():
            clean_line = line.replace('- ', '').strip()
            md_table += f"| {i+1} | {clean_line} |\n"
    return {"markdown_table": md_table}

3 传递给终端输出节点

将 Code 节点清洗后绝对标准化的 markdown_table 变量，连接到 End（结束）节点或推送到飞书/钉钉的节点。
