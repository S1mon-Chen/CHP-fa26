Module 2 · 工作流 (Workflow) 编排实战

拖拽式连线编排：创建 Workflow，配置输入节点与 LLM 推理节点

在 Coze 的画布中，节点是工作流的器官，连线是神经。第一步我们需要设定流水线的入口参数（Start），并拖入一个大模型节点（LLM），通过变量引用的方式，让大模型接收前方传来的动态数据进行推理提炼。

Coze 画布操作指南

UI GUIDE

1 定义入口参数 (Start 节点)

Start 节点是数据的源头。在这里我们需要增加一个输入参数，告诉系统我们要巡检什么。

参数名: keyword
类型: String
默认值: "小米 SU7 最新动态"

2 拖入并配置大模型节点 (LLM Node)

从左侧节点库拖入 “大模型”，选择豆包·Pro 等底座。最关键的是使用双大括号 {{}} 引用变量。

请阅读以下新闻文本，提取关于产品 {{input.keyword}} 的 3 条核心要点。
新闻内容：{{input.news_text}}

3 拖拽连线 (Connect)

将 Start 节点的输出锚点拖拽连接到 LLM 节点的输入锚点。数据流向就此初步打通！
提示：大模型现在虽然能收到词了，但它还不懂联网。下一节我们会在中间“剪断”连线，插入搜索插件。

先把 Start 和 LLM 连起来试试。大家会发现，现在大模型虽然拿到了关键词，但它回答的内容可能是过时的、瞎编的。这就是我们下一节要解决的问题！”
