Unit 1: Vibe Coding 启蒙与“咒语”工程 (35-40 Slides)

Module Breakdown · 单元模块拆解

第一单元：打破黑盒，体验“用嘴编程”的魔法

本单元是全套课程的破冰点。我们将带领零基础的业务人员完成心智重塑，安装主力工具（Trae），并掌握结构化指令（PACT）模型。最终通过 两个震撼的办公自动化实战，跑通 Vibe Coding 的第一个业务闭环。

1. 心智转换

理解大模型是“虚拟 CPU”和执行引擎，而非陪聊机器。

2. 工具破冰

零基础完成 Trae 安装与配置，消除对代码编辑器的恐惧。

3. 指令契约

掌握 PACT 提示词结构，用“黑纸白字”规范 AI 输出。

4. 实战跑通

自然语言指挥 AI 完成两个日常办公自动化脚本。

模块一

心智重塑：什么是 Vibe Coding？

Slides 1-8
  • 痛点引入： 传统办公痛点（千表合并、发票提取） vs Vibe 解决方案。
  • 范式转移： 从“写字者”转变为“下达图纸的产品经理”。
  • 认知对比： ChatGPT（聊天框） vs Trae/Cursor（具备本地文件操作权限的 IDE）。
模块二

工具准备：打造智能工作台

Slides 9-15
  • 环境搭建： Trae 下载、安装与首个本地工作夹创建。
  • 界面导览： 资源管理器、编辑区与 AI 交互区认知。
  • 模式区分： Chat 模式（只答疑）与 Builder 模式（直接写代码操作文件）的核心区别。
演示重点：手把手带领学员新建名为"我的办公自动化"的文件夹并用 Trae 打开。
模块三

指令工程：写出不翻车的“咒语”

Slides 16-25
<PACT_模型>
Persona: 你是一个10年经验的数据分析师...
Context/Constraints: 不准修改原文件，必须使用 Python Pandas...
Task: 将总表按部门拆分...
</PACT_模型>

学习使用 Markdown 与 XML 标签（如 规则）来做指令隔断，防止大模型出现幻觉。

核心模块四

实战演练：让 AI 替你干活

Slides 26-36
案例 1：Excel 极速批量拆分

场景： HR/运营每月需将包含全国员工数据的总表，按“分公司”一键拆分为几十个独立 Excel。

-> Builder 指令下达
-> AI 自动编写 Python 脚本
-> 终端一键运行见证奇迹
案例 2：杂乱文件自动归类

场景： 凌乱的下载文件夹，一键按 PDF、图片、Word 等后缀名自动建文件并归档。

引入安全卡扣：运行前让 AI 先打印出"将要移动的列表"进行确认防呆。
模块五

单元总结与课后打卡

Slides 37-40
  • Takeaways: Vibe Coding 不是学语法，而是学“表达与边界约束”。
  • 防坑预告： 遇到报错别慌，直接把错误丢给 AI（为下一课铺垫）。
  • 课后作业： 写出属于你的第一个自动化需求 Prompt 发至学习群。
