案例二：杂乱文件一键归类 (并给 AI 套上缰绳)

当我们需要 AI 帮我们“移动”或“删除”文件时，风险极高。
这次我们将学习 Vibe Coding 中的核心防御技巧：Dry-Run (防呆预览)。

带“安全卡扣”的 Prompt
你是一个精通 Python 的系统级自动化专家。
<具体任务>
- 读取当前目录下的所有文件。
- 根据文件后缀名创建对应的文件夹（如：PDF文件夹、图片文件夹、Word文件夹等）。
- 将对应文件移动到新建的文件夹中。
</具体任务>

<安全红线规则>
- 忽略 Python 脚本文件自身，不要移动它。
- 绝对不要立刻移动文件！
- 必须先在终端打印出“准备移动的计划列表”（比如 X 文件将移动到 Y 文件夹）。
- 打印完成后，通过 input() 询问我：“是否确认执行？(y/n)”。只有我输入 y，才执行移动！
</安全红线规则>

架构师心法：Dry-Run（空跑）机制

这就是 Vibe Coding 中极其重要的防呆设计。大模型偶尔会犯蠢，如果不加这道确认工序，它可能会把你桌面上重要的系统文件一并打包移走。先打印计划，再执行操作，是你驾驭 AI 的核心缰绳。
