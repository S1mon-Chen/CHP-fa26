工具的灵魂开关：Chat Builder

初学者最容易犯的错，就是用错了模式。
请记住：一个是只动嘴的“军师”，另一个是能接管键盘的“包工头”。

Chat (问答模式)

军师顾问

就像网页版的 ChatGPT，它只能把答案显示在聊天框里。它不会自动帮你新建文件，也不能直接修改你的本地数据。

适用场景

  • 解释一段你不懂的代码或报错
  • 跟你头脑风暴解决问题的思路
  • 写好代码并帮你运行

Builder (建造者模式)

干活的包工头

Vibe Coding 的真正灵魂！下达指令后，它会接管你的键盘，自动在左侧创建文件、写入代码，甚至帮你点击运行终端。

适用场景

  • “帮我写一个处理 Excel 的 Python 脚本”
  • “把刚才写的代码报错修好，然后重新运行”
  • “在这个文件夹下新建 5 个测试文件”

铁律：杜绝手动“复制粘贴”

如果你发现自己还在用鼠标高亮代码，然后 Ctrl+C、Ctrl+V，说明你用错了模式。立刻切换到 Builder！ 点一下 "Accept" (接受)，代码就会自动贴到正确的地方。
