实战场景设定：电商大促海量客诉的智能分类与意图识别

完美发挥 Dify 的大模型编排与文本解析强项，独立构建一个自动判断客户情绪、归类客诉意图并输出结构化 JSON 的智能应用。

1. 业务背景与痛点

电商大促期间客服每日面临数万条非结构化投诉文本，人工审阅效率低下，高危客诉无法实时拦截。

2. 为何选择 Dify 独立实战

本任务核心在于大模型的文本理解、提示词约束与结构化输出。Dify 完美契合该 AI 推理需求，无需任何复杂的 API 管道。

3. 核心交付目标

输入一段愤怒催款客诉，由 Dify 瞬间输出包含情感、类型与紧急度的标准 JSON 格式结果。
