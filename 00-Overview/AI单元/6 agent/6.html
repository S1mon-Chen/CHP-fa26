容器部署与本地 DeepSeek 接入：通过 Docker 一键部署 Dify 并直连 Ollama

无需云端付费 API。通过 Docker 运行 Dify 引擎，并配置 Base URL 完美打通本地 Ollama 运行的 DeepSeek-R1 模型。

Docker & Ollama Commands Terminal

# 1. 获取并一键启动 Dify 容器集群：

git clone https://github.com/langgenius/dify.git
cd dify/docker
docker compose up -d

# 2. 启动本地 Ollama 并加载 DeepSeek：

ollama run deepseek-r1:8b

# 3. Dify 后台 Ollama 供应商核心连接参数：

- Model Name: deepseek-r1:8b
- Base URL: http://host.docker.internal:11434
容器访问宿主机必须填写 host.docker.internal，避免 500 连接报错。
