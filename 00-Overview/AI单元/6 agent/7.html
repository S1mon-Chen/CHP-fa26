编写结构化 Prompt 链：实现情感分析与标准 JSON 强制输出

在 Dify 工作流中通过严密的 System Prompt 与约束机制，让大模型稳定返回可供下游系统直接消费的标准 JSON 结构。

System Prompt & JSON Template

# Dify LLM 节点系统提示词：

你是电商智能客服主管。请分析输入客诉，严格输出合法 JSON：
{
"ticket_id": "TICK-2026-0901",
"sentiment": "愤怒/平静/满意",
"category": "退款/物流/质量/其他",
"urgency_level": "High/Medium/Low"
}
# 严禁输出任何 markdown 标记或解释文字！
通过双重约束（结构模板 + 禁言令），彻底杜绝大模型吐出冗余的 Markdown 代码块符号。
1

精准的情感与分类映射

将非结构化的愤怒催款文本映射为标准化枚举值（如 sentiment: 愤怒, urgency: High），便于自动化分流。

2

Chatflow 节点参数绑定

在 Dify 的 LLM 节点输入框中直接引用 {{#sys.query#}}，实现用户输入的动态注入。

3

纯净 JSON 输出保障

确保输出结果不含多余字符，为后续独立 Dify 应用的闭环奠定坚实的数据契约基础。
