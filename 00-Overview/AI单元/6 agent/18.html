单元作业布置：任选 Dify 或 n8n 独立实现一个真实工作流并打卡

检验学习成果的时刻到了！选择你最感兴趣的引擎，在本地独立搭建一套自动化工作流或智能体应用并完成打卡。

🎯 赛道一：Dify 智能体实战

结合本地 Ollama（DeepSeek 模型），创建一个专属的私有知识库问答或智能客诉分类应用，并一键发布生成 Web App 网页。

  • - 包含系统提示词与结构化 JSON 约束
  • - 接入本地大模型运行成功
  • - 提供 Web App 访问截图或录屏
适合侧重 AI 推理与对话交互方向的学员

🎯 赛道二：n8n 自动化管道实战

在本地 Docker 运行 n8n，搭建一套定时心跳触发、接口数据抓取、Split Out 拆包、IF 分流并写入本地 CSV 的工作流。

  • - 包含 Schedule 定时器与 HTTP 抓取
  • - 配置 Split Out 与 IF 条件分流
  • - 成功将文件稳稳写入本地磁盘路径
适合侧重系统集成与数据自动化的学员
