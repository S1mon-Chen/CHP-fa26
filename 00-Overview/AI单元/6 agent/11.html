容器运行 n8n 与可视化画布：一行 Docker 命令启动 5678 端口

无需配置复杂的 Node.js 环境。通过轻量级 Docker 容器一键拉起 n8n，即刻进入强大的拖拽式自动化画布。

n8n Docker Run Command Terminal

# 在终端执行以下命令一键启动 n8n 容器：

docker run -it --rm --name n8n -p 5678:5678 n8nio/n8n

# 启动成功后，浏览器访问本地端口：

http://localhost:5678
使用 --rm 参数可在停止容器时自动清理临时文件，保持开发环境绝对干净。
