A Docker 权限防坑与白名单启动命令

若遇到 Access to the file is not allowed 或目录不可写，必须带白名单与卷挂载重启容器：

docker run -d --name n8n -p 5678:5678 -e N8N_RESTRICT_FILE_ACCESS_TO=/data -v ~/n8n_data:/data n8nio/n8n

B 写入节点关键参数设置
