激活技能：FileSystem MCP 安装与 @ 召唤术

在召唤 Skill 自动读取本地文件前，必须确保已经安装配置好 FileSystem MCP 插件。

前提：安装 FileSystem MCP

Q: FileSystem MCP 是不是要先安装？
是的！因为周报 Skill 需要自主去读取 `Team_Reports` 文件夹，必须先在 Trae/Cursor 的 MCP 设置中接入文件系统服务：

"mcpServers": {
"filesystem": {
"command": "npx",
"args": ["-y", "@modelcontextprotocol/server-filesystem", "你的工作区绝对路径"]
}
}
配置完成后重启编辑器，点亮 MCP 绿色连接状态。
聊天框召唤指令

在 Trae 聊天框输入以下极简指令，即可瞬间唤醒封装好的总监秘书：

@weekly_report_skill.md 请读取当前工作目录下的 Team_Reports 文件夹，帮我生成本周的高管精简周报！
极简高效：无需重复输入背景，AI 自动加载 Skill 中的全部 SOP 与红线约束。
