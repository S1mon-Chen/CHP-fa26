智能体架构师“九大法则”

The 9 Agent Architect Golden Rules

9 Redlines
1. 脑体解耦

LLM负责推理，MCP/RAG/Skill为器官。

2. 离散节点

划分 LLM/Data/Action/User 单职责节点。

3. 干净状态

State仅留 Raw Data，绝不存预化Prompt。

4. 图环控制

用显式END节点与 limit 硬防死循环。

5. 四级容错

区分 Retry/Loop自愈/HITL/BubbleUp。

6. 持久快照

借助 thread_id 与 DB 记录断点续传。

7. 协议缝合

以 MCP 为管道、RAG 为知识、Skill 为写。

8. 异构协同

n8n 低代码网关 + 代码微服务代理。

9. 物理事务

用 Spring IoC 接管写，享受 @Transactional。
