# Step 2: 拖出 AI Agent 节点并物理连接 3 类插槽 (Sockets)
├─ Model Socket: Groq / Ollama Chat Model (llama-3.3-70b)
├─ Memory Socket: Window Buffer Memory (k=10)
└─ Tools Sockets (多工具并发插接):
├── Tool 1: MCP Client Tool (Jira SSE Endpoint)
├── Tool 2: Qdrant Vector Store (retrieve_as_tool)
└── Tool 3: HTTP Request (POST host.docker.internal:8000/query)

# Step 3: 拖出 JS Code 节点重构清洗结构，送入 Respond to Webhook
  • 多源增强 (Multi-Source Sockets)：一个 AI Agent 节点同时挂载 MCP、Vector DB 与 HTTP 代理工具，由 ReAct 大脑自主决策调用顺序。
  • 内网避坑配置：跨容器请求后端 FastAPI 时使用 `host.docker.internal:8000` 避开 `localhost` 通信死锁。
核心：把低代码拖拽速度与高代码微服务能力融合于统一网关中
