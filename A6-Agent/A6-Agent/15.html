LangGraph 四级异常分类治理矩阵

Error Type Taxonomy & Resolution Matrix

Fault Tolerance
1. Transient
瞬时网络 / 限流抖动： 责任方：System (Automatic) $\to$ 挂载 Retry Policy 指数退避自动重试。
2. LLM-Recover
工具失败 / JSON 字段解析错： 责任方：LLM Brain $\to$ 错误观察回写 State，Loop 回 LLM 自动纠偏。
3. User-Fixable
信息缺失 / 目标指引模糊： 责任方：Human Operator $\to$ 触发 interrupt() 暂停等待补充。
4. Unexpected
未知系统崩溃 / 硬件故障： 责任方：Developer / SRE $\to$ 向上冒泡 (Bubble Up) 触发报警打断。
原则：把不同粒度的异常精准路由至最适合修复它的组件中去处理

LangGraph 异常治理 Python 实现示例

Error As State Update & Retry Policy

Python Code
// 1. LLM 可自愈错误：将 Exception 格式化写入 State
def safe_tool_call_node(state: EmailAgentState):
try:
res = run_external_mcp_tool(state["query"])
return {"search_results": res, "error": None}
except ToolExecutionError as e:
# 回写 State 驱动图环路由回 LLM 重试
return {"error": f"Tool Error: {str(e)}"}

// 2. 用户可修复错误：触发 interrupt() 挂起
def human_review_node(state: EmailAgentState):
if state.get("missing_param"):
interrupt({"message": "Please input customer ID"})
  • 自愈闭环 (Error As Feedback)：Tool 报错不打断图运行，而是压回 Context 让 LLM 重新理解后换个入参重试。
  • 挂起恢复 (Pause/Resume)：参数缺失时触发 `interrupt()` 挂起内存，待用户补充后唤醒原位继续。
工程突破：兼顾系统级自愈能力与生产环境卡扣安全，实现 7×24 运行不溃退

Architectural Core Thesis / 架构师视角

分类治理异常是保证 Agent 状态图长期鲁棒运行的核心！绝不能把所有的错误统统一关了之。将抖动交给系统 Retry、把工具解析错压回 State 给 LLM 自愈、把关键信息缺失交给 Human Interrupt 补全、把未知未知异常抛出报警，能大幅提升复杂智能体的生产稳定性。
