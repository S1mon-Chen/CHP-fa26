1. Spring AI 工单处理主控制服务

TicketOrchestratorService.java (Port 8080)

Spring AI Java
// Spring AI 核心服务：挂载 RAG Advisor, MCP 节点与物理写 Skill
@Service
public class TicketOrchestratorService {
@Autowired private VectorStore vectorStore;
@Autowired private McpClient mcpJiraClient;

public TicketResponse processTicket(TicketRequest req) {
ChatClient client = ChatClient.builder(chatModel)
.defaultAdvisors(new QuestionAnswerAdvisor(vectorStore)) // RAG 屏障
.tools(new McpToolCallbackProvider(mcpJiraClient)) // MCP 工具
.defaultFunctions("springRefundBean") // @Transactional写动作
.build();

return client.prompt().user(req.getIssue()).call().entity(TicketResponse.class);
}
}
  • 能力无缝融合：单一次 `ChatClient` 调度同时注入了 RAG SOP 召回、Jira MCP 查单以及 `@Transactional` 物理退款操作。
  • 强类型 DTO 导出：使用 `.entity(TicketResponse.class)` 自动将结果转译为符合 API 契约的 Java 对象。
物理特性：物理写动作完全在 Java 物理事务切面保护下执行

2. LangGraph 状态图复杂推演微服务

ticket_agent_graph.py (Port 8000)

LangGraph Python
# LangGraph StateGraph: 处理复杂计算、路由与 Qwen2.5 本地推演
class TicketAgentState(TypedDict):
ticket_id: str
issue_type: Literal["bug", "refund", "faq"]
sop_chunks: list[str]
mcp_jira_issue: dict | None
resolution_plan: str

# 组装状态图并设定条件边
builder = StateGraph(TicketAgentState)
builder.add_node("classify", classify_node)
builder.add_node("rag_search", rag_search_node)
builder.add_node("mcp_jira", mcp_jira_node)
builder.add_conditional_edges("classify", route_by_type_edge)
graph_executor = builder.compile(checkpointer=MemorySaver())
  • 状态图图环控制：由 `route_by_type_edge` 根据工单类型判定跳转路线，并在未决状态时循环重试。
  • 检查点快照：使用 `MemorySaver()` 支持随时被外部人机审批机制 `interrupt()` 挂起。
物理特性：暴露为 FastAPI /query REST API 供前端 n8n 反向代理
