Spring AI 整合 RAG (VectorStore & Advisor)：将企业私有知识库作为 Agent 的感知与记忆屏障

搭建企业私有知识防幻觉感知障壁：将 `VectorStore` (PGVector / Qdrant) 与 `QuestionAnswerAdvisor` 注入 Spring AI `ChatClient` 拦截链，在前置感知阶段召回领域 SOP 事实，实现零幻觉的自主推演与受控决策

1. Spring AI `VectorStore` 与 `Advisor` 配置

QuestionAnswerAdvisor & VectorStore Injection

RAG Advisor
// 1.1 声明式构建注入 QuestionAnswerAdvisor 的 ChatClient
@Bean
public ChatClient ragAgentClient(ChatClient.Builder builder, VectorStore vectorStore) {
return builder
.defaultAdvisors(
new QuestionAnswerAdvisor(vectorStore, SearchRequest.builder()
.topK(3)
.similarityThreshold(0.7)
.build())
)
.defaultFunctions("springRefundBean")
.build();
}
  • 前置透明拦截：`QuestionAnswerAdvisor` 在请求发送前拦截用户 Prompt，自动向 PGVector/Qdrant 搜索，把 Relevant Chunks 压入 Prompt。
  • 零代码侵入业务：开发人员调 `chatClient.prompt().user("...")` 时无需手写任何 VectorStore 搜索逻辑。
物理特性：在 AOP 切面层为 Agent 推演提供只读事实记忆网，根治无中生有

  • 事实约束防护：强制大模型基于物理文档 Chunk 进行推理，防止盲目“猜测”非标准命令导致生产事故。
  • 多向量库无缝对接：Spring AI `VectorStore` 抽象类天然支持 PGVector、Qdrant、Milvus 与 Pinecone。
核心：把离散的企业架构与 SOP 文档转化为 Agent 可随时调用的事实神经屏障
