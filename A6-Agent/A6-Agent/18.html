1. 图节点组装与编译

agent_server.py (Part 5: StateGraph Assembly)

Graph Compile
# 5.1 构建 StateGraph 图对象
builder = StateGraph(EmailAgentState)

# 注册离散节点
builder.add_node("classify", classify_intent_node)
builder.add_node("doc_search", doc_search_node)
builder.add_node("mcp_crm", mcp_crm_node)
builder.add_node("draft", draft_response_node)

# 设定入口节点与条件路由边
builder.set_entry_point("classify")
builder.add_conditional_edges("classify", route_intent_edge)
builder.add_edge("draft", END)

# 5.2 编译可执行图对象 (Compile Graph)
graph_executor = builder.compile()
  • 图对象可重用：`graph_executor` 一经编译，线程安全且可高并发被多个 HTTP 请求重复 `invoke()` 调用。
  • 入口与终点明确：通过 `set_entry_point("classify")` 和指向 `END` 的边收敛整个处理拓扑。
核心：编译状态图，将其抽象为单一入参、确定输出的纯逻辑执行句柄

2. FastAPI 暴露 /query 微服务

agent_server.py (Part 6: FastAPI & Uvicorn)

FastAPI Server
# 6.1 初始化 FastAPI 实例与 Pydantic 请求体
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI(title="LangGraph Email Agent Service")

class QueryRequest(BaseModel):
email_content: str
sender_email: str

# 6.2 定义 POST /query REST 接口
@app.post("/query")
async def query_agent(req: QueryRequest):
# 传入 State 初值并触发图推演
init_state = {
"email_content": req.email_content,
"sender_email": req.sender_email
}
final_state = await graph_executor.ainvoke(init_state)
return {"draft_response": final_state["draft_response"]}
  • 强类型请求校验：使用 Pydantic `QueryRequest` 保证入参 JSON 格式合法，自动生成 OpenAPI / Swagger 文档。
  • 支持原生 Async：使用 `ainvoke()` 避免阻塞 FastAPI 事件循环，最大化吞吐。
命令行启动：uvicorn agent_server:app --host 0.0.0.0 --port 8000

Architectural Core Thesis / 架构师视角

编译后的 LangGraph 图对象本身就是纯萃的业务逻辑微服务！用 FastAPI 与 Uvicorn 将其包装为 HTTP `/query` 接口，不仅能让 Agent 轻松对接前端或低代码可视化自动化网关 (n8n)，更实现了 AI 算法层与上游业务展示层的物理解耦。
