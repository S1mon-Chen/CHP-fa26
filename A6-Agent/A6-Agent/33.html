Spring AI 整合 MCP (Spring AI MCP Client)：将 MCP Tool/Resource 动态绑定至 Agent

解构 Java 生态下的 MCP 标准集成：利用 `spring-ai-mcp` 模块构建 `McpClient` 实例，将远端 Jira / GitHub / PostgreSQL MCP Server 的 Tool/Resource 转化为 Spring AI `McpToolCallbackProvider`，动态绑定至声明式 `ChatClient` 实现零硬编码跨系统协同

1. Spring AI `McpClient` 动态 Bean 绑定

spring-ai-mcp Starter & ToolCallbackProvider

Spring AI MCP
// 1.1 配置 McpClient 与 McpToolCallbackProvider Bean
@Configuration
public class McpConfig {
@Bean
public McpClient mcpJiraClient() {
return McpClient.using(new SseClientTransport("http://mcp-jira:3000/sse"))
.sync();
}

@Bean
public McpToolCallbackProvider jiraToolProvider(McpClient mcpJiraClient) {
return new McpToolCallbackProvider(mcpJiraClient); // 自动转化远端 tools/list
}
}

// 1.2 ChatClient 链式挂载 MCP 动态工具 Provider
chatClient.prompt().user("Query BUG-902 status from Jira MCP")
.tools(jiraToolProvider) // 动态绑定所有远程工具
.call().chatResponse();
  • 零硬编码 API 适配：`McpToolCallbackProvider` 自动握手远端 JSON-RPC `tools/list`，把第三方 Tool 转化为原生 `ToolCallback`。
  • 双传输通道支持：无缝支持本地进程 `StdioClientTransport` 与远程长连接 `SseClientTransport`。
物理特性：把离散的跨语言工具调用归一化为 Java 容器受控的 MCP 神经触角

2. 跨系统 MCP 物理调度与凭证隔离

Cross-System Handshake & Token Isolation

JVM Security
# 2.1 用户请求：“检视 GitHub PR #102 并创建 Jira 工单”
[Spring AI Agent] ──► McpClient (GitHub SSE): callTool("get_pr_diff", {id: 102})
Observation: "NullPointerException at OrderController.java:42"

# 2.2 ReAct 循环中自动跨系统唤醒第二个 MCP Server
[Spring AI Agent] ──► McpClient (Jira SSE): callTool("create_issue", {...})
Success: "Created Ticket BUG-9023 in Jira MCP Server"
  • 凭证隔离物理安全：Spring Boot 托管 HTTP Header/SSE 鉴权 Key，大模型仅能感知工具签名，无法直接触碰原始密钥。
  • 异构语言无缝缝合：一个 Spring AI 服务可同时挂载 Python、Java、Node 编写的分布式 MCP Server，打破语言壁垒。
核心：消除冗余的接口重写工作，实现企业 Java 应用对全网 MCP 生态的通用自治调配

Architectural Core Thesis / 架构师视角

MCP 协议是 Spring AI 迈向全网跨系统工具自治的通用标准化神经管道！借助 `spring-ai-mcp` 依赖与 `McpToolCallbackProvider`，Java 架构师无需手写任何特定系统的 API 适配层，即可将分布式 MCP Server 动态插接至 `ChatClient`，实现高内聚、易扩展的企业级 AI 自动流。
