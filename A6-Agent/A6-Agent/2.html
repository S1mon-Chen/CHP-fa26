什么是 Agent？解构 Brain（推理/规划）与 Body（Tool/MCP/RAG 交互体）

解构基于 AI 大模型自治系统的“物理两分法”架构：Brain 大脑 (LLM 推理、意图理解与 DAG 规划) 与 Body 躯干 (MCP 管道、RAG 知识与 Skill 安全执行) 的物理协同范式

The Brain (AI 推理与规划大脑)

Cognitive Core · Reasoning & Planning Engine

Cognitive Engine
// Brain 认知过程：意图分析 -> 优先级判定 -> 任务规划
Input: "Customer email: System 504 error on billing export"
1. Intent Classification: "URGENT_BUG"
2. Planning DAG: "RAG Docs -> CRM History -> Issue Ticket"
3. Decision: "Escalate to Human Agent after gathering logs"
  • 自然语言意图理解：解析复杂的非结构化需求，提取隐式约束与上下文优先级。
  • 复杂目标拆解 (Planning)：将终局目标拆解为可顺序/并行执行的控制流节点与依赖 DAG。
  • 自我反思与调整 (Reflection)：基于环境反馈 (Observation) 动态发现偏差，矫正下一步决策。
定位：决定系统的智能上限、逻辑收敛能力与认知深度

The Body (交互躯干与能力接口)

Execution Organs · MCP + RAG + Skill Hands

Execution Organs
// Body 物理器官接入：协议管道 + 知识大底座 + 物理双手
1. MCP Client Node: Connects Jira MCP & GitHub MCP Servers
2. RAG Knowledge Store: Vector Search "504 Gateway Timeout Doc"
3. Skill Pattern Net: Run `apply_bug_ticket_skill` (with HITL)
  • MCP 协议通道 (Model Context Protocol)：作为标准化神经管道，透明无缝接入跨进程、跨云端 Server 资源。
  • RAG 知识库大底座：作为 Agent 的外挂情境记忆，提供领域专有文档、架构规范与历史事实。
  • Skill 安全双手：高鲁棒性受控执行体，自带断路器、预演 Undo 与审批拦截，保障物理写安全。
定位：决定系统的物理能力边界、执行效率与安全合规底线

Architectural Core Thesis / 架构师视角

Brain 决定智能上限，Body 决定安全与能力边界！在大模型 Agent 系统设计中，大模型负责推理思考 (Brain)，而 MCP 协议、RAG 知识库与 Skill 技能网络构成了 Agent 的器官与双手 (Body)，两者的解耦编排是构建高可靠、易扩展自主系统的根本。
