受控技能网络 (Skill Pattern Net)

Course 5 Milestone · Capability Hands

Passive Control
// 被动脚本模式：依赖预定义固定链路
User Request: "Execute DB Backup Task"
↓ Step 1: Trigger RouterGate(DB_Cluster)
↓ Step 2: Call BackupSkill.execute(dry_run=False)
↓ Step 3: Run AuditLog.write()
// 局限：面对模糊目标或异常突发时，无法自我调整规则
  • 被动调用与单向确定性：只能在硬编码或明确控制流指令下按预定逻辑执行。
  • 缺乏目标自治性：面对模糊指令（如“帮我准备咖啡”或“解决 API 504 崩溃”）时无法自动拆解子目标。
定位：确定性的物理能力执行双手 (Capabilities & Hands)

自主 Agent 决策大脑 (Agent Decision Brain)

Course 6 Focus · Autonomous Cognitive Engine

Autonomous Agent
// 自主 Agent 模式：目标驱动的闭环推理
Goal: "Resolve API 504 Gateway Timeout"
1. Perception: Read logs & RAG architecture docs
2. Reasoning/Plan: "Ping DB -> Check Connection Pool -> Refactor SQL"
3. Action: Select MCP Tool / Skill & Execute
4. Observation & Loop: Evaluate result & Re-plan
  • 目标导向与自主规划：根据模糊需求自主进行 Task Decomposition，生成复杂宏观 DAG 拓扑。
  • 统筹调度底座：将 MCP 协议通道、RAG 知识大脑与 Skill 安全双手融合于单一决策图中。
定位：具备自我推理、反思与动态调整能力的自主大脑 (Brain)

Architectural Core Thesis / 架构师视角

Skill 是能力节点 (Hands)，Agent 是目标导向的自治决策大脑 (Brain)！把大模型作为核心推理引擎，结合状态图与闭环反馈 (Feedback Loop)，是驱动系统从被动脚本向全自治 Agent 跨越的根本工程抓手。
