模块二演练：跑通基于 FastAPI + LangGraph + Ollama 的本地智能 Agent 服务

运行并验证完整私有化微服务：启动 Ollama (Qwen2.5) 本地大模型推演引擎 与 Uvicorn FastAPI Web 服务，通过 Postman/cURL 发起 POST /query 请求，验证包含意图分类、RAG 检索与草稿生成的端到端推演 JSON 响应流

1. 本地服务部署与启动指令

Ollama Serve & Uvicorn FastAPI Launch

Deploy Local
# 1.1 启动 Ollama 本地离线模型服务
ollama serve
# 验证 Qwen2.5 7B 模型本地已就绪
ollama run qwen2.5 "Hello Agent"

# 1.2 启动 FastAPI LangGraph 微服务 (端口 8000)
uvicorn agent_server:app --host 0.0.0.0 --port 8000 --reload

INFO: Started server process [28012]

  • 物理脱网合规：完全运行在本地局域网，数据零上传，脱离外网 API 限制与 Token 计费。
  • 高并发 Async 支持：Uvicorn 异步事件循环与 LangGraph `ainvoke()` 无缝衔接。
物理特性：提供工业级 API 暴露能力，为上游 n8n 可视化网关（模块三）做好准备

2. HTTP /query 接口测试与响应验证

cURL / Postman Verification Trace

API Test
# 2.1 通过 cURL 发起 HTTP POST 推演请求
curl -X POST "http://localhost:8000/query" \
-H "Content-Type: application/json" \
-d '{"email_content": "API fails with 504 errors", "sender_email": "vip@acme.com"}'

# 2.2 接收端到端完整推演响应 JSON (HTTP 200 OK)
{
"status": "success",
"classification": {"intent": "complex", "urgency": "critical"},
"draft_response": "Dear VIP, regarding the 504 gateway issue..."
}
  • 端到端闭环验证：证明 State 初始化、Ollama 分类推理、RAG/MCP 检索与草稿拼接已全线跑通。
  • 无缝衔接模块三：此 REST API 可在下个模块中直接被 n8n HTTP Request 节点代理调用。
验证结论：Python 侧 Agent 状态图微服务运行稳定，具备完全解耦交付能力
