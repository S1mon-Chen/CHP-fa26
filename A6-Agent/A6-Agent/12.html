LangGraph 核心设计哲学 (1/3)：离散节点 (Discrete Nodes) 划分

Thinking in LangGraph 核心原则（Step 1 & 2）：将复杂 Agent 物理解构为单一职责的离散节点——明确划分 LLM 推理节点、Data 检索节点、Action 物理动作节点 与 User Input 人类干预节点

LangGraph 4 大类离散节点分类

Node Category Taxonomy & Responsibilities

4 Node Types
1. LLM Steps
推理与理解节点： 处理意图识别、文本生成或路由决策（如 `Classify Intent`, `Draft Reply`）。
2. Data Steps
数据与上下文检索节点： 从外部系统抓取数据（如 `Document Search`, `CRM History Lookup`）。
3. Action Steps
外部物理写动作节点： 触发写操作与物理变更（如 `Send Reply Email`, `Create Bug Ticket`）。
4. User Steps
人类卡扣干预节点： 暂停图状态机等待人类审批或补充参数（如 `Human Review`）。
原则：单一职责原理 (SRP)，确保每个节点可独立测试、可替换

Architectural Core Thesis / 架构师视角

高内聚低耦合的离散节点 (Discrete Nodes) 是构建生产级 Agent 状态图的第一步！绝不要在一个函数中将 LLM 推理、RAG 数据检索与物理写操作绞在一起。遵循 LLM / Data / Action / User 4 大类解耦，能极大地提升节点的可独立单测性与排查可追溯性。
