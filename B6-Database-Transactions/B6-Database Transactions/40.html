Part 01: ACID 物理落地 Slide 3-8
  • • A 原子性：Undo Log Before-Image 逆向撤销
  • • D 持久性：Redo Log 顺序写与 WAL 预写保障
  • • I 隔离性：并发控制消除读写冲突
  • • C 一致性：数据库状态合法转移的终极目标
Part 02: 调度与可串行化 Slide 9-15
  • • 读写冲突：$RW$ (不可重复读), $WW$ (脏写), $WR$ (脏读)
  • • 冲突可串行化：连续对调非冲突操作转换串行
  • • 优先图 (DAG)：有向无环充要判定与拓扑排序
  • • 调度安全：可恢复与无级联回滚 ($c_i < c_j$)
Part 03: 隔离级别与封锁 Slide 16-24
  • • 隔离级别：RU, RC, RR, Serializable
  • • 多粒度锁：$S$/$X$ 锁与表级意向锁 $IS$/$IX$
  • • 间隙锁防线：Record Lock + Gap Lock = Next-Key Lock
  • • Strict 2PL：排他写锁挂住直至 `COMMIT`，消除死锁环
Part 04: 快照隔离与 MVCC Slide 25-29
  • • 核心思想：“读不阻塞写，写不阻塞读”
  • • 隐藏列：`DB_TRX_ID` 与 `DB_ROLL_PTR` Undo 版本链
  • • ReadView 视窗：`m_ids`, `min_trx_id`, `max_trx_id`
  • • RC vs RR：语句级快照 vs 事务级快照复用
Part 05: WAL 预写日志 Slide 30-36
  • • Buffer Pool：内存脏页与后台平滑异步刷盘
  • • STEAL/NO-FORCE：工业界主流高并发刷盘矩阵
  • • WAL 金律：$\text{Log Flush} \prec \text{Data Page Flush}$
  • • CLR 补偿日志：记录 Undo 动作并包含 `UndoNextLSN`
Part 06: ARIES 崩溃恢复 Slide 37-40
  • • 模糊检查点：记录 DPT 与 ATT，锁定 $\min(\text{RecLSN})$

  • • 阶段 2/3：正向重放历史 $\to$ 逆向撤销 Loser 事务

1. 关系型数据库内核三大物理设计权衡 (Engine Wisdom)

Trade-off Essence
Ⅰ. 离散随机 I/O $\to$ 顺序追加 I/O (WAL 原理)

用顺序写 Redo Log 护航替代昂贵的数据页同步强刷，使得数据库写提交延迟从 10ms+ 暴降至微秒级。

Ⅱ. 共享锁互斥 $\to$ 空间换并发 (MVCC 原理)

用 Undo Log 链保留历史镜像，让占绝大多数的读 SQL 无锁执行，实现“读不阻塞写，写不阻塞读”。

Ⅲ. 物理真相现场对齐 (Repeating History 原理)

重置物理数据页到崩溃发生瞬间的客观现场，配合 CLR 算法锁死回滚工作的有界性与幂等性。

法则：理解了物理日志与锁的折中，就掌握了所有关系型数据库内核的基石
