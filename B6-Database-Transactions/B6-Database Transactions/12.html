1. 冲突等价与冲突可串行化定义

Formal Rules
冲突等价 (Conflict Equivalence: $S_1 \equiv_c S_2$) Swap Sequence

如果调度 $S_1$ 可以通过**有限次连续交换相邻的非冲突操作**转换为调度 $S_2$，则称 $S_1$ 与 $S_2$ **冲突等价**。由于交换不涉及冲突操作，两者的执行终态必然完全相同。

冲突可串行化调度 (Conflict Serializable) Sufficient Condition

如果一个交错调度 $S$ **冲突等价于某个纯串行调度 $S_{\text{serial}}$**，则称 $S$ 为**冲突可串行化调度**。这是工业界数据库保障并发安全的黄金充要判规。

本质：将复杂的并发安全性证明化归为“非冲突指令对调代数”

2. 逐步等价交换推导实战 (Step-by-Step Derivation)

Derivation Walkthrough

考虑包含事务 $T_1, T_2$ 的交错调度 $S$。通过以下两步无冲突对调，即可将 $S$ 转化为串行调度 $T_1 \rightarrow T_2$：

// 初始交错调度 S:
S = r1(A) → w1(A) → r2(A) → r1(B) → w1(B) → w2(A)
// Step 1: 对调无冲突的 r2(A) 与 r1(B) (作用于不同变量)
S' = r1(A) → w1(A) → r1(B) → r2(A) → w1(B) → w2(A)
// Step 2: 对调无冲突的 r2(A) 与 w1(B) (属于不同事务且变量不同)
S'' = [r1(A) → w1(A) → r1(B) → w1(B)] → [r2(A) → w2(A)]
// 结论：S'' 严格等于串行调度 T1 之后再执行 T2，证明 S 绝对安全！
开启下一个核心：Slide 13 · 优先图 (Precedence Graph / DAG) 拓扑验证法

核心代数启发 (Swapping Algebra Insight)

等价交换的本质是**在不破坏任何冲突操作（$RW, WW, WR$）物理相对顺序的前提下**，将散落在时间轴上的非冲突指令不断“聚拢分组”，最终拼凑出某个纯串行事务序列。
